## 6. 过程中修正的错误（如实记录）

1. **判据把"首次"造错**（1 条假红 `E12_entry_hints_shown`）：A 组把 `hints_seen=1` 写进了同一个临时设置文件，
   于是 E 组读到的"首次"其实是"已看过"。改法：E 组自己先把临时文件删掉再实例化入口，并在验证"重启保留"时
   单独写入 `volume=0.35`。**是夹具错，不是生产缺陷**。
2. **一次编辑误伤 `animal_body.gd` 声明区**：按行号替换时把 `@onready var camera` / `survival` / `ai` 等声明覆盖掉，
   当场 `git checkout` 回滚该文件（未提交的 T059 改动重做），并用 `git diff --numstat` 确认只含预期新增。**教训：改行号前先核对锚点内容**。
3. **`match` 键类型不一致**：滑块键历史上混用 `&"sensitivity"` 与 `GameSettings.KEY_*`（String），
   `_on_menu_setting_changed` 改为 `String(key)` 归一后匹配，避免静默走 `_` 分支。
