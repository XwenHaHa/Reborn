## 2. 时钟接缝

- 单一接缝：`scripts/core/game_clock.gd`（`extends RefCounted` + static；消费者 `const GameClock := preload(...)`，不用 `class_name`，避免 `--headless --script` 全局类缓存未刷新）。
- API：`now_ms()` / `is_fake()` / `use_fake(start_ms)` / `advance_ms(ms)` / `use_real()`。
- 生产实现：`Time.get_ticks_msec()`；`WorldDirector._process`、`hud.gd` Toast 到期、`save_manager.gd` 节流全部只读 `GameClock.now_ms()`。
- 世界时间注入范式（测试侧）：`GameClock.use_fake()` → `time_advancing` 保持 true → 每物理帧 `world_director.set_world_time(w + 1/60)` → `await physics_frame`。世界时间与物理帧严格锁步。
- 生产代码零测试分支：`_process` 只按 `now_ms()` 差推进；`time_advancing` 是既有暂停门闩语义；没有 `if is_fake()` 改写游戏逻辑的分支。

## 3. 批处理守卫

`Tools/t040_headless_batch.ps1`：每套 RED 判据（任一命中）：

1. 非零退出；
2. 无 `SUMMARY`/`RESULT` 或不可解析；
3. `checks <= 0`；
4. `fails < 0`；
5. `fails != 0`；
6. `RESULT|FAIL` 与 `failures=0` 矛盾；
7. 输出含 `SCRIPT ERROR`。

并账覆盖**全部**套件（含 RED），RED 行格式：`GUARD|<suite>|RED|cause=<reason>|exit=<code>|checks=<n>|fails=<n>`；整体非零退出。

**墙钟空洞守卫（负责人新增要求，2026-11-06）**：

| 判据 | 阈值 | 判定 | 退出码 |
|---|---|---|---|
| 单套输出静默（从上一次 stdout/stderr 行到 Kill/退出） | >30 s（`T040_GAP_SEC`） | 该套记 `INVALID|cause=silence_gap`，该轮整体 **INVALID** | 2 |
| 整轮墙钟 `wall_ms` 与套件耗时之和 `sum_ms` 偏离 | >60 s（`T040_DRIFT_SEC`） | 该轮记 `INVALID|list=run_drift|drift_ms=...` | 2 |

- 每套必写 `WALL|<suite>|start=..|end=..|wall_ms=..|max_silence_s=..`；每轮必写 `RUN|r|WALL|wall_ms=|sum_ms=|delta_ms=`。
- INVALID **不算通过也不算失败**，要求整轮重跑；只有 `bad=0` 且 `invalid=0` 才 `VERDICT|PASS`。
- 实现：`Start-Process -PassThru` 在 PowerShell 5.1 上取不到 `ExitCode`（即使 `WaitForExit()` 后仍为空，实测 `CODE1=[]`），改用内嵌 C# `BatchRunner`：.NET `Process` 重定向 stdout/stderr 实时落盘、每 500 ms 检查静默、超阈值 Kill、`p.WaitForExit()` 后取 `ExitCode`，返回 `exit=..|gap_s=..|max_sil=..`。
- 踩坑：PowerShell 变量名大小写不敏感，局部 `$gapSec=-1.0` 曾覆盖参数 `$GapSec=30`，把 2.2 s 的 t033 误判 INVALID；已改名为 `$gapDetected/$gapS`，并在 sleep 后先判 `HasExited` 再判静默。

**结论：不该这么慢。969.1 s = 904 s 连接待机 + 约 65 s 正常运行，与改造无关。**

| 假设 | 证据 | 判定 |
