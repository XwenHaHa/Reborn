## 3. 自身断言（`tests/run_t038_save_queue.gd`）

- `RESULT|pass=68|fail=0`，EXIT=0，连跑 3 次结果一致。
- 覆盖段：
  - A 队列基础（默认 `throttle_seconds=1.0`、同帧两请求只写一次、`revision` +1、`coalesced` 计数、队列排空）

  - E 失败注入（上表逐项 + 失败后继续 + 任一失败后至少一份可解析档）
  - F 读档回退（主档缺失 → `recovered_backup`；双坏 → `corrupt`）
  - G T037 兼容（非正式运行 `disabled`；死亡两次写且 `pending` 清空；发现/解锁各一次；退出写）

## 4. 变异校验（5 处，均「先红后复原」）

| 变异 | 效果 | 红点 |
|---|---|---|
| M1 去掉普通请求合并判定 | 同帧多次请求被重复计数 | A5/A10/A11 |
| M2 关键事务不吸收普通 pending | 关键后普通又被写出 | C2/C5 |
| M3 `.bak` 复制失败时删除旧备份且不报 warning | 备份链断裂 + 玩家无提示 | E18/E19 |
| M4 最终换名失败不回滚主档 | 主档被移走后不恢复 | E11/E12/E13 等 |
| M5 忽略节流窗口 | 窗口内重复写盘 | B2 |
