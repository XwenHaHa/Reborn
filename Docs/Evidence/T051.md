## 4. 渲染与判读（按求值后 bbox 构图）

`t051c_render.py` 逐帧按 depsgraph 求值后的包围盒摆机位/地面（本资产静止顶点带偏移，按原点或静止 bbox 会拍到空景——本轮踩过两次并修正）。

- **`t051_mouse_anim_Run_f10.png`** → 判读：「**没有明显的撕裂或拉丝**…大腿与臀部关节处过渡平滑，没有因权重缺失导致的穿插或拉扯…尾巴从臀部延伸出、长度较长且锥度自然，比例正常…**属于"可接受"**；仅右后腿根部体积略"融"进躯干。」
- **`t051_mouse_anim_Eat_f0.png`** → 判读：「无拉丝/撕裂，网格完整；但**存在严重塌陷与结构问题**：尾根像细棍插在气球上、右侧后脚"融化/穿模"进身体、躯干没有骨骼支撑感、比例失衡（梨形）…近看 0.5–3 米**需返工**。」

**判读与数值一致**：Run/Walk/Idle 数值小且判读"可接受"；Eat 数值最大（46/57）且判读"需返工" → 结论可信。
