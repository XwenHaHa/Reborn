## 5. Blender 探针（确定性数字）

### 5.1 杂散几何探针 `t049b_geom_probe.py`

判读曾提到"腹部下方有一根灰白杆状物"，用几何口径核：

```
T049B|objects|mesh=1|names=['CAT_BODY_001']
T049B|obj|CAT_BODY_001|verts=7030|tris=8376|mats=2|parent=Armature
T049B|islands|CAT_BODY_001|count=397|vert_counts=[158, 153, 141, 135, 112, 107, 101, 94, 91, 88, 85, 83]
```

只有 1 个网格对象；397 个岛屿是**毛发簇/眼鼻等贴片**（最大 158 顶点），没有异常大的杂散块。改用修正后的姿态重渲染，同一判读模型回答"腹下干净，没有杆状异物"——该"杆状物"是**旧一版渲染的角度误读**，不是资产缺陷（如实记录：未对旧帧做像素级复核）。

### 5.2 根骨位移比例探针 `t049c_drop_probe.py`

第一版"压低"看不出效果，原因是换算错了两层：

```
T049C|armature|Armature|world_scale=(0.03657,0.03657,0.03657)
T049C|root_rest|basis_y=(-0.1929,-0.0000,-0.9812)      # 根骨本地 Y ≈ 世界 -Z
T049C|rest|z_min=0.00175|z_max=0.31180
T049C|local_dz=-0.050|world_drop_max=0.00183           # 只乘静置矩阵逆 → 漏掉 27× 缩放
T049C|unit_Y|dz_max=0.03589                            # 每个本地 Y 单位只换 3.6 cm 世界高度
```

修正后的换算：`骨骼本地位移 = 静置矩阵逆 @ (世界位移 / 骨架对象缩放)`。重导出后渲染 bbox 从 `z_max 0.312`（f0）降到 **0.293**（f8）、末帧回到 **0.316**，与设定的 ±1.4/1.8 cm 压低量级一致。
（第一版直接写 `location.y = dz`，把"压低"变成了整体前移：f8 身高一点没变，`z_max` 仍 0.313。）

## 7. 过程中修正的错误（如实记录）

1. **测试文件被改坏**（`run_t049_attack_cue.gd`）：`var _wd` 插进了 `_initialize()` 内、`_assert`/`_step` 重复定义 → `Parse Error: Unexpected "Indent" in class body`。按行读回后重写成员区与函数区，`--check-only` 退出码 0。
2. **`ERROR: Animation not found: "AttackCue"`**：鼠身上 `get_animation("AttackCue")` 未命中。生产侧加 `has_animation()` 门（不是改测试）。
3. **`D3` 判据写错**：把 `speed_scale` 当"必须 > 1"断言，实际是 `speed / sprint_speed` 归一值（满速恰好 1.0）。**是夹具错**，改为对照归一比值后 PASS。
4. **假时钟下提示卡 2 s**：`AttackSettlement` 依赖世界时间，假时钟下世界时间不自走；测试改为逐物理帧 `WorldDirector.set_world_time(+1/60)`。
5. **根骨位移轴/缩放错**：见 §5.2，两处换算修正。
6. **姿态幅度过小**：见 §5.3，按判读放大并收敛（2 cm 内压低、前腿 26°）。
