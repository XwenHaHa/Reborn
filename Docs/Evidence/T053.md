## 6. 过程中修正的错误（如实记录）

1. **探针脚本反复改坏**（`tool_t053_env_modules.gd` → 最终并入断言套件并删除）：`Edit` 的 PUT 行号估计偏移，先后覆盖了 `for pb in arm.pose.bones` 类关键行。三次失败后改为**整文件重写**（内容已在上下文完整掌握），此后一次通过。教训：改脚本先用 `Read` 确认行号，不要凭"上次的行号"推算。
2. **`var name := ...` 类型推断报错**（`Cannot infer the type of "name"`）：循环变量来自未标注类型的常量数组 → 改成 `for path in MODULES` + `_measure_one(path: String)`。
3. **净空算成 −0.20 m（夹具错）**：第一版把屏障**顶面**当"地面"（`position.y + size.y = 0.60`），而门楣底面是 0.40 ⇒ 负净高。改为取屏障**底面** 0.10 后净高 0.30，与 `run_t011_greybox` 的 `GROUND_TOP` 口径一致。**是判据错，不是几何错**。
4. **鼠胶囊 1 命中（同一处夹具错导致）**：中心点被算到 y=0.50（门楣体内），修正基准后中心 y=0.25，鼠 0 命中。
