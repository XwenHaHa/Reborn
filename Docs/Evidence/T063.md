## 2. 包体积决策材料（**结论：这条省体积的路不能走**）

背景：T043 起 `export_filter=all_resources` 会把 `assets/` 的**源文件**（`.glb`/`.hdr`）一起打进包，
`Reborn.pck` 54.6 MB。看起来最省事的一招是"把源文件排除"。**实测否掉了它。**

| 方案 | `Reborn.pck` | 文件数 | 审计 | 画面（同机位、同脚本） |
|---|---|---|---|---|
| A 现状 `all_resources` | **54,611,684 B** | 229 | `leak=0`、`required_ok=10` | 菜单**有 3D 猫 + 庭院背景**（地面/水/芦苇/石墙/树），无紫块/缺失资源 |
| B 额外排除 `assets/**/*.glb` + `assets/**/*.hdr` | **44,821,008 B（−9.79 MB，−17.9%）** | 197 | `leak=0`、`required_ok=4` | 菜单**只剩纯 UI 背景：没有 3D 猫、没有庭院环境** |

- B 的导出 `EXIT=0`、审计也过（说明**审计抓不到这类"资源被排除但引用还在"的问题**）；
  是**画面判读**抓到的：vision 对同一问题回答——A「有 3D 写实猫（右下角）+ 庭院环境（地面纹理/水池/石头/芦苇/石墙/树）」，
  B「**没有 3D 猫**、背景是**纯色 UI**、无地面纹理」。
- 原因（判断，未逐条证实）：`assets/**/*.glb` 是 3D 视觉场景的直接引用；`*.hdr` 是天空 HDRI。
  把它们排掉后，导入产物（`.godot/imported/*`）虽然还在，但**引用链在包内断了** → 展示模型与天空缺失。
- **结论**：**不采纳 B**。真要瘦身必须换路子（`export_filter` 改成按"导入资源"导出，而不是按扩展名排除），
  并且**必须重跑**：包内探针 + 发行包首启 + 菜单/存活帧判读 + 审计 require。**该工作属独立任务，需负责人立项。**
- 决策现状：`export_filter` **保持 `all_resources` 不变**（预设已还原，`git status` 对该文件干净）。
