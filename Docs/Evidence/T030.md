## 6. 过程中发现的真实缺陷与修复

1. **绝对路径取 autoload 在 `--script` 早期会失败**（`Can't use get_node() with absolute paths from outside the active scene tree`）：`GameState` / `LifeCycle` / `MainEntry` 统一改为 `Engine.get_main_loop().root.get_node_or_null("X")` 相对查找；修前 B3/B4/B5 等 4 条断言失败，修后全绿。
2. **导出包内 `resources/species/*.tres` 会变成 `*.tres.remap`**（与 T027 同类缺陷）：`_discover_configs()` 先在包里拿到 0 个物种 → 入口 `selectable_slots()` 空 → 包内 6 条断言失败（`H5/H6/H10~H13`）。现在先剥 `.remap` 再按 `.tres`/`.res` 收集并去重；修后包内 111/111。**这条只在包里暴露，源码全绿也发现不了**。
3. `add_to_life()` 的 `var cur := current_life[field]` 无法推断类型（`Parse Error`）→ 改为 `var cur: Variant`。
4. `--headless` 下帧间隔极小（4 帧 ≈ 0.000 s），**不能靠帧数攒出可测时长**：H 段改为显式 `WorldDirector.set_world_time(start + 2.0)` 再断言 `duration == 2.0`（原来断言 `>0` 实测得 `0.000` 判 FAIL，属判据缺陷而非实现缺陷）。

## 7. 设计落地说明（与规格的对应）

- **D1**：`LifeCycle` 不建节点，`MainEntry` 收到 `spawn_requested` 后建身体并回呼 `mark_spawned()` → 状态机可在无渲染环境单测（B/C/D/E/F/G 全部用 `mark_spawned(null)`）。
- **D2**：档案/事件/解锁只存 `GameState`；`LifeCycle.rejections` 只做"拒绝诊断"计数，不是第二份档案。
- **D5**：结算时 `player_controlled=false` + 清空 `move_intent/want_*` + `interaction.release_interact(&"life_ended")`；身体**改名后 `queue_free()`**（不生成尸体、不产食物、`npc_count()` 不变 —— H22/H23 断言）。
- **D6**：`events` = `{seq, life_id, kind, world_time, data}`；聚合来源：食物/水取 `survival.changed` 的正增量，捕猎取 `WorldDirector.capture_reported`（`captor_id == player.source_id()`），逃脱取 NPC `CatAI.prey_lost(prey_id == player.source_id())`。
- **D7**：`SETTLING`/`SELECTING` 期间 `WorldDirector.time_advancing=false`，进入 `ALIVE` 恢复；`MainEntry._exit_tree()` 兜底恢复（避免测试/编辑器里冻结残留）。
- **D8**：`main.tscn` 只剩 `Node3D + script`；关卡/HUD/状态栏运行期构建 → T013/T018/T026 的"无调试节点/无 `CanvasLayer`"断言继续成立（`run_t013 159/159`、`run_t018 73/73`、`run_t026 96/96` 复跑全绿）。

## 8. 未验证 / 遗留（如实记录）

- **`test_mode = true` 是临时开发态**：正式"发现猫才解锁猫"的条件不在 T030 范围；入口 `@export var test_mode` 默认 `true`，一旦切换为 `false`，正式模式只放行"非捕食者"（数据驱动，不写物种名），且 `selectable_slots()` 只列已解锁物种（C 段已用桩验证该分支）。
- **真实按键选择 NOT-RUN**：`life_select_1/2` 只做了"键码 = 引擎常量"的断言（A10/A11）与逻辑路径覆盖（`select_species()`），没有真人按 `1`/`2` 的实机验证。
- **逃脱计数口径**：目前一次"被追击后脱离"记一次（`prey_lost`），不是"与捕食者的完整遭遇胜负"；结算面板分级（策划 §9.5 的"重要事件"归类）留待 P4 后续任务。
- 存档/持久化 **未做**（T037）：`GameState` 只在内存里，进程退出即丢。
- 结算界面是**运行期文字状态栏**，不是正式 UI（美术/动效属 P6）。
