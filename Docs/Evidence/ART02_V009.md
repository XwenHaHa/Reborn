## 3. V009 管线（`Tools/Blender/art02_cat_v009.py`）

- **躯干/四肢/尾巴**：一根骨架（36 关节 ×2 侧）→ `SKIN` 修改器 → `SUBSURF(1)` → 焊接重合点 → bmesh 松弛。
  四肢/尾巴是**同一张曲面的分支**；脚掌由"掌-跖-掌尖"单链延伸。
- **头部**：12 个截面 × 24 段放样 + 剖面调制（颊毛/胡须垫/颅顶压平/下巴）。
- **眼睛**：眼球 + 上下眼睑环（各 11 点、8 段管）；鼻子：鼻垫 + 人中起始。
- **耳朵**：外/内两张 8×8 曲面 + 侧边/底/顶缝合（有厚度、内耳凹陷 0.78）。
- **表面**：只用 bmesh 松弛 + 宽高斯解剖塑形（胸骨、腹线、臀下、肩胛、大腿、趾垫/趾缝）。
  **不使用** voxel remesh / decimate / 噪声位移（脚本自检里明文打印这三个 `False`）。

自检项（不过就退出码 1）：三角形 ≤10000、材质槽 ≤2、`min_z≈0`、`max_z≤0.48`、`|x|≤0.18`、
X 轴对称 ±12 mm、非流形边 = 0、毛发槽壳数 = 4（躯干+头+2 耳）、无遗留修改器。

可观察到的**真实改善**（客观部分）：
- 拓扑从 remesh 三角面汤变成 **99.3% 四边形 / 0 非流形**；
- 没有 remesh 特有的"台阶状三角 + decimate 长条三角"（线框图可直接验证）；
- 耳壳有厚度与内耳凹陷、眼球有眼睑环、鼻头/人中是独立结构。

可观察到的**仍未解决**（否决项）：
- 横向环状台阶（成因是 Skin 修改器**逐关节半径起伏**，不是 remesh；加强松弛 3 倍仍存在）；
- 四肢关节不可辨（半径起伏在实际渲染距离下读不出来）；
- 脚掌趾部（场塑形振幅已到 8 mm，仍被判"圆球"）。
