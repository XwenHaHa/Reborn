## 4. 导出包内容验证（关键证据）

### 4.1 方法：为什么这样验证

**实测发现：导出产物会拒绝 `--script` 与位置参数。** 原因明确（引擎自己的报错）：

```
ERROR: Scene path was specified on the command line, but this Godot binary was
compiled without support for path overrides. Aborting.
To be able to use it, use the `disable_path_overrides=no` SCons option when compiling Godot.
```

即**官方导出模板在编译时带了 `disable_path_overrides=yes`**，这是 Godot 的**有意设计**，不是缺陷。

**对照实验**（证明 `--script` 在编辑器构建有效、在导出产物被静默忽略）：

| 场景 | 命令 | 退出码 | 报错 |
|---|---|---:|---|
| 编辑器 + 无效脚本 | `godot --path proj --script res://tests/NOPE.gd` | **1** | `Can't load script` ✅ 有效 |
| 导出产物 + 无效脚本 | `RebornSelfTest.console.exe --script res://tests/NOPE.gd` | **0** | 无 ❌ 被忽略 |

**因此采用的替代方法**：用**编辑器二进制**加载**导出的 pck**，这样 `--script` 有效，而测的是**包里的真实内容**：

```powershell
& $g --headless --main-pack "$out\RebornSelfTest.pck" `
    --script 'res://tests/run_t002.gd' --quit-after 1200
```

### 4.3 输入链路验证

**覆盖边界（说清楚）**：
- ✅ 覆盖 `InputMap 动作 → 玩家控制器 → 实际位移`
- ❌ **不覆盖** `操作系统键盘 → 引擎`。真实按键注入无安全自动化手段（盲发按键可能打进用户当前焦点窗口），故不做，记 `awaiting-review`。

实测数值与**物理理论独立吻合**（这是控制器正确性的强证据）：

| 档位 | 参数值 | 理论位移（含加速段） | 实测位移 |
|---|---:|---:|---:|
| Walk | 1.80 m/s | ≈1.64 m | **1.653 m** |
| Sprint | 4.50 m/s | ≈3.49 m | **3.525 m** |
| Crouch | 0.90 m/s | ≈0.86 m | **0.867 m** |
| Jump | 3.20 m/s | 抬升 ≈0.522 m | **0.550 m** |

四个方向（前/后/左/右）位移方向全部正确，`walk/sprint/crouch` 三档速度关系正确。

## 6. 过程中发现并修复的真实 bug

### 6.1 玩家控制器动作名写错（已修复）

**位置**：`Game/Reborn/scripts/characters/player_greybox.gd`

**问题**：

```gdscript
if Input.is_action_pressed("pause"):      # 错：应为 crouch
    speed = crouch_speed
elif Input.is_action_pressed("jump"):     # 错：应为 sprint
    speed = sprint_speed
```

**后果**：
1. **蹲下键完全无效**
2. **按跳跃键会同时触发跳跃与冲刺**（`is_action_just_pressed("jump")` 与 `is_action_pressed("jump")` 同时命中）

**来源**：早期编写控制器时误用动作名；之后只在 `project.godot` 里补了 `sprint`/`crouch` 定义，**漏改脚本**。

**修复**：改用 `crouch` / `sprint`。**新增 `tests/run_t007_input.gd` 覆盖此类问题**（含"三档速度关系"断言，写错动作名必然失败）。

### 6.2 控制台包装选项取值错误（已修复）

`debug/export_console_wrapper` 在 Godot 4.7 是枚举，`1` = 仅调试版，导致 release 导出无 `.console.exe`。改为 `2`。
