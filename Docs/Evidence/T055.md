## 6. 过程中修正的错误（如实记录）

1. **autoload 取不到（首跑 0/1）**：`SceneTree` 脚本在 `_initialize()` 里 `root` 还没进树，`get_node_or_null("/root/AudioDirector")` 直接报 `Can't use get_node() with absolute paths from outside the active scene tree`。加 `await process_frame` 后正常（与 T043a 同口径）。
2. **衰减差只有 4.08 dB**：`unit_size` 取 5.0 m 时，1 m 与 8 m 的增益分别是 1.0 与 0.625。改为"这声音该传多远"的设计值（走 1.6 / 跑 2.4 / 攻 2.2 / 伤 3.2）后差 **10.46 dB**、且在 16 m 仍有 0.15（可闻）。**是参数错，不是模型错**。
3. **静音断言假红**：`play_count` 是累计量，切换开关前没 `reset_log()`，把上一节的播放算了进去。
4. **三处 `Edit` 行号漂移改坏文件**（`audio_director.gd` 常量区、`run_t055` 的两处函数头）：按行重读后整段重写修复；后续改为"先 Read 再改"。
