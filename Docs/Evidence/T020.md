## 4. 决策落地（对 `Docs/Tasks/T020.md` §4）

- **D1 感知是组件**：`Perception extends Node` 挂在 `AnimalBody` 下（同 T016/T019 口径）；**只观察**，做决定走既有 `alert_for(position, reason)`；
  实测 `F_move_intent_zero_in_alert` = `(0.0, 0.0)`（警戒期间 AI 不抢 `move_intent`）。
- **D2 威胁 = 异物种的存活身体**：遍历 `animal_bodies` 组比较 `species_id`，**不写物种名分支**。
- **D3 视觉顺序**：距离 ≤ `vision_range × cover_factor` → 视锥半角 → `world_static` 视线遮挡；
  近距 ≤0.80 m **跳过**草丛分档与遮挡、**仍受视锥限制**（`B_near_exempt_0.6m_seen=true`、`B_behind_not_seen=false`）；
  草丛系数 = 重叠 `cover_volumes` 取最小（实测 0.4；不在草丛 1.0）。
- **D4 听觉**：不吃墙、不吃草丛（`C_wall_does_not_block_hearing` / `C_cover_does_not_reduce_hearing` 均 true）；距离 = `HearingRange × Loudness`；
  自己的声源按 `source_id` 忽略。
- **D5 噪声是快照**：只带**发生位置 + 时间**；`last_seen_*` 与 `last_noise_*` 分开存；声源走开后快照不动（`D_noise_snapshot_unchanged=0.0000`）。
- **D6 脚步**：`footstep_interval_base` 0.5 s 按速度反比缩放（夹在 0.1–1.5 s）；只在落地且速度 >0.05 m/s 时计数；
  用世界时间差 → 暂停不出声（`E_no_steps_while_paused` ✓）。
- **D7 逃跑优先级**：可达 `hide_spots` → 可达 `cover_volumes` → 都没有则**不设目的点**，靠 `flee_timeout` 回退（G1 段）。
- **D8 可达判据**：`map_get_closest_point` ≤ `reach_tolerance` **且** `map_get_path` 非空、末端 ≤ 容差；导航未同步时按可达处理。
  关卡实测：鼠层路径末端距洞 **0.010 m**、猫层最近点 **0.700 m**（`H_cat_layer_cannot_reach_hole`）。
- **D9 状态迁移**：看见威胁 ≤1.8 m → 直接 `FLEE`；否则 `ALERT`（0.3 s）→ 仍可见 → `FLEE`；
  `HIDDEN` 保持到「`now − max(last_seen, last_noise) ≥ 4.0`」（`F_hidden_elapsed_ge_4=4.02 s`）。

## 6. 附带修复：导航层反查读错 meta 键（T019 遗留，T020 捕获时发现）

- **现象**：`-- t020` 捕获日志出现 **2 条** `ERROR: The object does not have any 'meta' values with the key 'species'`，
  backtrace 指向 `_resolve_nav_layer (res://scripts/ai/animal_ai.gd:249)`；`-- t018` 不出现（T018 没开 AI）。
- **根因**：关卡的导航区域写的是 **`metadata/species_id`**（`tool_make_courtyard_nav.gd:122`），
  而 T019 的 `_resolve_nav_layer()` 读的是 `metadata/species`；`debug_entry.gd:844` 读的是 `species_id`（正确）→ 两处口径不一致。
  另外 `get_meta(name, null)` 在 Godot 里**默认值为 null 等同于报错**（不是「返回 null」），
  所以**每次建 AI 都报错一次**，并静默退回 `fallback`。
- **影响**：真实关卡里鼠与猫都退回**层 1** → **猫会用鼠的导航面**（猫的层 2 被忽略）；日志被 ERROR 污染。
  鼠恰好也是层 1，所以 T020 的鼠类断言看不出问题；T019 的用例也发现不了——它的夹具自己 `set_meta("species", "Mouse")`
  （`run_t019_mouse_ai.gd:392`），**读了同一个错键却碰巧得到正确结果**。
- **修法**（最小、可回退）：新增 `AnimalAI.node_species_id(node)`，先 `species_id` 再兼容 `species`，
  一律用 `has_meta()` 判断（**不传 null 默认值**）；`_resolve_nav_layer()` 与 T020 新增的 `find_hide_spot()` 都改用它。
- **复验**：捕获日志 ERROR **2 → 0**；T019 `C_nav_layer_is_mouse_layer` = 1、`C_nav_layer_source` = `metadata`（仍 PASS）；
  T020 164/164 ×3；全量回归 18 套件全绿；包内复验全绿。
