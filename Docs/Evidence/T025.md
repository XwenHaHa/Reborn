## 6. 过程中改掉/发现的问题（都记在这里）

1. **`_locked_dir` 清零顺序错**（实现缺陷，套件抓到）：`step()` 里先清锁定方向再结算伤害帧 → `_facing_direction()` 走"无方向 = 放行"兜底 →
   **朝向检查整个失效**（E3b 侧方 90° 仍被打中）。改成**先结算再清零**，并把这条写进代码注释。
2. **T024 夹具把"隐藏点"放在竞技场外（±20 m）**：猎物在场外**持续下落**，回到场内时按落地速度吃到跌落伤害
   （实测 `fall=88.85 m/s` → `(88.85−7)×10` 封顶 100 → **直接摔死**）。这解释了 D4 段"第二次搜索没发生"。
   已把默认隐藏点改到 **身后 15 m**（仍在场外视距、但在地面上）；诊断用的 `MEASURE|d4a|d4|` 两行留在套件里当证据。
3. **`prey_dead` 捷径撤回**：为"猎物死了就别搜"加的分支要调 `_prey_alive()` **全图查询** —— 那是**上帝视角信息**
   （猫并没有看见猎物死），且会改写 T023/T024 已有的"失视 → SEARCH"语义。**撤回**，一律走既有时序（`SEARCH` → 超时 → `EXPLORE`）。
   规格 §1.4 相应改为"不特殊处理"。
4. **`AnimalBody.ai_enabled` 不能当"暂停开关"**（再次踩到，T024 已记）：实验里想临时停 AI → 组件被释放/重建 + 旧引用失效。
5. **`ACT` 枚举只能追加**：`run_t021_capture.gd` 的 A 段断言把前 5 个值的序号锁死（`IDLE=0…DEAD=4`），`ATTACKING` 必须追加在末尾。
6. **`ResourcePoint.new()` 没有碰撞体** → 交互检测找不到它（F2 一开始 `try_interact()` 无效）；夹具必须用 `resource_point.tscn` 实例。
7. **套件里别在断言参数里重复调被测函数**：`_assert("x", str(f()), f())` 会**调用两次**（第一次成功、第二次被拒 → 假失败）。
   一律先取变量；`died`/`changed` 这类计数**必须往数组 append**（GDScript lambda **按值捕获**局部变量，计数器不会变）。
8. **后台 `Start-Process` 捕获这次完全没有输出、进程立刻结束**（log/err 都是 0 字节）；改用**同步执行**一次成功。
   后续取景建议直接同步跑（命令已写进 `Docs/Commands.md` §2.21）。
