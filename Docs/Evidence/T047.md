## 3. 人造极端姿态（找边界；轴由链末端世界位移判定，不盲猜）

轴判定（`t047b`）：对每条腿根分别绕本地 X/Y/Z 转 45°，比较链末端世界位移；Y 向位移最大者视为"侧向外展"。左右侧 roll 不同，选中轴也不同（R 走 Z、L 走 X），已在脚本里注明。

## 5. 一次最小修复尝试（**结论：无效，已回退**）

`Tools/Blender/t047e_fix_weights.py`：对四条腿根（`Bone.011/015/019/023`）与躯干（`Bone`、`Bone.001/002`）做 `vertex_group_smooth`（factor 0.5 / repeat 2 / expand 0.35），再 **限 4 → 归一**（顺序错了会留下 408 个"和≠1"的顶点，已修正）。

| 指标（动画极值帧） | `SM_Cat_005`（原） | 平滑后（`SM_Cat_006`，未发货） |
|---|---|---|
| Idle 塌陷/拉丝 | 4 / 0（min 0.418） | **0 / 2**（min 0.628） |
| Run 塌陷/拉丝 | 236 / 120（min 0.067） | **248 / 95**（min 0.072） |
| Walk 塌陷/拉丝 | 182 / 159（min 0.075） | **183 / 136**（min **0.0095**） |

- 权重统计仍干净（`zero=0`、`sum_dev=0`、`max_influences=4`）。
- **但形变几乎没改善，Walk 的最小面积比还变差**（0.075 → 0.0095）。
- 判定：**塌陷由拓扑（折痕处没有支撑环线）主导，权重平滑解决不了**。`SM_Cat_006.glb` 已删除，资产保持 `sm_cat_005`，`run_art02_cat` 基线不动。

## 6. 结论与可选项（**需负责人选**）

| 方案 | 做法 | 代价 |
|---|---|---|
| **A 拓扑级返工** | 在肩/髋折痕处加 1–2 圈支撑环线（`Bone.011/015/019/023` 根部），再重刷/平滑权重并重烘 UV（因为加线会破坏原 UV） | 大：等于重做该资产的一段，且要重跑 T045/T046 取证 + 全量回归 |
| **B 换源** | 换带合格拓扑/权重的猫资产（`cat_fripouille` 是扫描类单块网格，折痕先天不足） | 需授权采购/自备；之后 T045 起整条链重走 |
| **C 接受并记录** | 写进 `ART_ASSET_SPEC` 已知缺陷；用观距/相机高度缓解（第三人称 1.5–8 m、视角偏高，折痕多在腿根内侧） | 0 返工；近战/镜头贴身时可见 |
| **D 步态降幅**（可选缓解，不治本） | 在 `art16_cat_gait.py` 里降低 `lift`/`sink` 与摆幅，把腿根峰值从 ~100° 压到 ~70°，折痕塌陷随之减少 | 步幅变小、跑动观感变弱；需重跑步态校验 |

**本轮不擅自选 A/B/D**：三者都会改资产或动画，属需要授权的范围。

## 7. 边界与未验证

1. 形变代理指标是**逐三角面积比**，对细长三角敏感；已同时给最小/分位与渲染判读，不单看数字。
2. 未在 Godot 里逐帧采样（Blender 的 depsgraph 求值与引擎 skinning 同源同数据，但未做引擎侧交叉验证）。
3. 未测**动画混合/淡入**（`AnimalBody` 的 Idle↔Walk↔Run 0.10–0.18 s 交叉淡入）下的瞬时形变。
4. 未评估**观距**影响（判读按 1.2 m 近景；游戏实际第三人称 1.5–8 m，需视觉复核是否可见）。
5. 本轮**未改任何资产/代码**：`sm_cat_005` 仍是现役，`run_art02_cat` 72/72 基线不变。
