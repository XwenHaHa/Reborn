## 2. 环境音（自有合成）

`python Tools/make_audio_t056.py --out Game/Reborn/assets/audio`（44.1 kHz / 16-bit / 单声道）：

```
AMBIENT|creek_loop.wav|bytes=352844|dur=4.000
AMBIENT|wind_loop.wav|bytes=529244|dur=6.000
AMBIENT|done
```

循环做法：合成阶段用**整数频率**的周期性涌动 + 首尾**交叉淡化**；运行时 `AudioStreamWAV.loop_mode = LOOP_FORWARD`、`loop_end = 帧数`（导入器默认 `LOOP_DISABLED`，不设会播完就停）。

## 6. 过程中修正的错误（如实记录）

1. **首轮全量批 3 套红 + 1 套 INVALID**：`--script` 运行方式下 `main_entry.gd` 里**直接写 autoload 单例名**（`SubtitleDirector.bind_player(...)`）在**编译期**就失败 —— `Compile Error: Identifier not found: SubtitleDirector`，连带 `run_art05_settings` / `run_art08_board_contract` 红、`run_art09_species_layout` 静默 30 s 判 INVALID。改为 `get_node_or_null("/root/SubtitleDirector")` + `has_method()` 后四套全绿，再跑全量 61 套通过。**这是本轮最值得记的一条**：autoload 单例名在脚本直译模式下不可靠。

3. **`Edit` 行号漂移**：给 `ambience_director.gd` 插 `players()` 时插进了 `bind_level()` 循环体中间，读回后整段重写修复。
