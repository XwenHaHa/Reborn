## 1. 缺口与改动

开工前：`MouseAI` 的 `FLEE` **从不设 `want_sprint`** ⇒ 逃跑按 `walk` 1.1 m/s 跑、播 `Walk`；`Run`（3.0 m/s）只有玩家操作时才会用到。**"逃跑"这个状态没有对应的高速表现**。

`scripts/ai/mouse_ai.gd` 改动（3 处，均带注释）：

| 位置 | 改动 |
|---|---|
| 导出参数 | 新增 `@export var flee_sprint: bool = true`（**数据开关**，可回退） |
| `_step()` 开头 | 每帧 `body.want_sprint = false`（冲刺只属于逃跑，逃完立刻回落） |
| `_step_flee()` 推进前 | `body.want_sprint = flee_sprint` 后再 `_advance_along_path()` |
| `_step()` HIDDEN 分支 + `_enter_hidden()` | `body.velocity = Vector3.ZERO`（**到达即站定**） |

理由（`_enter_hidden` 注释原文）：冲刺 3.0 m/s 靠摩擦减速会滑出 ~0.2 m，会让 T020/T026 的"躲藏中不位移"失真（实测 0.2111 / 0.0710 m）。

**没有改** `AnimalBody` 的切换判据（`want_sprint && speed > walk×1.15`），也没有改任何动画资产。

## 5. 边界与未验证

1. **逃跑速度 3.0 是否合适**属平衡决策（T029/U01）；本任务只保证"逃跑不比走慢、且表现与之匹配"。体力耗尽后会自动转回走速（既有双门控），该回落路径未单独断言。
2. 冲刺噪声更大（`noise_loudness_sprint = 1.0` vs walk 0.5）——猫的听觉距离会变长，这属于 T020/T024 的既有感知模型，**未测其对追猎平衡的影响**。
3. 未测**真实玩家手感**（操控鼠逃跑时的输入延迟/镜头），也未做 U01 真人试玩。
4. `Eat` 段形变（T051）未动；T047 的猫肩/髋折痕仍未决。
