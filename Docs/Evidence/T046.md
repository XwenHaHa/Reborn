## 3. 拉伸位置 = 头部（不是尾巴）

- 骨骼链 `Bone → .001 → .002 → .003 → .004 → .004_end` 沿 **+X** 延伸到 x≈7.5；另一条链（`.005 … .010_end`）沿 **−X** 到 x≈−9.4；四条腿链末端都在 z≈0.15（地面）。
- `MAT_Cat_Detail`（眼球/胡须）的面全部落在 **x∈[6.08, 6.82]** ⇒ **+X 端是头**，`Bone.004`（x 4.19–6.98）就是**头/面部**；`Bone.010` 那端是尾。
- 因此 545 个 `>4×` 的拉伸面 = **面部**（占头部面数 13.6%），与 T045 视觉判读「面部五官贴图偏平、像直接涂上去」**互相印证**。

### 7.4 踩坑（写进脚本注释）

1. **fps 必须在导入前设成 30**：glTF 导入按场景 fps 把秒换成帧。先导入再改 fps 只会改导出换算，Run 从 0.208 → 0.167 → 0.133 s，直接把 `anim_run_length`（>0.2 s）判红。
2. **删 UV 层要按名字重新取**：`me.uv_layers.remove(old_layer)` 用旧的 Python 包装会报 `Texture layer '…' not found`（层集合已重排）。
3. 烘焙目标图节点的 `select`/`active` 状态决定 bake 写哪张图；DIFFUSE 必须关掉 direct/indirect 只留 color，否则会把光照烘进贴图。

2. 未做**UV 重叠**检测（重叠对烘焙贴图有害，但本次贴图是作者手绘/烘焙好的，重叠无法从几何反推）。
3. 未检查**骨骼权重**（T047）与**动画形变**下的拉伸（需在姿态下采样）。
4. Blender 3.3.1 的 FBX 源有 3 个网格（`eye2`/`eye2.001`/`high_poly`），脚本取面数最多的网格分析；GLB 已合并为单一 `CAT_BODY_001`，故 GLB 结论覆盖全身。
