## 1. 实现（生产改动清单）

| 文件 | 改动 |
|---|---|
| `scripts/data/species_config.gd` | 新 `Population` 组：`region_capacity / region_initial / region_recover_interval`；`validate_config()` 加三条校验（capacity ≥ 0、initial ∈ [0, capacity]、interval ≥ 0 有限） |

| `resources/species/cat.tres` | `1 / 1 / 0.0`（"猫容量1、初始1，原型不自动增长"） |
| `autoload/world_director.gd` | **纯加法**账本节：`region_records/region_active_bodies/_region_rects/_region_initials`、`init_region_population() / region_ids() / region_total() / region_capacity() / region_population_totals() / region_active_count() / region_id_at() / register_region_body() / unregister_region_body() / region_population_advance_to() / region_population_snapshot() / restore_region_population()`、`_deduct_region_for_capture()`；`report_capture` 幂等门内加一行扣账；`_process` 在 `world_time += delta` 后加一行恢复驱动；`reset_for_new_game()` 追加账本归零 |
| `scripts/world/ecology_spawner.gd` | 两处接线：`_spawn_one` 落点反查区域后 `register_region_body`（账本未初始化/区外返回 false 安静跳过）；`clear()` 逐身体 `unregister_region_body` |
| `scripts/core/main_entry.gd` | `_ready` 里 `_build_level()` 之后、`_build_ecology()` 之前调 `_init_region_population()`（新私有方法，调 `wd.call("init_region_population", _configs)`） |

**契约要点**（规格 §3 D1～D10）：

- **账本**：每 `level_regions` 区域 × 物种一条 TD §3 `RegionRecord`，纯数据、无 Node 引用；
  区域矩形从标记中心 ± 子 `Volume/Shape` BoxShape3D 半尺寸**只读推导**（生产代码不碰生成器脚本）。
- **恢复只吃 `world_time`**：`region_population_advance_to()` 镜像 `ResourcePoint.advance_to`
  ——多周期一次结算（`periods = floor((t−next)/interval)+1`、`gained = min(periods, capacity−total)`）、
  夹紧容量、满容量清零 `next_recover_at`、有空额才排期 `t+interval`；驱动在 `_process`（门闩时时间不走 → 天然冻结）。
- **捕获只扣一次**：扣账在 `report_capture` 的 `captured_target_ids` 幂等门内；
  扣账同时把受害者移出活动登记（结构性防重复扣）；未登记个体区域账不动（既有套件夹具零影响）。
- **快照/重建**：数量与 `next_recover_at` 从快照恢复；**容量与恢复间隔是配置数据、不从快照恢复**；
  未知区域/物种跳过、负数钳 0、超容量钳容量、非有限整条回初始；返回 `{restored, skipped, repaired}` 修复报告。
- **零新信号**：`capture_reported` 签名零改动；区域语义经账本查询暴露（TD §4 的 region 载荷信号面待有消费者再议）。
- **死亡不扣账**：TD §3 明文（"实例化/销毁表现不改变它"）——只有捕获扣；见 §8 待负责人怪癖。
