### 2.1 冻结逐项（B 段，真实等待 5 s）

`Input.action_press(move_forward/sprint)` 后 `await create_timer(5.0, true)`（真实等待 ≥ 4,900 ms），逐项断言**一字不变**：

- 世界时间：`world_time`、`sim_delta`；
- 资源点：`units`、`next_refill_at`（夹具预先设 `next_refill_at = t0 + 0.1`）；
- 区域种群：`total`、`next_recover_at`（夹具预先设 `next_recover_at = t0 + 0.1`）；
- NPC：全部 transform；
- 玩家：transform、velocity；
- 生存：health/hunger/thirst/stamina；
- 脚步计数；
- 主档字节与 `revision`。

同时断言 `get_tree().paused == true`、`WorldDirector.time_advancing == false`、玩家按移动/疾跑键位移为 0。

### 2.2 恢复还原（C 段）

`resume_game()` 后：暂停层隐藏、树恢复、门闩打开、字段不跳变；再等 0.6 s，`world_time` 前进、资源恢复、区域恢复、饥饿下降、按住前进键位置变化、仍存活且控制权在。

### 2.3 主动结束 = 正常死亡（F 段）

确认后：

- `settle_count + 1`、`lifecycle.state = selecting`、`player = null`、`spawn_count` 不变（**不重生**）；
- 档案 +1，`end_reason = died`、`damage_reason = player_quit`；
- 最后事件 `life_end`；
- 结算页逐字含「死亡（player_quit）」（`life_settle_panel.summary_text()` 为 `结束原因：死亡（player_quit）`）；
- `pending_settlement_life_id` 写入后由结算呈现清空；
- 档 `revision` 至少 +2（`settle_shown` → `death`），最终 `saved_reason = "death"`；
- 存档存在且无 `current_life`（**不清档**）；菜单可见、状态行隐藏；
- `selecting` 状态拒绝 `open_pause()`；
- `dismiss_settle()` 后可选猫重生且 `life_id` 变化（**重生仍由玩家在结算后触发**）。

### 2.4 暂停不入档（A/E 段）

- `open_pause()` 前后主档字节相同、`revision` 不变（A17/A18）；
- 确认层打开 1 s 不写盘；取消后档案 0、仍暂停、仍存活（E 段）。

### 2.5 Esc 优先级（D 段）

- 结算页呈现 → `handle_escape()` 返回 false；
- `NewGameConfirm` 打开 → 返回 false、不暂停；
- `EndLifeConfirm` 打开 → 只取消确认、仍暂停；
- 暂停中 → 恢复；
- `ALIVE` → 暂停；
- 真实 `InputEventKey KEY_ESCAPE` 经 `Input.parse_input_event` 在暂停中由 `PauseMenu`（ALWAYS）恢复；
- `InputEventAction("pause")` 经 `_unhandled_input` 能打开暂停。

### 2.6 树序（G 段）

断言 `Hud < PauseMenu < EndLifeConfirm < MainMenu < LifeStatus < NewGameConfirm < LifeSettlePanel`，其中：

- `PauseMenu` 在 `Hud` 之上；
- `EndLifeConfirm` 在 `PauseMenu` 之上；
- 两者都在 `LifeSettlePanel` 之下（结算页仍最上）。

既有 `MainMenu < LifeStatus < NewGameConfirm < LifeSettlePanel` 与 T033 解锁集语义（`build([])` 全解锁 / `set_unlocked([])` 全锁）、菜单可见时状态行隐藏，全部复证不变。
