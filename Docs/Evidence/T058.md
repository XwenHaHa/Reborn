## 4. 过程中修正的错误（如实记录）

1. **判据口径错（2 条假红）**：`F_point_idempotent` / `F_point_refuse_no_settle` 把世界时间跟常量 `T0` 比，
   但 `await physics_frame` 期间 `WorldDirector._process` 会按真实 delta 推进世界时间 → 差 ~16 ms 假红。
   改成**调用前后快照**比对（并顺带把 `A_eval_no_side_effect`、`B_time_plus_60`、`B_world_time_written`
   也改成快照口径）。**是判据错，不是生产缺陷**（`rest()` 的 `+60` 本身逐位正确）。
2. **GUI exe 抓不到 stdout**：直接用 `Godot_v4.7.2-stable_win64.exe`（GUI 子系统）跑 `--headless --script`
   时 PowerShell 的 `*>` / 管道拿到 0 字节，`exit=0` 不可信。**统一改用 `Tools/CaptureRun.ps1`**
   （CreateProcessW + `STARTF_USESTDHANDLES` 重定向到日志文件），与负责人"不许弹窗"的要求一致。
3. **`ambient_light_energy` 无效的连带问题**：见 `Docs/Evidence/T057.md` §8（T058 的时间快进会跨昼夜边界，
   所以 G 组直接复用 T057 修好后的纯函数采样）。
