# 可重复验收用例 v0.2（Godot 4）

> **v0.2（2026-10-13）**：引擎由 UE5 改为 **Godot 4.7.2 + GDScript**。用例 ID 与验收意图保持不变，**操作步骤与通过条件已改写为 Godot 说法**。
> 所有用例当前仍**均未执行**（E 系列未跑）。每次记录任务号、引擎版本、场景、参数版本、步骤、预期/实际、PASS/FAIL/NOT-RUN、日志路径。

**新的验收基础设施**：Godot 可用 `--headless` 无头运行 + 脚本断言，因此**大量用例可从"人工点击观察"升级为"可自动判定的数据断言"**。这是本次切换带来的最大测试能力提升。

```powershell
& '<godot_console.exe>' --headless --path '<proj>' --script 'res://tests/test_xxx.gd'
```

- 退出码 0 = 通过；非 0 = 失败。
- **必须加 `--quit-after <N>`** 防止挂死。
- 输出约定：每条断言打一行 `ASSERT|<id>|<expected>|<actual>|<PASS|FAIL>`，便于机器解析。

> **视觉部分例外**：画面比例、形变、HUD 遮挡等仍需图像判断，当前 vision 服务 403 → **记 NOT-RUN / awaiting-review，不得编造画面判断**。数据断言不受影响。
