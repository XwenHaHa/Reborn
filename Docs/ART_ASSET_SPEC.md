# ART_ASSET_SPEC —— 正式资产规格（Reference Lock）

版本 1.1（2026-11-09）｜配套：`Docs/ART_ASSET_AUDIT.md`、`references/ART_STYLE_GUIDE.md`、`references/reference_manifest.json`｜T044 起：§1.5 新增命名/来源集中规则，§2 面数预算改为**本机实测**（`Docs/Evidence/T044.md`）。

## 0. 总则

1. **先有参考，再建模**：`reference_pending → reference_confirmed → modeling → review → approved`。
   参考未确认前**不得**开展正式建模（`modeling3.md`/`modeling4.md` §五）。
2. **批准的参考只读**：`references/` 内的文件不得被覆盖；改外形/风格必须写 `Docs/ART_ASSET_CHANGELOG.md` 并说明原因。
3. **禁止用"加面数 / 改颜色 / 打灯"代替形体改进**；每轮返工必须列出具体缺陷 + 新截图。
4. **关键角色（猫、鼠）的最终批准需要负责人确认**（agent 只能提交 `review` 结论，不能自行 `approved`）。
5. 参考文件与正式游戏资产**物理隔离**：`references/**` 不进 `Game/Reborn/`；下载/解包一律落在 `references/**`。

## 1. 通用技术契约（沿用已实测数据）

| 项 | 约定 | 依据 |
|---|---|---|
| 单位/尺度 | 米；Blender `+Y` 朝前、`+Z` 朝上 → glTF/Godot 内为 `-Z` 朝前 | `Docs/BlenderPipeline.md`（T005 实测） |
| 精度 | 导出 GLB（`export_yup=True, export_apply=True`） | T005/T006/ART01/ART02 实测 |
| 材质槽 | 动物 ≤2、环境模块 ≤2；贴图 ≤2048²；glTF baseColor 线性 → Godot albedo 为 sRGB 编码 | ART01/ART02 实测 |
| 碰撞 | **`.glb` 只带视觉**；碰撞在 Godot 侧用简单形状显式建（Box/Capsule），不做三角面复杂碰撞 | T005 约定 |
| 命名 | 资产 `CAT_BODY_001` / `ENV_BOULDER_001` …；文件 `SK_*.glb`（含骨骼）/ `SM_*.glb`（静态） | `Docs/BlenderPipeline.md` §命名 |
| 版本 | 每轮返工存新 `.blend`，不覆盖上一版 | ART01/ART02 实践 |
| 导出可复现 | `.blend` 非逐字节可复现，`.glb` 可复现 → 验收以 `.glb` + sha256 为准 | T005 实测 |

### 2.3 从实测推出的成本

| 量 | 720p 实测 | 1080p 实测 |
|---|---|---|
| 分辨率系数 | — | **×1.78**（6.695 / 3.751，像素填充主导） |
| 每件猫实例（8,376 tris / 4 draw） | **0.0042 ms** | **0.0097 ms** |
| 每件鼠实例（3,602 tris / 4 draw） | **0.00087 ms** | ≈0.002 ms |
| 每件巨石（≈15,000 prim / 0 额外 draw） | **0.0148 ms** | — |
| 每件草丛（≈8,960 prim / 0 额外 draw） | **0.0077 ms** | — |
| 每 draw call（由猫/鼠斜率拆出） | ≈**0.001 ms** | ≈0.0024 ms |
| 每万渲染三角形（角色类） | ≈0.010 ms | ≈0.019 ms |
| 每万渲染三角形（大覆盖面静态件） | ≈0.009 ms | — |

**两条结论（比面数更重要）**：
1. **几何量在本机不是瓶颈**：32 只猫（≈13 万渲染三角）只多 **0.13 ms**；64 块巨石（≈96 万）多 **0.83 ms**。真正的成本项是**屏幕覆盖率（填充/着色）与 draw call**，其次是骨骼皮肤的固定开销。
2. **分辨率是最大变量**：同一场景 1080p 比 720p 贵 **78%**。预算必须标明档位，否则数字没有意义。

### 2.4 预算表（可判定阈值）

| 层 | 预算 | 依据 |
|---|---|---|
| 目标帧预算 | 60 fps = 16.67 ms；**渲染 ≤ 11.67 ms（70%）** | 通用目标，留 30% 给逻辑/物理/波动 |
| 场景总增量 | **P6 新增资产合计 ≤ +2.0 ms @1080p 或 ≤ +40 draw call（先到者为准）** | 1080p 基线 6.70 ms → 余量 4.97 ms，取 40% |
| 角色单件 | ≤ **40k tris**、≤ **2 材质槽**、≤ **4 draw call**；同屏 ≤ 12 只 | 12 只 ≈ 0.12 ms @1080p（实测 0.0097/件） |
| 鼠单件 | ≤ **20k tris**、≤ 2 槽、≤ 4 draw | 同尺度下远低于阈值 |
| 环境单件 | ≤ **15k tris**、≤ 2 槽、≤ 2 draw；**屏幕占比 > 15% 的大件按 0.009 ms/万渲染三角 @720p 复核** | 巨石实测（0.0148 ms/件） |
| 装饰件 | 同类静态件必须共享材质并优先 MultiMesh/合批；**每多一个独立 draw call ≈ 0.001 ms @720p** | 实测 draw 斜率 |
| 贴图 | ≤ 2048²，材质槽 ≤ 2（沿用 v1.0 契约） | 未单独测带宽，按既有契约 |

> 与 v1.0 固定面数表的关系：v1.0 的 15k–40k（猫）等数字在新表里**全部落在实测余量内**（≥10×），因此降级为"**结构建议**"而不再是硬上限；**不允许为满足面数牺牲关键结构**（洞净空 0.24×0.30、耳/吻/爪轮廓）。
>
> 与 `tool_perf_probe.gd` 旧读数（2026-10-21：1.643 ms / 178k primitives / 53 draw @720p）的差异**已解释**：关卡此后新增 ART07 环境、ART13/ART14/ART16 角色与展板、SSAO 0.75、HDRI 天空球与阴影修正，primitive 与 draw call 翻倍，帧耗时随之 ×2.3；两次都是真机读数，不是矛盾。

## 3. 评分与验收门槛（`modeling4.md` §六）

| 维度 | 分值 | 判定要点 |

## 5. Reference Lock 状态机（强制）

```
reference_pending ──(人工/授权下载 + 网格检查 + 许可核对)──► reference_confirmed
      │                                                          │
```

规则细节：
- `reference_confirmed` 需要同时满足：① 许可允许**商用+修改+随游戏分发**；② 真实网格已**打开检查**（拓扑/UV/尺寸/朝向）；③ 在 manifest 里记录 sha256 与来源 URL。
- `review` 阶段必须附带：多角度截图、`vision.js` 判读原文、与参考的同角度对比、Godot 集成断言结果。
- `approved` 只能由负责人确认；agent 不得自行置位。
