# T053 环境模块生产

## 1. 目标与不做

**目标**（开发计划 :221）：**环境模块生产** —— 石块、树根/洞口、矮墙等 3～5 个模块做成**可复用、口径可复测**的在役资产；**不把碰撞堵住鼠路**。

开工前的实际状态（不是"从零做资产"）：
- 石块 / 树根洞口 / 围栏 / 矮墙 / 转角料石 / 门垛立柱 / 树根屏障 7 个模块的 GLB **已在 ART03 阶段接入关卡**（`l_courtyard.tscn` 已实例化）；
- 但这些数字**散落在 ART03 各次证据里**，没有任何一处能在改动后一次性复测：改一个 GLB，没有任何红灯会亮；
- `ART_ASSET_SPEC.md` §4.3 写着「当前状态：BoxMesh 拼的屏障，**没有洞**」、§4.4 写着「当前状态：BoxMesh」，都是**过时描述**；
- "不堵鼠路"此前只有 `run_t011_greybox` 的**几何常量**断言（洞口宽 0.24 / 高 0.30、鼠站立尺寸能塞进去），**没有运行时物理证据**。

所以本任务交付的是：**把模块口径与洞口通行变成可重复断言**，并校正与实测冲突的规格数字。

**不做**：
- 不重做已合格的模块几何（围栏 1,244 / 矮墙 663 / 料石 176 / 门垛 28 tris 都在预算内）。
- 不缩放巨石：见 D2。
- 不动 `HOLE_W/HOLE_H` 常量与洞口位置（`tool_make_courtyard.gd` 与 `run_t011_greybox` 的契约）。
- 不做地表贴图选型、不做昼夜光照（T057）、不做包内复验。

## 2. 决策

- **D1 口径一次测全（8 个模块 × 6 条）**：面数预算、材质槽数、尺寸、原点落地（`min_y≈0`）、**GLB 内无碰撞**（碰撞必须由关卡显式建，否则同一件东西两处碰撞、改不动）。尺寸把本次实测值当**回归基线**，漂移 >12 mm 即红灯。
- **D2 巨石尺寸按实测校正，不缩放资产**：源件是 CC0 **真实比例扫描**（`art05_boulder_001.py` 头注已记录"米制，无需缩放"），关卡 `CreekBoulder` 的 `BoxShape3D` 与网格 AABB 逐轴 1:1。spec 里「≈1.2 m ±20%」是灰盒占位时代的目标值，与"实物石头 1.83 m"冲突——**改规格而不是改石头**：缩到 1.2 m 会让石头与地形比例失真，且不解决任何玩法问题（记录旧值/新值/理由见 §3）。
- **D3 "鼠路"用物理胶囊证明，不用几何常量推断**：在洞口中心放**真实胶囊**做 `intersect_shape`——鼠（r 0.06 / 高 0.18）必须 **0 命中**，猫（r 0.16 / 高 0.48）必须 **≥1 命中**。几何常量只能证明"缝够宽"，证明不了"这一处真能走过去"。
- **D4 净空基准取屏障底面，不取顶面**：屏障 `y∈[0.10,0.60]`、门楣底面 `0.40` ⇒ 净高 `0.30`（与 `run_t011_greybox` 的 `GROUND_TOP` 口径一致）。第一版用顶面算成 `−0.20`，是**夹具错**。

## 3. 产物

- `tests/run_t053_env_modules.gd`（新，**57 条**）：A 组 8 模块 × 6 条、B 组巨石视觉/碰撞一致、C 组洞口净空 + 鼠/猫胶囊。
- `Docs/ART_ASSET_SPEC.md`：§4.3 当前状态（真实洞口 + 运行时实测）、§4.4 尺寸（1.2 m → 实测 1.269×1.004×1.829 m，含更正理由）、§4.4 面数/材质/当前状态。
- `Docs/Evidence/T053.md`。

**没有改任何资产或关卡**：所有模块都已接入且达标；本任务产出的是判定与规格，不是新几何。

## 4. 验收

1. 8 个模块：面数在预算内、材质槽 ≤ 规格、尺寸与基线一致（±12 mm）、`min_y ≈ 0`、GLB 内 0 个碰撞节点。
2. `CreekBoulder`：`BoxShape3D.size` == 网格世界 AABB（±2 mm）。
3. 洞口：净宽 ≥ 0.24 m、净高 ≥ 0.30 m；鼠胶囊 0 命中、猫胶囊 ≥ 1 命中。
4. 全量 headless 套件 0 失败、0 INVALID、`visible_hits=0`。

## 5. 失败恢复

- **尺寸断言红**：先确认是不是导入量化（±12 mm 内算通过），再查是不是有人改了资产或缩放。
- **鼠胶囊被挡**：逐项排查——洞口被装饰件占住（`RootHoleStump*` 应有 0 碰撞）、门楣压低、地面抬高；**不要**靠调 `HOLE_W/HOLE_H` 常量蒙过去（会连带 `run_t011_greybox` 的灰盒契约）。
- **猫胶囊也能过**：说明洞口太宽，"猫不能进洞"的玩法分离失效——这是设计约束，需负责人确认改哪边。
- **巨石视觉/碰撞不一致**：先量网格 AABB，再改 `BoxShape3D.size`；不要给 GLB 加碰撞（会与关卡重复）。

## 6. 挂账（不在 T053）

- 其余地形模块（草、土墩、棚顶）不在本任务 3～5 个模块范围内。
- 包内复验（T043 打包链未重跑）。
- 正式美术 approved 仍需负责人确认。
