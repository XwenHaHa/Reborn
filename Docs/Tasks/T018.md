## 1. 目标

1. **状态可见**：Health / Hunger / Thirst / Stamina 四项当前值与上限（`x / 上限`）。
2. **低值警告可见**：`Hunger/Thirst ≤ 25`（T015 的 `low_stat_threshold`）时给出明确警告文本；恢复后消失。
3. **交互提示可见**：当前唯一交互目标（T016）的**动作名 + 目标 ID + 进度**；无目标时不显示。
4. **调试数值不混入**：正式 HUD 文本里**不得**出现 `PARAMS|` / `MOV|` / `nav_points` / `nav_layer` / `step_climb` /
   `probe` / `headroom` / `wish=` / `frame=` / `collision_debug` / `F1=` 这类调试内容（逐条断言）。
5. **只观察不改状态**：HUD 不修改 `SurvivalState`、不动资源账本、不调目标的 `commit_interaction`；
   绑定前后状态快照必须一致。
6. **信号驱动**：状态/警告/交互提示都由信号触发更新；**唯一**每帧读取的是"交互进度条"（连续量），
   在注释与规格里写明（避免"UI 每帧写游戏状态"）。

## 4. 决策（D1~D6）

- **D1 位置**：`Control` 全屏 + 左下角一列文本（不遮挡准星中心）；`mouse_filter = MOUSE_FILTER_IGNORE`（不吃输入）。
- **D2 文本形式**：先用 `Label` 文本（不做血条控件）——2～4h 任务里"可见"以**文本 + 可见性**为准；
  血条/图标样式属后续 UI 打磨（记录在 §9）。
- **D3 单位**：`Parameters.md` 的生存指标是无量纲 0～100 → 直接显示 `85 / 100`；距离类数值（将来）按厘米显示（`TechnicalDesign` 第 14 行）。
- **D4 警告措辞**：饥饿用「饥饿」，水分用「缺水」，两者同时用「饥饿 + 缺水」；不使用英文键名（界面中文）。
- **D5 交互提示**：`eat` → 「进食」、`drink` → 「饮水」、其它用 `action_id` 原样；
  文本形如 `[进食] seed_food_1  33%`；无目标时整行隐藏（`visible = false`）。
- **D6 唯一每帧读取**：`_process()` 只刷新交互进度百分比；状态、警告、目标切换全部走信号。

## 5. 接口（本任务新增）

```gdscript
# scripts/ui/hud.gd
class_name PlayerHud extends Control

signal bound(species_id: StringName)

@export var player_path: NodePath = NodePath("")

func bind_player(body: AnimalBody) -> void   # 连接信号并立刻刷新一次
func unbind() -> void                        # 断开信号（换物种/死亡时用）
func is_bound() -> bool
func hud_text() -> String                    # HUD 当前显示的全部文本（断言用）
func status_lines() -> PackedStringArray     # 状态行（四项指标）
func warning_text() -> String                # 低值警告（无则 ""）
func interaction_text() -> String            # 交互提示（无则 ""）
func interaction_visible() -> bool
func refresh() -> void                       # 手动刷新（绑定/测试用）
```

## 6. 断言（`tests/run_t018_hud.gd`，目标 ≈70 条）

- **A 场景与接口**：`hud.tscn` 存在；`PlayerHud` 是 `Control`；根节点 `mouse_filter == MOUSE_FILTER_IGNORE`；
  默认 `visible == true`；三个子 `Label` 都在。
- **B 状态显示**：绑定后 `hud_text()` 含四项指标与上限（`100 / 100`）；`apply_damage(30)` 后 HUD 的 health 变成 `70 / 100`
  （**信号驱动**，不手动 refresh）；`restore_hunger(10)` 后 hunger 更新。
- **C 低值警告**：把 hunger 设到 20 → 警告文本出现「饥饿」；恢复到 80 → 警告消失（`warning_changed` 驱动）；
  thirst 20 → 「缺水」；两者都低 → 「饥饿 + 缺水」。
- **D 交互提示**：范围内放一个 SEED 食物点 → 提示含「进食」与目标 ID；移出范围 → `interaction_visible() == false`；
  水点 → 「饮水」。
- **E 交互进度**：`press_interact()` + 合成 `tick` 到的一半 → 文本出现百分比且随进度变化；提交后提示回到无目标态。
- **F 调试数值不混入**：`hud_text()` **不含** `PARAMS|` / `MOV|` / `nav_points` / `nav_layer` / `step_climb` / `probe` /
  `headroom` / `wish=` / `frame=` / `collision_debug` / `F1=` / `Debug`（逐条断言，共 12 条）。
- **G 只观察不改状态**：绑定前记录 `survival.state.to_dictionary()` 与资源点 `to_record()`，
  绑定 + 刷新 + 触发一次信号后两者**完全不变**；`hud` 不持有任何写接口（静态：HUD 脚本不含 `restore_` / `apply_damage` / `commit_interaction` 调用）。
- **H 集成**：`l_courtyard.tscn` 上放玩家 + HUD → 场景里 0 个 `/debug/` 节点；HUD 挂在正式场景里 `visible == true`；
  绑定真实 `animal_body.tscn` 全流程；全量回归不退化。
