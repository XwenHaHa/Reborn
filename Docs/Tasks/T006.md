## 4. 参数（厘米 → 米，`Parameters.md`）

- 猫胶囊 `radius=0.16, height=0.48`；探针模型**站立总高目标 ≈ 0.44 m**、**体长 0.60 m**、**体宽 0.20 m**
  （与 T005 的米制链路一致，不追求动物外观）。
- 动画：**24 fps，帧 1 → 帧 25** = **1.000 s**；**帧 1 与帧 25 姿态完全相同**（循环闭合）。
- 骨骼（Blender 坐标，米）：`root`(0,0,0)→(0,0,0.08)；`spine`(0,−0.30,0.34)→(0,0.30,0.34)；
  `leg_front`(0,0.20,0.24)→(0,0.20,0)；`leg_back`(0,−0.20,0.24)→(0,−0.20,0)。
  层级：`root → spine → {leg_front, leg_back}`。
- **绑定方式：刚性权重**（每顶点对对应骨权重 1.0，手工指定）。
  理由：自动权重（Bone Heat）对分离几何体可能失败且不可复现；刚性绑定足以验证"骨骼→网格"往返。
  **代价**：看不到关节混合插值——属本任务已知限制，正式角色资产不得沿用。
- **约定（T005 实测）**：角色在 Blender 里**面朝 `+Y`** ⇒ 导入 Godot 后面朝 `−Z`（Godot 前方）。

## 6. 逐步实现

1. 复验 vision 工具可信性（已知答案探针图）。
2. Blender 脚本：空文件起步（**不删任何对象**）→ 建 3 个盒体 + 1 个骨架 → 合并网格 → 刚性顶点组
   → 建动作（帧 1/13/25 关键帧，首末一致）→ 存 `.blend` → **重开校验**（对象/骨骼/动作帧范围）
   → 导出 `.glb`（记录实际 kwargs，含 `export_skins`/`export_animations`）→ 打印 SHA256。
3. 复制到 `Game/Reborn/assets/tests/`，`--headless --import`，读回真实 `.import` 设置。
4. **先 dump 再断言**：用 `tool_dump_scene_tree.gd` 打印骨骼数/骨骼名/动画名/长度/循环模式/皮肤信息。
5. 写 `tests/run_t006_rig.gd` 断言（全部读引擎真实数据）：
   - 结构：`Skeleton3D` 4 根骨（名保留）、`AnimationPlayer` 有动作、`MeshInstance3D` 有 skin；
   - 尺寸：网格 AABB 三轴 ≈ 源尺寸（(0.20, 0.44, 0.60)，±1 cm）——与 T005 米制链路一致；
   - 骨骼静止位姿：`spine` / `leg_front` 的静止头位置符合 `(x,y,z)→(x,z,−y)`（±1 cm）；
   - 蒙皮：每个顶点权重和 ≈ 1.0，被使用的骨 ≤ 4；
   - 动画：**长度 ≈ 1.0 s**（±0.05）、`loop_mode` **记录实测值并断言**、轨道数 > 0；
   - **实际播放**：加入试验世界 → `play("Loop")` → 在 t=0 / 0.5 / 1.0 采样 `leg_front` 骨尖世界位置：
     t=0.5 与 t=0 的差值 **> 5 cm**（真的动了），t=1.0 与 t=0 的差值 **< 2 mm**（循环闭合）；
   - **无根运动**：播放期间 `Skeleton3D` 的 `global_position` 变化 < 1 mm；
   - **根骨不缩放**：`root` 骨的 `global_pose` 缩放 ≈ 1.0（±1e−3），`spine` 的平移动画只动骨、不动节点。
6. 视觉：`-- t006` 模式渲染 **t=0.0 与 t=0.5 两帧**（同一相机、同一光照），
   用 `vision.js` 检查：两帧四肢姿态是否明显不同、有无拉伸/爆点/碎裂、有无整体漂移。
7. 回归：T002 / T005 / T007 / 台阶探针全跑；若改了工具脚本，先 `--check-only`。
8. 打包复验（`RebornSelfTest.pck` 内跑 T006 断言）。
9. 写 `Docs/Evidence/T006.md`；更新 Tasks / Handoff / Environment / Bootstrap / TestCases。

## 8. 失败回退

- **允许 T006 阻塞**：静态占位可继续推进 P1～P5，**但不得据此启动正式骨骼批量生产**（AGENTS.md 明确）。

- Godot 侧失败：保留 `.import` 与引擎 stderr；不得用"手工改导入资源"绕过资产链验证。
- 视觉工具失败：视觉项记 **awaiting-review**，不编造画面判断。
- 不改产品规则、不改引擎路线。
