## 1. 目标

把一个**只用于开发/验证**的调试入口做出来，并把 T009～T012 攒下的两条移动遗留项收掉：

1. **调试入口场景**（`scenes/debug/debug_entry.tscn`）：实例化生态灰盒 `l_courtyard.tscn`，**可切换猫/鼠两种玩家**，
   可**显示碰撞形状**、可**显示导航路径**，屏幕上有一块**只属于调试的 HUD**（物种、姿态、速度、位置、地面/导航状态、按键图例）。
2. **移动参数可记录**：进入关卡时打印一次该物种的全部移动参数，并周期打印一行机器可读的 `MOV|` 记录
   （位置/速度/姿态/是否在地面/`climb.last_probe`），用于"记录移动参数与问题"。
3. **遗留项 ①（修）**：单级台阶抬升成功时会**水平瞬移 `radius_safe`（0.2 m）** —— 改成**只抬 y**，
   本帧水平推进交回 `move_and_slide()`；改完必须重跑 T008/T009/T010/T011/T012 全部断言。
4. **遗留项 ②（记录）**：猫跨 0.50 屏障在**导航层不可达**（T012 §9）—— 本任务**只记录**（是否加 `NavigationLink3D` 由负责人定），
   并在调试入口里把"猫沿导航走不到屏障顶"这件事可视化（路径显示）。

范围外（**本任务不做**）：正式 HUD 与调参页（T018）、AI/NPC（T019+）、录制视频（本环境无可用录制工具 → 如实记 NOT-RUN）、
跳跃链接、正式美术。

## 4. 决策

- **D1 调试入口与正式流程分离**：调试 HUD/路径可视化**只在** `scenes/debug/debug_entry.tscn` 里，
  `l_courtyard.tscn` / `main.tscn` **不得**含任何调试节点（断言守着：正式场景里 `debug_entry` 组件/HUD 数为 0）。
  依据：`TestCases.md` "调试数值不混入最终界面"（T018 会做正式 HUD）。
- **D2 输入用 InputMap 动作，不用裸键码**：新增 `debug_switch_cat`(F1)、`debug_switch_mouse`(F2)、
  `debug_toggle_collision`(F3)、`debug_toggle_path`(F4)、`debug_toggle_hud`(F5)。
  裸键码必须实测：`Esc=4194305`、`Shift=4194325`、`Ctrl=4194326` 已在 T001 核对 → 同族 `F1=4194332 … F5=4194336`；
  断言直接与引擎常量 `KEY_F1..KEY_F5` 对照（等于用引擎自己核对我们的数字）。
- **D3 碰撞显示用引擎开关**：`Viewport.debug_draw` 在 `DEBUG_DRAW_DISABLED` 与 `DEBUG_DRAW_COLLISION_SHAPES` 之间切；
  这是引擎自带的可视化，不自己画碰撞线。
- **D4 导航路径自己画**：T012 实测**运行时导航调试绘制不可见**，所以路径显示用 `ImmediateMesh` 线带
  逐帧取 `NavigationAgent3D.get_current_navigation_path()` 画出来（诚实标注：这是"我们自己画的路径线"，不是引擎调试视图）。
- **D5 遗留项 ① 的修法**（`Docs/Evidence/T009.md` §5.3 已写明建议）：`try_step_up()` 成功时
  **只把 y 设成落点高度**（不动 x/z）；`step_or_slide()` 成功抬升后**仍按本帧 motion 设置速度并调用 `move_and_slide()`**，
  不再把速度清零。判据：抬升那一帧的**水平位移 ≤ 该帧正常位移 + 0.05 m**（原来会 ≥0.2 m）。
- **D6 视频**：本环境**没有录制工具**（T001 能力清单里没有）→ "问题视频"记 **NOT-RUN**，改用
  **截图（HUD/碰撞/路径三态）+ `MOV|` 日志 + 量化断言**；不声称录了视频。

## 6. 断言（`tests/run_t013_debug_entry.gd`，目标 ≈60 条）

**A 场景与分离**：`debug_entry.tscn` 可加载、根为 `Node3D` 且挂了脚本；实例化后**关卡被实例化**、
存在 `Player`（`AnimalBody`）、相机 current；`l_courtyard.tscn` 与 `main.tscn` **不含**调试 HUD/路径节点（= 调试不混入正式场景）。

**B 输入映射**：`InputMap` 里有 5 个调试动作，且**键码与 `KEY_F1..KEY_F5` 一致**（引擎常量对照）。

**C 切换玩家**：`switch_species("Mouse")` → 身体物种为 `Mouse`、胶囊高 **0.18**、导航层 **1**、HUD 文本含 `Mouse`；
再切 `Cat` → **0.48**、层 **2**、HUD 含 `Cat`；两次切换都**位置有效**（在地面上、0 重叠、不穿墙）。

**D 显示开关**：碰撞显示开 → `viewport.debug_draw == DEBUG_DRAW_COLLISION_SHAPES`，关 → `DISABLED`；
路径显示开 → 路径节点可见且有 ≥2 个点（目标在同层可达），关 → 不可见（且不残留上一帧的线）；
HUD 开关同理。

**E 参数与记录**：`movement_parameters()` 的每个字段与当前 `*.tres` 一致（走/跑/蹲速度、跳跃速度、`max_step_height`、
胶囊半径/半高、相机偏移、FOV）；进入关卡时打印一次 `PARAMS|` 行；跑 N 帧后存在 `MOV|` 行且字段齐全。

**F 回归**：见 §7 的独立套件；并跑 T002/T005/T006/T007/T008/T009/T010/T011/T012 全绿；包内同跑。

## 7. 移动回归套件（`tests/run_t013_movement_regression.gd`，目标 ≈50 条）

一条命令跑完"移动相关"的关键量（把散在各套件里的移动判据集中复现一次）：

1. **平地三档**（猫 1.8/4.5/0.9、鼠 1.1/3.0/0.65 m/s）：60 帧位移与理论值对照（±8%）；
2. **台阶（遗留项 ① 的量化判据）**：猫上 12 cm / 鼠上 3 cm 台阶：
   - **仍能上**（y 增益 ≈ 台阶高，落点在地面上）；
   - **抬升那一帧的水平位移 ≤ 该帧正常位移 + 0.05 m**（修复前实测 ≥0.2 m，`Docs/Evidence/T009.md` §5.3）；
   - 20 cm（猫）/ 12 cm（鼠）仍**被挡**；
3. **跳跃**：猫跳净空 ≥0.50（照 T009 口径），鼠 `can_jump=false` 且按住跳跃 `max_up=0`；
4. **通道**：鼠过 24×30 洞、猫被挡（复用 T011 的车道，量终点 z）；
5. **斜坡**：25° 坡能上、0 空中帧、0 卡死；
6. **相机**：眼高 = 胶囊中心 + `camera_offset_z`（模型：轴为本地 +Y），蹲姿下降 = 2×`crouch_drop`。

> 这一套是**回归**，不是新功能：数值口径全部沿用 T009/T010/T011 已验收的阈值；差异只在于"台阶水平瞬移"这一条改成新判据。

## 9. 失败回退

- 若**只抬 y 后上不去台阶**：先记录逐帧 y/速度/`last_probe`；允许调**抬升后本帧的水平推进量**（必要时按台阶进深补一点），
  但**不允许**退回"瞬移到 `radius_safe`"；**不许放宽** T008/T009/T010 的阈值。
- 若**调试入口切换物种后身体异常**（卡住/重叠/掉出地面）：先查出生点与胶囊重建顺序（`queue_free()` + 等帧），
  再查 `make_camera_current`；**不许**用"跳过断言"收场。
- 若**路径画不出来**：先确认 `NavigationAgent3D` 的层与地图、目标点是否同层可达（T012 已给出判据）；
  画不出就如实记录（本任务不是导航任务）。
- 视频不可得 → 记 NOT-RUN，用截图 + 日志替代（D6）。

## 11. 完成说明：三处与开工规格不同（都因为实测）

1. **D3 的碰撞显示接口改了**。规格写的是 `Viewport.debug_draw = DEBUG_DRAW_COLLISION_SHAPES`，
   **该枚举成员在 4.7 不存在**（解析期报错）。实测：`Viewport.DEBUG_DRAW_*` 只有 0..4
   （DISABLED/UNSHADED/LIGHTING/OVERDRAW/WIREFRAME）、`PhysicsServer3D` **没有任何 debug 方法**，
   唯一相关开关是 `SceneTree.debug_collisions_hint`；而打开它之后**同机位两张截图逐字节相同**
   （MD5 `64DC75C7…`）→ 命令行运行下**看不见**。因此 F3 改为"打开引擎开关（编辑器调试运行下才有效果，
   本环境无法验证）**+ 自绘线框**（诚实标注不是引擎调试视图）"，并用开/关两张图的 MD5 差异证明自绘可见。
2. **遗留项 ② 的探针端点直线距离是 5.00 m**（z 21.5 → 16.5）。T012 证据里的"9.00 m"是另一对更宽的端点
   （z 23.5 → 14.5）；两者结论一致（鼠层穿洞口、猫层绕行不穿洞），这里只是端点更近。
3. **包内文本级断言会退化**：`.pck` 里场景不是可读文本（`FileAccess` 读到 0 字节）。已改成
   "不可读即通过 + 打印长度"，并把**主判据换成运行期结构判据**（实例化后无调试节点/无 CanvasLayer、
   根节点脚本路径 == `scripts/debug/debug_entry.gd`），避免"看起来过了其实没检"。

另：本任务执行中途发生过一次 `project.godot` 被外部写成极简版的事故（InputMap 全空、多个套件大面积失败），
先 `git checkout` 恢复、再等外部写手合并出正确版本、最后用输入断言验收 —— 全过程记录在
