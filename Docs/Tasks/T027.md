# T027 按玩家物种布置测试生态 —— 任务规格

> 计划出处：`轮生_Reborn_开发计划_v1.0.md` 第 154 行「T027 按玩家物种布置测试生态 | 4～8h | 前置 T021,T026 |
> **同一地图可测试猫捕鼠与鼠避猫**；**玩家不计入 NPC 数量**；**出生周围无即时攻击**」
> 日期口径：2026-10-24（顺序递增虚构日期）。状态：**done（本轮完成）**。

## 0. 一句话目标

给**同一张 `l_courtyard.tscn`** 装上"按玩家物种布置"的 NPC 生态：玩家是猫 → 场上只有鼠 NPC（可捕）；
玩家是鼠 → 场上只有猫 NPC（要躲）；**玩家本人不计入 NPC 计数**；**出生点周围既看不见也打不到玩家**（捕食者出生半径 > 它的视野半径）。
产物是一个可复用组件 `EcologySpawner` + 一个可玩入口 `ecology_entry.tscn` + 断言套件。

## 1. 范围

### 做
1. **新组件** `scripts/world/ecology_spawner.gd`（`class_name EcologySpawner extends Node3D`）：
   - **数据驱动、不写物种名**：候选物种是 `Array[SpeciesConfig]`；数量用 `count_per_species` + `count_overrides`（`species_id → int`）。
   - **按玩家物种布置**：`setup(player, origin)` 只生成**与玩家不同种**的 NPC；玩家换物种时 `setup()` 先 `clear()` 再重铺（不留旧 NPC）。
   - **出生安全**：每个 NPC 必须落在距 `origin` ≥ `min_distance_for(cfg)` 的位置；
     **`can_attack` 的物种用 `predator_min_distance`（14.0 m）**，其余用 `min_spawn_distance`（8.0 m）；
     两个值都**大于该物种的 `vision_range`**（猫 9.0 / 鼠 6.5）→ 出生瞬间**看不见**玩家。
     另加 NPC 之间的最小间距 `min_npc_separation`（2.0 m）。安全点找不到就**跳过并记录**，绝不硬塞。
   - **落点**：优先用组 `npc_spawn_points`（缺省回退 `spawn_points`，按 `metadata/species` 匹配）→ 再用绕该标记的**环上候选**（12 个角度 × `ring_radius`）；
     所有候选都要按**物种自己的导航层**吸附（用**带层**的 `map_get_path` trivial 查询，**不用层盲的 `map_get_closest_point`**），吸附误差 ≤ 0.60 m 才算可用。
   - **NPC 建成即开 AI**（`ai_enabled = true`）：鼠 NPC 走 T019/T020 的觅食/逃跑链，猫 NPC 走 T023/T024/T025 的巡游/追击/攻击链。
   - **计数口径**：`npc_count()` 只数**自己铺出去的** NPC（**玩家不计入**）；`npc_count_of(species_id)`、`npc_ids()`、`npc_bodies()`；
     `spawn_report()` 给每个 NPC 的 `species/position/distance/source` 与跳过原因。
2. **可玩入口** `scenes/debug/ecology_entry.tscn`：`debug_entry.tscn` 的同构场景 + `ecology_enabled = true`（+ `start_species` 可切）。
   **`debug_entry.tscn` 本身保持 `ecology_enabled = false`** → 既有 24 套断言套件与既有取景分支**完全不受影响**（零改动、零回归风险）。
3. **调试入口接线**（`scripts/debug/debug_entry.gd`）：
   - `@export var ecology_enabled: bool = false`；`@export var npc_count_per_species: int = 2` / `@export var predator_npc_count: int = 1`
     （按 `SpeciesConfig.can_attack` 分派，**不写物种名**）；
   - `_build_level()` 里建 `EcologySpawner` 挂到关卡下；`switch_species()` 末尾 `setup()`；`restart_round()` 重建关卡时自然重铺；
   - HUD 加 `eco:` 行（`on/player/npcs/prey/pred/min_dist/safe_min/skipped`）+ 查询接口 `ecology_line()` / `ecology_npc_count()` 供断言与试玩观察。
4. **断言套件** `tests/run_t027_ecology.gd`（A～E，目标 ≥ 90 条）。

### 不做（越界即停并解释）
- **区域 NPC 数量账本 / 恢复周期 / 读档重建** → T035（本轮只做"当下的活跃 NPC 计数"，不做区域总量与容量）。
- **正式启动链（`main.tscn`）接生态**：`main.tscn` 现在是"只挂试验世界"的占位启动；正式出生/选物种属 P4 的 `LifeCycle`（T030）→ 本轮只给**可玩入口场景**，并在 Handoff 写明。
- **NPC 出生点的正式布置**（各区域几个、有无巢穴）→ T027 只用"现有出生标记 + 环上候选"，不擅自改关卡几何（改关卡会牵动 T011/T012 的导航烘焙）。
- 视觉判读若服务不可用 → 如实记 NOT-VERIFIED。

## 3. 决策

| # | 决策 | 理由 |
| --- | --- | --- |
| D1 | 生态做成**独立组件** `EcologySpawner`，挂关卡下、由入口驱动 | 组件可被 P4 的正式出生链复用；不把生成逻辑塞进 `debug_entry` 的 `_ready` |
| D2 | **不改关卡几何、不重烤导航**；落点用"现有出生标记 + 环上候选 + 按层吸附" | 改 `l_courtyard.tscn` 会牵动 T011/T012 的导航烘焙与 24 套回归的几何前提，代价远超收益 |
| D3 | **可玩默认放在新场景** `ecology_entry.tscn`，`debug_entry.tscn` 保持关闭 | 既有 12 个套件/7 个取景分支都实例化 `debug_entry.tscn`；默认打开会改动它们的夹具语义（T019 的教训）→ **零回归风险** |
| D4 | 出生安全 = **距离规则 + 行为窗口**双证：`min_distance_for(cfg) > cfg.vision_range`（几何）且 4 s 内玩家**零伤害、零攻击启动、最近距离 ≥ 3 m**（行为） | "无即时攻击"要能客观验；只写"距离 ≥ 8 m"证明不了"打不到" |
| D5 | 捕食者半径**按 `can_attack` 分派**（14 m），不按物种名 | 项目铁律：能力差异走配置字段 |
| D6 | NPC 数量：猫 NPC 1 只、鼠 NPC 2 只（`count_overrides`），`max_npcs = 3` | 鼠玩家面对 1 只猫已有压力（P3 阶段门只要求"能说明同一地点的不同用途"）；3 只 NPC 也不会把 20 米场地占满 |
| D7 | `npc_count()` 只数**本组件铺出的** NPC；测试再用"关卡 `animal` 组数量 − 玩家"交叉核对 | "玩家不计入"必须可客观验，而不是自我声明 |

## 4. 验收断言（`tests/run_t027_ecology.gd`，目标 ≥ 90 项）

### A 数据与接口（≥ 16）
- A1 `EcologySpawner` 存在且关键接口齐全（`setup/clear/npc_count/npc_count_of/npc_ids/npc_bodies/spawn_report/min_distance_for/desired_count`）
- A2 入口默认值：`debug_entry.tscn` 的 `ecology_enabled == false`；`ecology_entry.tscn` 的 `== true`（两场景都实例化得出来）
- A3 关卡数据：`spawn_points` 里 `CatSpawn`/`MouseSpawn` 都在，且都带 `metadata/species`
- A4 `desired_count()`：默认 `count_per_species`；`count_overrides` 覆盖生效；`max_npcs` 截断
- A5 `min_distance_for()`：`can_attack` 的物种拿到 `predator_min_distance`，其余拿到 `min_spawn_distance`；**两者都 > 该物种 `vision_range`**
- A6 **静态检查**：`ecology_spawner.gd` 源码里**没有** `"Cat"`/`"Mouse"` 这类物种名字面量（差异全在资源里）

### B 按玩家物种布置（≥ 20）
- B1 玩家=猫：NPC **全是鼠**（`npc_count_of(cat) == 0`、`npc_count_of(mouse) == 2`）
- B2 玩家=鼠：NPC **全是猫**（`npc_count_of(mouse) == 0`、`npc_count_of(cat) == 1`）
- B3 每个 NPC：`species_config` 与报告的物种一致、`is_in_group("animal")`、存活、`ai_enabled == true`、是关卡的后代
- B4 每个 NPC 都**吸附在自己的导航层上**（按层的 trivial 路径查询，误差 ≤ 0.60 m）
- B5 **换物种重铺**：猫→鼠 后旧鼠 NPC 全部释放（实例失效/已出树），只剩猫 NPC；再切回猫只剩鼠 NPC
- B6 NPC 之间间距 ≥ `min_npc_separation`（实测最小值）

### C 玩家不计入 NPC 数量（≥ 12）
- C1 `npc_count()` 与 B1/B2 的期望一致，且 `npc_ids()` **不含**玩家实例 id
- C2 交叉核对：`npc_count() == 关卡 "animal" 组存活身体数 − 1（玩家）`
- C3 `npc_count_of(玩家物种) == 0`（玩家不被算成 NPC）
- C4 连续换 3 次物种后计数仍然精确（不累积、不漂移）；`max_npcs` 不被突破

### D 出生周围无即时攻击（≥ 16）
- D1 每只 NPC 的**出生距离 ≥ 该物种的 `min_distance_for`**（实测列表逐项）
- D2 捕食者出生距离 ≥ 14.0 m（实测），且 **> 猫的 `vision_range` 9.0**（出生瞬间看不见玩家）
- D3 非捕食者出生距离 ≥ 8.0 m（实测），且 **> 鼠的 `vision_range` 6.5**
- D4 行为窗口 4 s：玩家 `health` **不变**、`last_damage_reason` 未变、**没有任何 NPC 启动过攻击**（`attack_count == 0`）
- D5 行为窗口内"最近距离"实测 ≥ 3.0 m（测量值写进 `MEASURE|`）
- D6 跳过项可解释：若某候选点被拒，`spawn_report()` 里能看到原因（`too_close` / `not_on_layer` / `too_near_other`）

### E 集成：同一地图两条链都能跑（≥ 26）
- E1 **同一张地图**：猫玩家与鼠玩家两次都在 `l_courtyard.tscn` 上（`level.scene_file_path` 一致），用的出生标记同一组
- E2 **猫捕鼠**：猫玩家 + 生态 → 把玩家放到某只鼠 NPC 正前方 0.9 m → `request_pounce()` → **捕获成功**（`capture_count +1`），
  且 **生态计数掉 1**（`npc_count()` 从 2 → 1）、被捕获的那只 `mark_captured` 生效（网格隐藏 / 不在 `animal` 组）
- E3 **捕食者会主动接近玩家**（鼠玩家 + 猫 NPC）：把玩家放到猫 NPC 正前方 4 m → 8 s 内猫的状态出现 `alert/approach/chase`，且**与玩家的距离至少缩短 1.0 m**
- E4 **鼠避猫全链**：同一局里鼠玩家跑到洞口 → `hidden`（`hidden_count ≥ 1`），猫全程与洞心距离 ≥ 0.30 m（复用 T026 口径）
- E5 世界账本：E2 只让捕获计数 +1（`capture_food_count` 也随捕获食物 +1）、其余不动；玩家 `health` 掉血只可能来自 E3 的猫（若掉了要记录实测值）

## 6. 回退与失败恢复
- 若"捕食者出生看不见玩家"在真实关卡上不成立（找不到 ≥ 14 m 且可导航的落点）→ 记实测数据与最近的可用距离，**不偷偷改小 `predator_min_distance`**，交负责人定（要么加出生标记、要么调视野）。
- 若换物种重铺留下旧 NPC（实例仍有效）→ 那是真缺陷（`clear()` 没覆盖），修实现并记证据。
- 若 `debug_entry.tscn` 的默认被意外打开而让既有套件变红 → 立刻改回默认关闭（D3 的硬要求）。
- **同一失败最多两次有依据修复**；无新诊断不上第三次。
