# T047 猫骨骼与权重

## 1. 目标与不做

**目标**（开发计划 :215）：对现役猫资产做**骨骼与权重**验收 —— 极端姿态测**肩、髋、尾**；**无明显塌陷与拉丝**；动手前**保存权重前版本**。

**不做**：
- 不改网格拓扑、不做重拓扑（那属资产返工，需负责人授权）。
- 不改动画曲线/步态参数（属 T048/T049 追溯）。
- 不宣称"能跑就算过"：形变证据必须同时有**数值**与**视觉判读**。

## 2. 决策

- **D1 先量，再判**：权重统计（影响数分布、零权重、权重和、死骨）+ 动画自身摆幅 + 动画极值帧的面积变化，三组数先摆齐，再决定要不要动手。
- **D2 形变指标用"姿态面积 / 静止面积"**：`<0.5` 记塌陷、`>2.0` 记拉丝（逐三角，depsgraph 求值）。这是可复算的代理指标，配合渲染图判读使用。
- **D3 姿态测试分两层**：① **动画自身**的极值帧（发货范围）；② **人造极端姿态**（40°/80°，肩/髋各两轴 + 尾/颈）用来找边界。两层都要报，不拿人造姿态冒充发货问题，也不拿"动画看着还行"掩盖边界缺陷。
- **D4 只做一次最小修复尝试**：对腿根与躯干组做权重平滑 + 归一 + 限 4 影响；**用同一套指标复测**，无效就回退并如实记录（不反复调参）。

## 4. 验收

1. 权重统计有明确数值：零权重顶点 = 0、权重和≠1 = 0、最大影响数 ≤4、死骨清单。
2. **动画自身**最差帧的塌陷/拉丝面数与最小面积比有数值，并有该帧渲染图 + 视觉判读原文。
3. 人造极端姿态（肩/髋 40°/80°、尾、颈）报塌陷/拉丝面数，且**说明轴选择依据**（不能盲猜欧拉轴）。
4. 若判定不通过：给出根因（权重还是拓扑）、已试过的修复及其复测结果、下一步可选项与代价。
5. 若动手改权重：改前版本必须留档（本轮未发货，故只记录基线为 `SM_Cat_005`）。

## 5. 失败恢复

- 权重平滑后指标变差 → 直接回退（删除新导出、保留脚本与数据），不进入"调参循环"。
- 判定"外展轴"时若左右侧结果不一致 → 说明 rig 左右 roll 不同，改用**链末端世界位移**判方向（本任务已用此法）。
- 渲染在无头环境失败 → 用 Cycles CPU（EEVEE 在 background 不可靠）。

## 6. 挂账（不在 T047）

- 肩/髋折痕的**拓扑级**修复（加支撑环线/重拓扑）或换源 —— 需负责人授权。
- 步态摆幅下调（会牺牲步幅观感）—— 属 T048/T049 参数决策。
