## 3. V009 的方法（与 V008 的根本区别）

| | V008（被否） | V009 |
|---|---|---|
| 躯干/四肢/尾巴 | 多个放样零件 **voxel remesh 焊接** → smooth → **decimate** → **噪声位移** | **一根骨架 + Skin 修改器 + 1 级细分**：四肢/尾巴是同一张曲面上的分支，没有"插上去的圆柱" |
| 头部 | 放样 + 后期贴面 | 逐截面放样 + **剖面调制**（颅骨/眉弓/颊毛/胡须垫/下巴同一张曲面） |
| 眼睛 | 眼球 + 间位虹膜 | 眼球 + **上下眼睑环**（有包覆） |
| 耳朵 | 扁锥管 | **有厚度的耳壳**（外/内两张曲面 + 边缘缝合 + 内耳凹陷） |
| 脚掌 | 3 个椭球贴片 | 掌/跖/趾部由同一曲面延伸 + **趾垫/趾缝场塑形** |
| 表面处理 | remesh + decimate + 噪声位移 | 只做 bmesh 松弛（不改拓扑）+ 宽高斯解剖塑形 |
| 拓扑 | 三角面汤（remesh 产物） | **99.3% 四边形**，零非流形，4 个毛发壳（躯干+头+2 耳） |

## 4. 三轮返工（§5 要求，每轮：缺陷 → 改法 → 复测）

| 轮 | 判读指出的缺陷 | 改法 | 复测 |
|---|---|---|---|
| **r1** | "像猪/兔子"；「躯干呈圆筒、腿像鹿腿、后肢 Z 字像骨折、眼睛是弹珠、拼接生硬」 | 骨架+细分首版；头/耳/眼分工；**首次自检**抓到 `islands=3`+`non_manifold=16`（skin 在趾部分叉产生孤立块）→ 改为掌-跖-趾部单链 | 自检通过；判读仍判"Blockout 阶段" |
| **r2** | 「胸腔不够深、背腹线不连续、髋方正、前腿无肘腕、后肢折角像折纸、尾巴几乎不收束、脖子过粗、**横向环状条纹**」 | 增加 spine 中间关节（hipjoint/midback）；胸 0.060→深、腰 0.038、髋 0.049；前肢 5 段关节半径起伏（肩 0.034→上臂 0.026→肘 0.0235→前臂 0.019→腕 0.014）；后肢 7 段（含 thigh/shank，跗关节前移 8 mm）；尾巴 8 段连续收束（0.0225→0.0036）；颈部 0.034；**加 bmesh 松弛 2×0.4 消除环状台阶**；眼睛内收 2 mm；耳壳加厚 + 内耳凹陷 0.78 | 5296 tris；判读仍指出"横向环状条纹极其明显、四肢像棍、脚掌无趾" |
| **r3** | 同上（环状条纹是主要否决项） | 松弛加到 **6×0.5**；趾垫振幅 0.0055→0.0080；尾根半径 0.0225 并前移；**落地对齐**（把最低点归零，`ground|shift=0.005691`） | 5296 tris / 99.3% 四边形 / 0 非流形 / `min_z=0.000000`；**判读仍判"玩具/香肠"→ 触发 §6 停止条件** |

中途排除的方案（有依据，不是放弃）：
- **细分加到 2 级**：实测 `tris=12244`（超 10000 预算）且脚底被平滑到 `-0.0084 m` → 退回 1 级 + 松弛；
- **skin 直接长出 3 根脚趾分支**：两次实测都在 `toeRL/htoeRL` 产生孤立块（`islands=3`、`non_manifold=16`）→ 改为"掌-跖-掌尖单链 + 趾垫场塑形"。
