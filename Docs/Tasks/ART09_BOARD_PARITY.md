## 0. 结论先说

现状不是"差一点"，而是**三个不同层级同时缺**：

1. **表现层缺失**（可自行完成）：书法标题、金色主按钮与 chevron、右栏照片式物种卡、技能环、罗盘、物种选择页版式、HUD 图标与位置。
2. **素材层级缺失**（需决策/授权）：森林溪谷背景、写实环境五件套、照片级猫鼠肖像。
3. **实玩画面缺失**（构图+光照+关卡，可自行完成大部分）：第三人称构图、逆光层次、浅景深、后处理调色。

因此不能再"往庭院里加装饰"。ART08 的教训已写在 `Docs/Evidence/ART08_ENVIRONMENT_BOARD.md` §视觉结论：`l_courtyard` 的宏观构图（围墙 + 直线水带）本身就不是展板溪谷，继续叠装饰属于无效迭代。

本计划的策略是 **"表现层换皮 + 展板切片关卡 + 素材授权门"** 三条并行，谁也不等谁。

## 2. 三条路径与推荐

- **路径 A｜纯表现层**：不新增任何第三方资产。菜单/选种/展示板用「2D 关键图 + 现有 3D」合成到展板级，实玩画面只做构图/光照/后处理。
  代价：实玩画面（要素 1、12、14）永远停在"接近但不够写实"。工期最短。
- **路径 B｜授权写实资产**：采购/下载 CC0 写实溪谷与环境资产，替换五件套，重做溪谷关卡。
  代价：需负责人逐项授权（沿用 `Docs/ART08_CHARACTER_ASSET_REGISTER.md` 的授权门），工期最长，效果最接近。
- **路径 C｜混合（推荐）**：菜单/选种/展示板（要素 2–11、13）走路径 A 做到展板级；实玩画面（1、12、14）先用现有资产重排构图 + 后处理 + 轻度程序化补件（蕨类/落叶/水面），并把写实替换留在授权门后。

**本计划按路径 C 编排，A/B 的任务边界已在各阶段标注，改路径只需删/留对应步骤。**
