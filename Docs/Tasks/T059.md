## 2. 决策

- **D1 一个文件、一套夹紧**：三项新设置全部进 `GameSettings`（`user://settings.cfg` 的 `[player]` 节），
  键名 `volume`（0..1，默认 1.0）、`camera_shake`（0/1，默认 1.0）、`subtitles`（0/1，默认 1.0）、
  `hints_seen`（0/1，默认 0）。**旧文件缺键 → 回落默认**（T037 的"缺集合补默认"口径）。
- **D2 音量落到 Master 总线**：`AudioServer.set_bus_volume_db(0, linear_to_db(v))`，`v=0` 时 `-80 dB` 并置静音标志。
  这样 `AudioDirector`（8 路 3D）与 `AmbienceDirector`（水体循环 + 风底噪）**自动一起生效**，
  不需要在两处各写一遍增益（T055 的"单一出口"精神）。
- **D3 晃动是"受伤反馈"，不是装饰**：`AnimalBody` 新增 `camera_shake_enabled` + `shake_camera(amount)`；
  触发点 = **生命值下降**（跌落/被攻击/饥饿脱水都走 `apply_damage`，用一个"上次生命值"比较即可全覆盖，不新增改血路径）。
  幅度按 `SHAKE_MAX_OFFSET = 0.05 m`、`SHAKE_DECAY = 6.0 /s` 衰减；关掉时**偏移恒为 0**（不是"很小"）。
- **D4 字幕开关直接改 `SubtitleDirector.enabled`**（T056 已有该字段，`enabled=false` 断言过不出字幕）。
- **D5 新手提示不堵操作**：`FirstRunHints` 是**纯显示**的 `Control`：`MOUSE_FILTER_IGNORE`、不抢焦点、
  不 `set_process_unhandled_input`、不暂停、不改世界时间；逐条淡入淡出（默认每条 2.2 s、共 4 条），
  播完发 `finished` → `MainEntry` 写 `hints_seen=1`。**只在新生命的首次出生**显示（读设置判断）。
- **D6 提示文案必须与真实键位一致**（`project.godot` 的 InputMap）：W/A/S/D 移动、Space 跳、Shift 冲刺、
  Ctrl 潜行、E 交互、鼠标左键扑击、Esc 暂停；**不写"按 R 休息"**（休息是走到休息点交互）。
- **D7 菜单侧**：设置面板新增"主音量"「镜头晃动」「关键声音字幕」三个控件；
  布尔项用**滑块 0/1 + 文案（开/关）**——不改 `setting_changed(key, value)` 的 `float` 契约（既有断言不变）。

## 4. 用例（验收）

1. **四项设置可读写并重建**：`save_to` → `load_from`（同一路径）后逐值相同；缺键回落默认；坏值夹紧（音量 1.7 → 1.0、-1 → 0、晃动 0.4 → 0/1 取整）。
2. **音量真的生效**：`volume=0.5` → Master 总线 `volume_db == linear_to_db(0.5)`；`volume=0` → 静音（`-80 dB` 且 `mute`）。
3. **字幕开关生效**：`subtitles=0` → `SubtitleDirector.enabled == false`，`=1` → true。
4. **晃动开关生效**：`camera_shake=0` → `AnimalBody.camera_shake_enabled == false` 且 `shake_camera(1.0)` 后相机偏移 **恒 0**；
   `=1` 时受伤后偏移 > 0、并在 ~1 s 内衰减到 < 1 mm。
5. **晃动由真实受伤触发**：直接 `survival.apply_damage(10)` → 振幅 > 0（不靠测试手动调 `shake_camera`）。
6. **新手提示**：首次出生可见、`mouse_filter == IGNORE`、**树未暂停**、世界时间照常推进（不堵操作）；
   4 条播完后 `finished` → `hints_seen=1` 落盘；同一会话第二次出生不再显示；`hints_seen=1` 的存档下新会话不显示。
7. **菜单控件**：`settings_values()` 含 `volume/camera_shake/subtitles` 三键；`set_setting()` 改值 → `setting_changed` 发出且写盘。
8. 全量 headless 0 失败、`invalid=0`、零窗口。

## 5. 失败恢复

- **`AudioServer` 在 headless 下也有总线**（dummy 驱动），所以音量断言可以在 headless 跑；**不要**用"有没有声音"判断。
- **`linear_to_db(0)` 是 `-inf`**：`volume=0` 必须走显式 `mute` 分支，否则 `set_bus_volume_db(-inf)` 行为不可靠。
- **提示条挡住 HUD**：`FirstRunHints` 放在 HUD 之上、`MainMenu` 之下，`MOUSE_FILTER_IGNORE`，且不 `set_anchors` 到全屏可点区域。
- **受伤检测误触发**：只在**生命下降**时触发；治疗/回满不触发；跨世（新身体）重置基线。
- 取证一律走 `Tools/CaptureRun.ps1`（**不许**让 Godot 窗口弹到桌面，见 Handoff 硬约束）。
