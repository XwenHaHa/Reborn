## 1. 目标与明确不做

**目标**：把 T035 留下的两个过渡态收口，并让读档/重生不再把玩家放进非法位置：
① 区域账本 `total_count` 是**唯一权威**，任何观察点都满足 `active <= total`；
② 读档后可见 NPC 由**区域账本**约束（`total=0` 的区域不生成、未实例化的 `total` 不占位）；
③ 玩家与 NPC 的落点有**可解释的合法性检查与回退规则**，捕获时“账本减一”与“活动实例移除”同一次事务。

**明确不做**：
- 不改存档格式、`save_version`、`WorldSnapshot` 键集合、`pending_settlement_life_id` 语义。
- 不改 T038 队列/节流/关键事务；不改 `LifeCycle` 状态机、死亡/发现/解锁时机。
- 不整体重生成 `l_courtyard.tscn`（保住 `unique_id` 与导航引用）；只做必要节点/代码改动，并复核 `resources/nav/*.tres` 无意外 diff。
- 不实现 T041 的主菜单“继续/新游戏确认”、不做 T042 的 `last_safe_spot_id`。
- 不做多槽、云存档、后台线程、动态种群 AI 预算。

## 2. 审计范围与验收判据

| 范围 | 判据 |
|---|---|
| `active > total` | 读档、重生、捕获后每个 `(region,species)` 恒有 `active <= total`；不合法时按 D1 收敛，账本不动 |
| 区域实例化 | 读档后每个区域的可见个体数 ≤ `total_count`；`total=0` 的区内 0 只；未被实例化的 `total` 不生成节点、不占登记位 |
| 捕获事务 | 已登记目标：`total-1` 与活动实例移除同一次调用；重复上报不二次扣；未登记目标不误扣 |
| 位置回退 | 玩家在区外/导航外/几何内/水面上 → 按 D3 规则回退；回退点仍合法；合法存档位置**原样保留**（T037 精确 transform 断言不大改） |
| 安全距离 | 读档/重生后 NPC 与玩家满足 `min_distance_for(cfg)`；无胶囊重叠；`safe_distance_ok` 可观测 |
| 兼容 | T022/T026/T027/T030～T039 全绿；T037 存档键/精确 transform、T038 队列计数、T039 损坏口径不改 |
| 观测 | `WorldDirector.ledger_consistency()`、`last_reconcile`、`last_capture_ledger`；`MainEntry.last_position_resolution` |

## 3. 决策

- **D1（`active > total` 收敛）**：
  - `total_count` 权威；`active` 只数“已登记、实例有效、存活、未被捕获”的身体。
  - **预防**：布置器只在 `active + planned < total_count` 的区域落点，`total=0` 直接跳过。
  - **纠正**：`WorldDirector.reconcile_region_population(player_position)` 对每个超额的键，
    先移除**距玩家最远**的活动个体（同距离按登记顺序后进先出），直到 `active == total`。
    **账本 `total_count` 不动**；被移除身体 `queue_free` 并注销登记。
  - **玩家可见影响**：如果被移除个体在玩家附近/画面内，会出现“NPC 突然消失”。这是账本权威的代价，
    报告里记 `visible_risk`（移除点距玩家 ≤ 12 m 为 true）。收敛只在读档/重生/捕获后触发，
    不做每帧随机清理。
  - **T040b 修订（负责人 2026-11-04 口头定，本任务 done 状态不变）**：**D1 改为 12 m 内一律不退场**。
    `reconcile_region_population()` 只移除距玩家 **>12 m** 的超额个体；≤12 m 保留并写
    `pending_excess / pending_entries`。近处不再出现“NPC 突然消失”。重试：捕获、自然死亡、读档/重生立即；
    玩家走远后入口每 60 物理帧检查 pending 重试。见 `Docs/Evidence/T040b.md`。
- **D2（按区域账本实例化）**：
  - 读档恢复 `total_count` 后，布置器按区域的 `total_count - active` 决定还能落几只；
    仍受 T027 的 `count_per_species`、`max_npcs` 上限。
  - **未实例化的 `total`** 不生成身体、不占 `region_active_bodies` 位；`total` 只作为上限与抽象数量。
    因此读档后某区域可能出现 `active < total`（如 `total=3` 只实例化 1 只），这是合法状态。
  - `total=0` 的区域必须 0 只；`region_id_at` 为空的落点拒绝（不再“区域外也算铺出来”）。
  - 位置必须在物种自己的导航层上、区内、非水面、不与 `world_static` 重叠。
  - **区域候选补充**：出生标记/环只覆盖标记附近；若某区域有余量但标记候选都因 `total` 被挡，
    布置器追加该区中心 + 2/4/8/12 m 环候选（仅账本已初始化时启用，T027 夹具 no-op），
    吸附后若挪出目标区域则拒绝（`region_mismatch`）。这样读档后落在其它区域的 `total`
    才可能被实例化。
- **D3（位置回退）**：
  - 合法定义：有限坐标、`region_id_at != ""`、距物种导航层最近点 ≤ 0.60 m、不在水体 AABB 内、
    胶囊与 `world_static` 无重叠。
  - **合法存档位置原样保留**（不强行吸附 y，保住 T037 的精确 transform 断言）。
  - 非法时按顺序尝试：① 距原位置 1/2/4/8 m 的 8 方向候选（吸附后取合法且最近）；
    ② 原位置所属区域的中心（吸附后合法才用）；③ 该物种 `spawn_points` 标记；④ 原点上方兜底。
    返回 `reason ∈ {valid, nearest_nav, region_center, spawn_marker, origin}`。
  - NPC 落点复用同一套合法性检查；非法候选跳过并记原因，不硬塞。
- **D4（安全距离重建）**：
  - 读档/重生后布置器以**回退后的玩家位置**为原点重建，沿用 `min_distance_for(cfg)`
    （非捕食者 8 m、捕食者 24 m）；并额外要求 NPC 胶囊与玩家胶囊不重叠。
  - 读档先 `clear()` 旧 NPC 再重铺，避免旧实例留在玩家身边。
- **D5（捕获事务）**：`WorldDirector.report_capture` 在幂等门内一次完成
  `total_count-1 + 注销活动登记`；随后 `CaptureSettlement` 立即 `mark_captured`（同一调用栈、无 await）。
  已登记目标：`total_after = total_before-1`、`active_after = active_before-1`；
  重复上报：零扣减；未登记目标：不误扣。节点按 T021 契约保留但隐藏、出组、停物理。
- **D6（格式与队列零改动）**：`WorldSnapshot` 键集合、`save_version=1`、`revision`、T038 队列/节流、
  `pending_settlement_life_id` 一字不改。
- **D7（观测）**：`ledger_consistency()` 返回逐键 `{region_id,species_id,total,active,ok}`；
  `last_reconcile` 记录移除数与 `visible_risk`；`last_capture_ledger` 记录捕获前后 total/active；
  `MainEntry.last_position_resolution` 记录回退原因与坐标。
- **D8（无新 UI/新资源）**：玩家可见影响沿用菜单/状态栏/HUD；不新增提示控件。
- **D9（兼容回退）**：无 `level_regions` 的夹具关卡（T027 调试入口等）账本未初始化，
  区域约束自动 no-op；T027 的 `count_per_species`/`max_npcs` 默认值不变。

## 7. 失败恢复

- 新增 API 缺失：测试用 `has_method` 守卫，该段只落红不崩。
- 位置回退误伤合法存档：先断言“合法位置原样保留”；若 T037 D12 的精确 transform 变了，视为回归缺陷，不改测试预期。
- 区域约束误伤 T027 夹具：无 `level_regions` 时账本未初始化，必须完全 no-op。
- 收敛移除过度：`total` 不动，`active` 只在超额时减；重复调用应幂等。
- 关卡/导航意外 diff：`git status` 复核 `l_courtyard.tscn`、`resources/nav/*.tres` 必须无改动；若有，停止并说明。
