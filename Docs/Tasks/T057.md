# T057 简化昼夜光照

> **状态：awaiting-review** —— 光照曲线、场景写入、存档恢复（无状态）全部有断言；但**"夜间是否像夜、是否仍看得清路线"没做成视觉判读**（vision 服务两次 `ETIMEDOUT`），只留下客观亮度数据待负责人看图判定。

## 1. 目标与不做

**目标**（开发计划 :249）：**简化**昼夜光照 —— 光照跟世界时间变化、**存档恢复正确**、**夜间可读**、必要感知差异**可调**。

开工前状态：关卡里已有 `SunLight`（DirectionalLight3D）与 `WorldEnvironment`（HDRI 天空 + ACES + SSAO + 雾），但**光照是静态常量**，`WorldDirector` 的昼夜 API（`time_of_day/is_daytime/day_index`，`day_length=1200`、昼夜对半）**完全没有被任何表现层使用**。

**不做**：
- 不做真实天文（方位角/季节/纬度）——"简化"是有意选择。
- 不做天气、云影、体积光（超出本阶段）。
- 不改雾/色调映射/SSAO/曝光等 ART 既有设置（`run_art09_frame_contract` 已锁）。
- 不把 `night_sight_multiplier` 接进 `Perception`（那会改玩法，需单独决策 + 重跑 T020/T023/T024）。

## 2. 决策

- **D1 采样是纯函数**（`scripts/systems/day_night.gd`）：`sample(world_time) -> {elevation, energy, ambient, color, is_day}`。存档恢复的正确性**不靠额外代码**，靠"无状态"：读档把 `world_time` 设回去，下一帧重算就是那一刻的样子。反之若做 `+= delta` 的动画推进，读档后必须补"快进到相位"，那才是 bug 温床。
- **D2 时间口径沿用 T034**：`day_length = 1200 s`、`[0,600)` 白天、`[600,1200)` 夜晚；`is_day` 与 `WorldDirector.is_daytime()` 必须一致（F 组断言，7 个边界点）。
- **D3 曲线刻意简单**：白天仰角 `70·sin(π·d)`、能量 `0.35+0.95·sin`、色温由暖到白；夜晚太阳落到地平线下，改用**月光**（冷色 `b>r`、能量 0.12）。
- **D4 夜间可读 = 环境光**硬下界**：`NIGHT_AMBIENT_FLOOR = 0.26`**，而不是"把太阳调亮当月亮"——环境光是 diffuse，能把整片地形抬起来；太阳能量过高会在夜里投出方向相反的硬阴影，看起来像"白天打了蓝光"。
- **D5 只写四样东西**：太阳旋转/能量/颜色、`Environment.ambient_light_energy`。其余 ART 设置一律不碰。

## 4. 验收

1. 采样曲线：日出 `0°`、正午 `70°`/能量 `1.30`、午夜 `-70°`/能量 `0.12`；周期 `t / t+1200 / t+2400` 逐字段相同。
2. 真写进场景：`SunLight.rotation_degrees.x = -70°`、`light_energy = 1.30`、`Environment.ambient_light_energy = 0.85`（正午）；夜间 `0.12` / `0.26` / 冷色。
3. **存档恢复正确**：任取 `t=412.5`，来回切到 950 → 10 → 412.5，6 个字段逐位相同（无状态）。
4. 夜间可读的数据侧：整段夜间 `ambient ≥ 0.26` 且 `> 0.2`，低于白天。
5. 旋钮 `night_sight_multiplier` 存在且默认 `1.0`（默认不改玩法）。
6. 与 `WorldDirector.is_daytime()` 在 7 个边界点一致。
7. 全量 headless 0 失败、0 INVALID、`visible_hits=0`。

## 5. 失败恢复

- **`Identifier not found: XxxDirector`**：`--script` 下不要直接写 autoload 单例名，用 `get_node_or_null("/root/...")`（T056 已踩，本任务沿用）。
- **函数名猜错导致断言静默消失**：`WorldDirector` 的昼夜 API 是 `is_daytime()`（不是 `is_night()`）。写 `_wd.call("is_night")` 会打 `SCRIPT ERROR` 并**中止该函数**，后面的断言不再执行——总条数会少 1（本次靠 `checks=23 vs 预期 24` 发现）。**总条数必须与预期一致**才算通过。
- **夜间"太亮像白天"**：先看客观平均亮度比（`PIX|mean_luma`），再决定是降 `NIGHT_AMBIENT_FLOOR` 还是降天空环境贡献；不要靠调太阳能量（会产生方向相反的硬阴影）。
- **夜里太黑看不清**：抬 `NIGHT_AMBIENT_FLOOR`，不要抬月光能量。
