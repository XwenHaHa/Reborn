# T048 猫待机与行走循环

## 1. 目标与不做

**目标**（开发计划 :216）：猫的**待机（Idle）与行走（Walk）循环**达到可用基线 —— **可无缝循环**；**优先原地动画**，不得让动画自带的位移与 `CharacterBody3D` 的移动**叠加成双倍位移**。

**不做**：
- 不重做动画资产（曲线由 `art16_cat_gait.py` 生成；本轮只验）。
- 不做攻击提示（`AttackCue`）—— 属 T049。
- 不动 T047 记录的肩/髋折痕问题。

## 2. 决策

- **D1 两层证据**：Blender 侧查**内容**（首末帧闭合、根位移、location 轨道），引擎侧查**运行时**（`loop_mode`、是否绕回、速率匹配、位移量）。
- **D2 区分"根运动"与"身体起伏"**：水平（x,y）漂移 > 5 mm 才算根运动；竖向 `|dz|` 只记录——那是刻意的 bob（art16 `bob` 0.016/0.020 m）。
- **D3 不重复位移用"位移量"证**：1 s 行走的水平位移应 ≈ `walk_speed × 1 s`（猫 1.8 m），而不是 1.8 m 加上动画自带位移。
- **D4 顺带把 Run 一起锁**：三段都用同一个 `AnimalBody` 判据，多一条断言成本低。

- `Docs/Evidence/T048.md`

## 4. 验收

1. `Idle / Walk / Run` 三个片段的 `loop_mode == LOOP_LINEAR`，且播过 1.2 个周期后仍在播、位置已绕回。
2. 静止 2 个 Idle 周期：身体与视觉节点位移 = 0（动画不自己走）。
3. 行走 1 s 的水平位移 ≈ `walk_speed`（±15%），且 `speed_scale` ≈ 1.0。
4. Blender 侧：首末帧骨骼角差 < 1°、水平漂移 < 5 mm、净位移 ≈ 0、无单调累加的 location 轨道。
5. 全量 headless 套件 0 失败。

## 5. 失败恢复

- 若闭环超差：先确认导入是否丢末帧（`animation/trimming`），再查生成脚本的循环相位；**不要**在引擎里用"循环时打断位移"掩盖。
- 若出现双倍位移：检查动画是否带根运动（location 轨道）与 `CharacterBody3D` 是否同时在推；修资产而不是加补偿。
- 判读/数值冲突：以"两者都过"为准，冲突记 `awaiting-review`。

## 6. 挂账（不在 T048）

- `speed_scale` 的夹紧区间（walk 0.5–1.8 / run 0.6–1.6）未单独断言。
- `AttackCue` 缺失 → T049。
- 猫肩/髋折痕（T047）仍未决。
