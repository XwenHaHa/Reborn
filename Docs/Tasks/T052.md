# T052 老鼠待机、移动/逃跑动画

## 1. 目标与不做

**目标**（开发计划 :220）：鼠的**待机 / 移动 / 逃跑**三种表现可用；**可共享移动循环，但速度与状态必须匹配**。

**不做**：
- 不做新模型/新骨骼/新贴图（那是 T050/T051 的资产面）。
- 不改猫的动画与步态参数。
- 不动 T051 已记录的 `Eat` 段形变问题（除非与本任务冲突）。
- 不调平衡数值（逃跑该多快属 T029/U01 决策）——本任务只让**逃跑用上已有的冲刺步速**。

## 2. 现状与缺口（开工前）

- 鼠资产已有 4 段动画：`Idle / Walk / Run / Eat`；`AnimalBody` 按 `want_sprint && speed > walk×1.15` 在 `Walk` 与 `Run` 之间切。
- 玩家操作的鼠能冲刺（`sprint_speed` 3.0 → 播 `Run`）。
- **缺口**：`MouseAI` 的 `FLEE` **从不设 `want_sprint`** ⇒ 逃跑只按 `walk` 1.1 m/s 跑，播 `Walk`。
  即"逃跑"这个状态**没有对应的高速表现**，速度与状态名不匹配。

## 3. 决策

- **D1 逃跑用冲刺（数据开关）**：`MouseAI` 新增 `@export var flee_sprint: bool = true`，`FLEE` 推进路径时 `body.want_sprint = true`；其余状态每帧复位为 `false`（避免"逃完还在冲刺"）。
- **D2 到达即站定**：`HIDDEN` 分支与 `_enter_hidden()` 把 `velocity` 清零——冲刺余速靠摩擦减速会滑出 ~0.2 m，那会让"躲藏中不位移"的既有契约失真（T020/T026 断言就是这么挂的）。
- **D3 用测试锁死"速度与状态匹配"**：新增 `run_t052_mouse_anim.gd`，三层断言（片段名 / 速度数值 / AI FLEE 与非冲刺对照组）。
- **D4 只改必要的生产代码**：`mouse_ai.gd` 三处（开关、FLEE 置位、隐藏清零）；不碰 `AnimalBody` 的切换判据。

## 4. 产物

- `scripts/ai/mouse_ai.gd`：`flee_sprint` 开关 + FLEE 冲刺 + 复位/清零
- `tests/run_t052_mouse_anim.gd`（新，23 条）
- `tests/tool_capture_t052_states.gd` + `Tools/t052_states.ps1`（取证）

## 5. 验收

1. 静止 → `Idle`、走 → `Walk`（≈1.1 m/s）、冲刺 → `Run`（≈3.0 m/s），片段时长与资产一致。
2. `MouseAI` 进入 `FLEE` 后：`want_sprint=true`、播 `Run`、速度 >1.6 m/s（实测 3.000）。
3. 把 `flee_sprint` 关掉后：不出现 `want_sprint`/`Run`，速度回到 ≈1.1 m/s（对照组，证明是数据在起作用）。
4. 既有的"躲藏中不位移"契约不退化（T020 `F_no_move_while_hidden`、T026 `D5`）。
5. 全量 headless 套件 0 失败；`visible_hits=0`。

## 6. 失败恢复

- 若逃跑冲刺让既有套件红：**先判断是契约变化还是夹具缺陷**——"躲藏中位移变大"是行为变化（应在生产侧清零速度修掉），"体力单帧增量变大"要检查是不是结算间隔（0.2 s）造成的夹具口径错误。
- 若冲刺让鼠跑不进退不了洞：先查 `sprint_min_stamina`（5）与体力消耗，必要时把 `flee_sprint` 关掉作为回退开关（数据层，不用改代码）。

## 7. 挂账（不在 T052）

- 逃跑速度是否最终（3.0 vs 更快）属 T029/U01 平衡决策。
- `Eat` 段形变（T051 记录）未动。
- 真实玩家手感与"逃跑时被猫追上"的对抗平衡未测。
