- 任务：T016（规模 4～8h，前置 T011 灰盒关卡）
- 状态：**done（2026-10-15）**——断言 `tests/run_t016_interaction.gd` **118/118 ×3** + 包内 118/118；全量回归 14 套件全绿；包 470,000 B。详见 `Docs/Evidence/T016.md`。
- 真源：`轮生_Reborn_开发计划_v1.0.md` 第 132 行「有效目标优先级、距离与遮挡检测；只显示并执行一个交互」；
  `Docs/TechnicalDesign.md` §4「交互接口（鸭子类型，三个方法）」、§5「物理与碰撞（交互视线用 `ray_cast`；目标碰撞体响应要实测）」；
  `Docs/Parameters.md` 交互范围 猫 100 cm / 鼠 45 cm（已由 T008 落成 `SpeciesConfig.interaction_range` = 1.00 / 0.45 m）。

## 1. 目标

一个任务只交付「找到唯一有效目标 + 调动作接口」，**不含收益发放**（发放与可取消结算属 T017）：

1. **目标接口用鸭子类型**：目标必须实现 `query_interaction(interactor)` / `commit_interaction(interactor, transaction_id)` / `cancel_interaction(transaction_id)`；
   检测侧用 `has_method()` 判定，**不用类型转换失败来判断**（`TechnicalDesign.md` §1 第 72~74 行的唯一范式变化）。
2. **只在 `interactable` 层（layer 3）找目标**：用 `intersect_shape` 的球形查询；**不修改身体自己的 `collision_mask`**（T009/T010 断言锁定它只有 `world_static`）。
3. **距离**用交互者物种配置的 `interaction_range`（猫 1.00 m / 鼠 0.45 m），目标可用 `range_override > 0` 覆盖；`distance <= range` 视为可用。
4. **遮挡**：从交互者眼睛向目标交互点做一次 `ray_cast`，被 `world_static` 挡住 → 该目标无效。
5. **优先级**：`priority` 降序 → 距离升序 → `interaction_id` 字典序（确定性并列打破），**对外只暴露一个 `current_target`**。
6. **物种允许**：目标 `allowed_species` 为空表示不限；非空时必须包含交互者 `species_id`，否则拒绝（`deny_reason = &"species"`）。
7. **同一时刻只执行一个交互**：已有进行中事务时新请求被拒（`deny_reason = &"busy"`）；`commit_interaction` 只在 `allowed` 时调用。
8. **事务**：`transaction_id` 唯一；**同一 `transaction_id` 重复提交返回既有结果、不重复调用目标**（`TechnicalDesign.md` §4 第 186 行）。
9. **时长**：`query_interaction` 返回的 `duration > 0` 时，按**世界时间**推进到时长才提交；暂停（树暂停 / `WorldDirector.time_advancing=false`）时不推进；`duration == 0` 立即提交。
10. **取消**：进行中被取消 → 调 `cancel_interaction(transaction_id)`，**不发收益**（不 commit）。
11. **调试入口只显示一个交互**：HUD 增加 `interact:` 一行（目标 ID / 可用性 / 拒绝理由 / 进度），`MOV|` 追加 `iact=`。

## 4. 决策（D1~D8）

- **D1 只查 area，不动身体 mask**：候选用 `PhysicsDirectSpaceState3D.intersect_shape()`（`SphereShape3D` 半径 = 有效范围，
  `collision_mask = 1 << (3-1)`，`collide_with_areas = true`）。**理由**：T009/T010 已把身体 `collision_mask` 锁死为 `world_static`，
  改身体 mask 会让移动断言与"交互不能撞墙"的规则一起崩。`collide_with_areas` 的实际响应由本任务实测（`TechnicalDesign.md` §5 要求"目标碰撞体响应要实测"）。
- **D2 原点 = 眼睛**：距离与射线都从 `Camera3D.global_position` 出发；没有相机（测试裸身体）时退回"胶囊中心 + 半高"。
  理由：交互是"看到/伸手够到"，与 `vision` 的观感一致，且让鼠（眼高约 3 cm + 半高）与猫的可用范围差异可解释。
- **D3 距离用 3D 欧氏距离**：不用水平距离；竖直差计入（`Parameters.md` 只给一个范围数值，没有俯视角度规定）。
- **D4 边界含等号**：`distance <= range` 可用。测不制造"恰好等于"的浮点边界，用 ±2% 余量验证两侧。
- **D5 排序确定性**：`priority` 降序 → 距离升序 → `interaction_id` 字典序。**同分不靠场景顺序**，避免"换个生成顺序就换目标"。
- **D6 时长走世界时间**：`duration` 用 `WorldDirector.world_time` 的差值推进；暂停不推进（与 T014 同一入口，不新增时钟）。
- **D7 操作方式**：`duration > 0` → **按住 `interact` 开始、松开取消**；`duration == 0` → 按下即完成。
  理由：这样"可取消交互"在 T017 有明确的用户动作，不需要再造一个取消键。**待负责人确认**（§9）。
- **D8 鸭子类型优先于类型**：候选节点只要有三个方法就能参与；`Interactable` 只是**默认实现**（可被 `extends`，也可被完全绕过）。

## 5. 接口（本任务新增）

```gdscript
# scripts/core/interactable.gd
class_name Interactable extends Area3D
@export var interaction_id: String = ""          # 稳定 ID（地图内唯一；空则在 _ready 用节点路径兜底）
@export var interaction_priority: int = 0         # 越大越优先；**不能叫 `priority`**（Area3D 自带 native `priority`）
@export var allowed_species: Array[StringName] = []   # 空 = 不限物种
@export var interaction_duration: float = 0.0    # 秒；0 = 立即完成
@export var range_override: float = 0.0          # 米；0 = 用交互者配置
@export var interaction_point_offset: Vector3 = Vector3.ZERO  # 相对本节点原点的交互点
@export var enabled: bool = true

func interaction_point() -> Vector3             # 全局坐标
func is_allowed_for(species_id: StringName) -> bool
func query_interaction(interactor: Node) -> Dictionary   # {allowed, action_id, duration, deny_reason}
func commit_interaction(interactor: Node, transaction_id: String) -> Dictionary  # {success, reason}
func cancel_interaction(transaction_id: String) -> void
func commit_count() -> int                      # 账本（重复事务 ID 不重复 +1）
func successful_transactions() -> PackedStringArray
```

## 6. 断言（`tests/run_t016_interaction.gd`，目标 ≈90 条）

- **A 参数与接口落地**：两份配置 `interaction_range` = 1.00 / 0.45；`Interactable` 与 `InteractionDetector` 有 `class_name`；
  三方法存在于基类；`has_method()` 路径可用；基类在 layer 3 且 `monitoring` 不参与移动。
- **B 距离**：猫在 0.98 m 有目标、1.02 m 无目标；鼠在 0.44 m 有、0.47 m 无；同一距离下**猫可见 / 鼠不可见**（范围差异来自配置）。
  `range_override` 覆盖生效（0.30 m 的目标让鼠也能用）。
- **C 遮挡**：眼与目标之间放一堵 `world_static` 墙 → 无目标（`deny_reason = &"occluded"`）；换成 `interactable` 层或 `safe_spot` 层的板 → 仍然可用（**遮挡只认 world_static**）。
- **D 优先级**：两个候选都在范围内 → 高 `priority` 胜（**即使更远**）；同 `priority` → 距离近的胜；同 `priority` 同距离 → ID 字典序小的胜。
- **E 物种允许**：`allowed_species = [&"Mouse"]` 的目标对鼠 `allowed=true`、对猫 `allowed=false` 且 `deny_reason=&"species"`；
  空 `allowed_species` 对两者都允许。
- **F 只显示一个**：`current_target()` 只有一个节点；`target_changed` 在切换时各发一次、同一目标不重复发。
- **G 只执行一个**：`duration = 0.3` 的交互开始后，`try_interact()` 对**另一个**目标被拒（`deny_reason = &"busy"`），目标账本 `commit_count()` 仍为 0。
- **H 时长与世界时间**：0.4 s 时未提交、0.6 s 时提交一次；**暂停（`time_advancing=false`）期间进度不前进**；
  `duration == 0` 按下即提交（进度立刻 1）。
- **I 取消无收益**：进行中 `release_interact()` → 调了 `cancel_interaction`、`commit_count() == 0`、`is_interacting() == false`。
- **J 事务幂等**：同一 `transaction_id` 调两次 `commit` → 目标 `commit_count() == 1`，且第二次返回既有结果。
- **K 鸭子类型**：一个**不继承 `Interactable`** 的 `Area3D`（自己实现三方法）能被选中并提交；
  一个只有 `query_interaction` 的节点被**跳过**（记录原因，不崩）。
- **L 集成**：真实 `animal_body.tscn` 在扁世界里 + 一个 `Interactable` → `press_interact()` 走通；
  调试 HUD 的 `interact:` 行与 `MOV|` 的 `iact=` 出现；正式场景（`main.tscn` / `l_courtyard.tscn`）仍 0 调试节点。

## 8. 失败回退

- 若 `intersect_shape` 在 headless 下**查不到 Area3D**（`collide_with_areas` 不生效），回退方案：给目标同时挂 `StaticBody3D`（layer 3）并用 area 优先、body 兜底；
  **不改成"遍历场景树找节点"**（那会让距离/遮挡检测失去物理依据）。
- 若 `ray_cast` 打不到 `world_static`（目标层响应缺省为 1 时正常，但自定义 `collision_layer` 的墙可能漏），直接记录实测：
  射线 `collision_mask` 只放 `world_static`，**墙的层不对就是墙的问题**，不改判定语义。
- 任一失败最多两次有依据的修复，之后按 `AGENTS.md` 记 blocked 并给出最小解除方法。

## 9. 需要确认的事项

1. **D7 操作方式**：`duration > 0` 的交互用"按住 `E` 开始 / 松开取消"是否符合设计？还是"按一下开始、再按一下取消"？
2. **D2/D3 原点与距离**：用"眼睛 → 交互点"的 3D 距离（含竖直差）是否是期望的"够得到"语义？鼠眼高很低时竖直差会明显压缩可用范围。
3. **是否要视锥限制**：本任务只做"距离 + 遮挡"，**不做朝向/半角**（`Parameters.md` 的 `VisionHalfAngle` 是感知用的，交互未规定）。
4. **优先级数值表**：`priority` 各资源点/安全点用多少，等 T017/T031 定；本任务只用测试值。
5. **`interaction_duration` 的正式数值**（吃/喝要几秒）`Parameters.md` 未给，等 T017 定。
