# T050 老鼠形体与 UV/材质

## 1. 目标与不做

**目标**（开发计划 :218）：确认鼠的基础形体与材质达到可用基线 —— **小尺度仍可辨、贴图和轮廓清楚**；并且**不是把猫缩放当鼠**。

**不做**：
- 不改网格/UV/贴图（本轮只**检查 + 取证**；发现问题再按 T046 的模式单独立项）。
- 不做骨骼权重（T051）与动画（T052）。
- 不宣称"能认出来就是美术合格"（`approved` 只能负责人置位）。

## 2. 决策

- **D1 小尺度用 0.45 m 观察距离**：鼠胶囊高 0.18 m，玩家第三人称看鼠约 1–6 m、猫线看猎物 0.5–3 m；0.45 m 是"极近特写"，比游戏里任何真实观距都苛刻 —— 在它下面能认清，实际游戏就更没问题。
- **D2 复用猫的检查器**：`Tools/Blender/t046_cat_check.py` 是通用网格检查器（拓扑/UV/材质），直接对 `SM_Mouse_002.glb` 跑，口径与猫一致（`raw`/`welded` 两组、逐三角 UV 各向异性）。
- **D3 "不是缩放猫"要有断言**：`run_art03_mouse.gd` 已锁 `mouse_visual_not_cat_asset`，本轮复跑取绿。
- **D4 只记录不修**：贴图分辨率/无 normal map/接地阴影弱等属"材质简单"与表现层范畴，写进证据与挂账，不擅自改第三方贴图。

## 3. 产物

- `Game/Reborn/tests/tool_capture_t050_silhouette.gd`、`Tools/t050_silhouette.ps1`（新，0.45 m 三向取证）
- `Art/Probes/t050_mouse_{front,side,three_quarter}.png`
- `Docs/Evidence/T050.md`

## 4. 验收

1. 0.45 m 三向截图可辨认出是鼠（判读原文入证据）。
2. 拓扑：`welded` 真非流形 = 0、退化面 = 0、孤立点 = 0、翻面 = 0。
3. UV：无越界 loop；各向异性报中位/p95/max 与 `>4×` 面数并定位。
4. 材质：槽数、贴图尺寸、是否"复杂毛发"有数值。
5. `run_art03_mouse.gd` 全绿（含"鼠视觉不是猫资产"断言）。

## 5. 失败恢复

- 判读答不出"是鼠" → 先查机位（0.45 m 太近会切掉头/尾）再改距离，不靠改模型凑判读。
- 背板出现地平线被判成渲染缺陷 → 用铺满视野的 40×24 m 背板（T045 已踩过）。
- 检查器对 FBX/GLB 报错 → 确认 Blender 3.3.1 与 glTF 导入器可用；FBX 多网格时取面数最多的。

## 6. 挂账（不在 T050）

- 鼠的**骨骼权重**（T051）与**动画**（T052）。
- 材质升级（normal map / 更高分辨率贴图）——需换源或重烘。
- 接地接触阴影弱（与猫同源）——表现层任务。
