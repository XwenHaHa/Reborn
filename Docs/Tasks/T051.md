# T051 鼠骨骼与权重

## 1. 目标与不做

**目标**（开发计划 :219）：鼠的**尾、四肢与躯干变形可用**；**骨骼命名稳定**；动手前保存权重前版本。

**不做**：
- 不改网格/拓扑（那属资产返工）。
- 不改动画曲线（Eat 段的形变问题记给 T052 / 后续返工）。
- 不拿"能跑"当通过：数值（权重统计 + 面积形变）与渲染判读都要有。

## 2. 决策

- **D1 骨骼命名可直接用**：鼠的 23 根骨骼是语义命名（`Back_01` / `Hip_02` / `Tail1_03…` / `FrontLeg1_l_07` / `BackLeg1_r_013` / `Neck_016`），不需要像猫那样用链末端位移反推轴。
- **D2 极端姿态不猜轴**：对四条腿根**每个轴各转 70°** 全部报数（12 组），而不是挑一个"看起来像外展"的轴。尾（`Tail1` 70° + `Tail2` 60°）与颈（`Neck` 45° + `Head` 35°）单独报。
- **D3 发货范围优先**：先测**动画自身**的极值帧（Eat/Idle/Run/Walk 逐帧），再看人造 70°；两者分开记录，不用人造姿态冒充发货问题。
- **D4 渲染必须按"求值后包围盒"构图**：本资产静止顶点带偏移（world `min y≈-5.19`、`z≈-1.35`），按原点或按静止 bbox 都会拍到空景/碎块（本轮踩了两次）。

## 3. 产物

- `Tools/Blender/t051_mouse_rig_check.py`（权重统计 + 动画极值帧形变 + 12 组极端姿态）
- `Tools/Blender/t051c_render.py`（按求值 bbox 逐帧构图渲染：动画 3 帧 + 尾/颈姿态）
- `Art/Probes/t051_mouse_{anim_Eat_f0,anim_Walk_f25,anim_Run_f10,pose_tail,pose_neck}.png`
- `Docs/Evidence/T051.md`

## 4. 验收

1. 权重统计：零权重顶点 0、权重和≠1 为 0、每顶点最大影响 ≤4、无影响骨骼清单。
2. 骨骼命名可读且稳定（语义命名、无重名冲突）。
3. 四段动画的腿根摆幅与最差帧形变（塌陷/拉丝面数、最小面积比）有数值。
4. 极端姿态 12 组 + 尾/颈各一组有数值；尾/四肢/躯干**无明显塌陷与拉丝**。
5. 至少 2 帧渲染 + 视觉判读原文，且判读结论与数值不矛盾（矛盾时以两者都过为通过）。

## 5. 失败恢复

- 渲染拍到空景 → 用**求值后**包围盒构图（depsgraph），不要用静止网格 bbox。
- 判读与数值冲突 → 两者都过才算过；冲突时记 `awaiting-review` 交负责人。
- 若改权重：先存 `SM_Mouse_002` 为基线再动，改后必须用同一套指标复测。

## 6. 挂账（不在 T051）

- Eat 段的形变（前肢/口部）返工 —— 与 T052 动画一起处理。
- 鼠的动画质量（步态/逃跑）—— T052。
