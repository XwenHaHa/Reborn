## 0. 一句话目标

把三条**已经分散实现**的规则（洞的几何/导航 → T010/T012；草丛的可见性系数 → T011/T020；逃跑与躲藏链 → T020/T024）
在**同一口径**下钉成契约，并补上当前**没有任何断言守着**的三条：
**草丛不改移动、不改攻击遮挡**；**AI 侧的"洞口不可达"**；**躲藏期间不凭空恢复资源**。
本任务以**验证 + 补差**为主：实测发现缺口才改实现（改则记证据）。

## 1. 范围

### 做
1. **草丛只降低可见性**（`Parameters` 第 73 行 `VisibilityFactor = 0.4`）：
   - 只影响**视觉发现距离**（乘 0.4）与 `cover_factor_at()` 取值；**不改碰撞**（体量是 `Area3D`，不是实体）；
   - **不改移动**：猫/鼠穿过草丛体积时位移不受影响、不被顶住；
   - **不改攻击复核**：`AttackSettlement.occluded()` 只看 `world_static` → 隔草丛**不算遮挡**（与"只降低可见性"一致）。
2. **鼠洞阻止猫进入**（四层合证）：
   - 几何/导航：猫层导航面**不覆盖洞内**，从猫的出发点"去洞口"的路径**终点不在洞心**；
   - AI 侧：`AnimalAI.reachable(hole_point)` 对猫为 **false**、对鼠为 **true**（新增断言）；
   - 物理：把猫**朝洞口推** 1.5 s，猫与洞心距离始终 ≥ 洞口半径（**进不去**）；鼠同一动作能进（< 0.30 m）；
   - 数值前提：`CatAI.hole_search_radius` / `search_arrive_radius` 都 ≥ 洞口半径 → 猫只会**停在洞外**（配合 T024 的洞口等待 6 s 超时）。
3. **躲藏不凭空恢复全部资源**（新增断言）：
   - `HIDDEN` 期间 Hunger/Thirst **不上升**、不回到上限、Health **不恢复**、Stamina 不超上限也不跳变；
   - `HIDDEN` 期间的衰减速率与 `EXPLORE` 期间**同量级**（躲藏既不是免费回血点，也不额外扣资源）；
   - 4 s 后出洞时数值**连续**（不出现"出洞即回满"）。
4. 断言套件 `tests/run_t026_cover.gd`（A～E，目标 ≥ 90 条）。

### 不做（越界即停并解释）
- **草丛的物理体积化**（"草丛是否要改成物理体积"仍是 T020 §8 的开放项）→ 本任务只**钉住现状**（非实体）。
- **洞口"能不能隔着打到洞里"的攻防细则**：属 T027 生态布置（若本任务实测发现"洞里仍可被看见/打中"，**如实记录为开放项**交给负责人，不擅自加挡板）。
- 区域 NPC 数量与生态布置 → T027；第一轮试玩 → T028。
- 视觉判读：vision 服务当前 503（T025 已记）→ 若仍不可用则记 NOT-VERIFIED。

## 4. 验收断言（`tests/run_t026_cover.gd`，目标 ≥ 90 项）

### A 数据与接口（22）
- A1 真实关卡：`cover_volumes` **有 4 个**、**全部** `visibility_factor == 0.4`（草丛里不混入"开阔 1.0"）；全部是 `Area3D` + `collision_layer == 0`（**非实体**）
- A1b "开阔 = 1.0" 由 `danger_zones` 的 `role == "open_exposure"` + `visibility_factor == 1.0` **声明**（`cover_factor_at()` 只读 `cover_volumes`，草丛外即默认 1.0 → 语义一致）
- A2 真实关卡：`hide_spots` 里有 `kind == mouse_hole`、`radius ≈ 0.30`、`species == Mouse` 的标记
- A3 `Perception.cover_factor_at()`：草丛内 = 0.4；草丛外 = 1.0；**两草重叠取最小**（0.4 与 0.6 → 0.4）
- A4 `MouseAI`：`hidden_hold_time == 4.0`、`immediate_flee_range == 1.80`、`flee_timeout == 3.0`；`hidden_count()` / `flee_kind()` 可查
- A5 `CatAI`：`hole_search_radius ≥ 0.30`、`search_arrive_radius ≥ 0.30`（**停在洞外的数值前提**）

### B 草丛只降低可见性（≥ 20）
- B1 **对照**：同一只鼠、同一距离 3 m → **草丛内看不见**、**草丛外看得见**（同一帧两夹具）
- B2 发现距离确实乘 0.4：草丛内 3.0 m 不可见 / 2.0 m 可见（9.0 × 0.4 = 3.6 的边界两侧）
- B3 **不改移动**：鼠在草丛体量内走 1 s 位移 ≥ 0.8 m（不被顶住）；猫同样
- B4 **不改攻击遮挡**：把草丛体量放在猫与鼠之间 → `AttackSettlement.occluded()` 为 **false**，攻击**命中**（掉 35）
- B5 草丛体量不参与物理层：`collision_layer == 0` 或节点非 `CollisionObject3D`（实测断言）

### C 鼠洞阻止猫进入（20）
> 判据用**按层**的 `map_get_path()`：Godot 4.7.2 的 `map_get_closest_point(map, p)` **不带导航层**，
> 而猫/鼠共用同一张世界地图 RID（实测两者返回同一个"最近点"= 鼠标层洞面 0.040 m）→ 不能用它判"猫能不能进洞"。
- C0 前提：猫鼠拿到的是**同一张世界地图 RID**（靠导航层区分）；洞轴 = 关卡 `RootBarrierLintel` 墙的本地 z 轴（水平，实测 `(0,0,1)`）
- C1 **跨墙路由（猫）**：从墙一侧 2 m 走到另一侧 2 m（两端先按层吸附，证明"猫的层确实铺到那里"）→ 路由**不靠近洞口**（实测最近 **2.000 m**）、**绕墙 34.68 m**（直线 4.00 m）
- C2 **跨墙路由（鼠）**：同一对端点 → 路由**穿过洞口**（实测最近 **0.041 m**）、长度 4.00 m ≈ 直线
- C3 `reachable(hole_point)`：猫 AI **false**、鼠 AI **true**
- C4 猫的路径终点：`map_get_path(cat_map, 猫出发点, hole_point)` 的终点距洞心 **0.681 m** > 0.10 m（去不了洞里）
- C5 物理推（猫）：沿洞轴朝洞口撞 1.5 s → 全程与洞心距离 ≥ 0.30 m（实测 **0.703 m**），且**确实走过 1.339 m**（夹具守卫，防"原地没动"的假通过）
- C6 物理推（鼠）：同一动作 → 钻到洞心 **0.089 m** < 0.30 m（**进得去**），走动 2.040 m
- C7 停在洞外的数值前提：`hole_search_radius`、`search_arrive_radius` 均 ≥ 洞口半径（A5 的运行时复核）

### D 躲藏不凭空恢复全部资源（16）
- D0 夹具前提：鼠**面朝猫**且 `perception.is_threat_visible() == true`（威胁在背后时鼠看不见 → 永远不会 FLEE，整段会退化成空断言）
- D1 `HIDDEN` 期间连续采样 2.5 s：Hunger/Thirst **不上升**（Δ ≤ +0.05）、不回到上限、Health 不上升
- D2 `HIDDEN` 期间 Stamina ≤ 上限，且相邻帧增量 ≤ `stamina_regen_per_sec × dt × 2`（**不跳变**，实测最大帧增量 0.00）
- D3 衰减速率与 `EXPLORE` 同量级：`|rate_hidden − rate_explore| ≤ 0.3 × rate_explore`（实测 0.1012 vs 0.0990）
- D4 4 s 后出洞：Hunger/Thirst **不高于**进洞时（无回满）
- D5 `HIDDEN` 期间 `move_intent` 为零、位移 ≤ 0.05 m（**躲着别动**）
- D6 出洞后状态回到 `explore`（`hidden_count() ≥ 1`、`flee_kind()` 有值）

### E 集成（真实关卡：猫追 → 鼠钻洞 → 猫停在墙外）（10）
- E0 非空前提：猫从洞口外 5 m **真的追过 ≥ 1.00 m**（实测 4.230 m）、鼠**真的钻进洞过**（`hidden_count ≥ 1`）
- E1 全程：猫与洞心距离 ≥ 0.30 m（实测 **0.806 m**），结束时状态 ∈ {search, explore, alert, approach, chase, attack}（实测 `approach` / `in_range`）
- E2 同期世界账本不变（`capture_count` / `capture_food_count`）、鼠仍存活（本段**关掉攻击**；攻击链见 B4 与 T025）
- E3 `main.tscn` 内无 `/debug/` 脚本节点
- E4 全程无脚本错误（套件汇总 + 退出码；日志报错行由 Evidence 的 `Select-String` 扫描核对）

## 7. 开放项（不阻塞 T026）
1. 草丛是否改成**物理体积**（T020 §8 遗留）—— 本轮按数据钉住"非实体"（`collision_layer == 0`）。
2. 洞里/洞口的**攻防细则**：实测**猫在墙外仍能"看见"洞里的鼠**（0.24×0.30 缺口通视，HUD `sense: seen=true`）但**够不到**（离洞心 0.806～1.025 m）。
   洞里能否被**打中**本轮未测（攻击距离 0.65 m < 猫的物理极限 ≈ 0.70 m → 预期打不到）；**只测不改**，交 T027 生态布置。
3. 鼠洞数量与位置布置 → T027；`HideSpot` 只留 1 个是否最终设计（T020 §8）。
4. 躲藏期间的**额外规则**（例如"完全静止才能藏"）→ 待负责人定。
5. **`AnimalAI.reachable()` 的判据 ① 层盲**（本轮发现，**未改**）：`map_get_closest_point()` 不带层，判据① 对猫可能取到**鼠标层**的点（实测 0.040 m）。
   结论不受影响（判据② `map_get_path()` 本身带层，且 `true ⟹ 真能到`），但判据① 是**冗余**的，它只会造成**假否**（理想解：去掉①或改成按层）。
   改它会影响 T019/T023/T024 的共享代码 → 不在 T026 擅自改，**交负责人定**。
