# T045 猫基础形体

## 1. 目标与不做

**目标**（开发计划 :213）：确认猫的**基础形体**达到可用基线 —— **正侧面与低镜头距离（1.2 m）轮廓可辨**，且**模型符合已验证的身体尺寸**（胶囊 0.16 / 0.48、高 ≤0.48 m、长 ≤0.62 m、原点脚底中心、朝 `-Z`）。

**不做**：
- 不做 UV/材质返工（T046）、骨骼权重（T047）、动画（T048/T049）。
- **不新造形体**：V009 程序化重建路线已按 `modeling3.md` §6 停止（`Docs/Evidence/ART02.md`），正式视觉用已授权参考 `cat_fripouille` 的产物 `sm_cat_004.glb`。
- 不做"美术合格"判定：`approved` 只能负责人置位（`Docs/ART_ASSET_SPEC.md` §5）。

## 2. 决策

- **D1 用"取证 + 量尺寸"来验收**，不重做模型：T045 的验收词是"轮廓可辨 + 符合尺寸"，两件事都能用固定机位截图 + 断言给出可复核证据。
- **D2 机位固定 1.2 m、平视 0.30 m 高、45° FOV**，三向：`front`（-Z 侧看脸）/ `side`（+X）/ `three_quarter`（前右 45°）。背景用**铺满视野的纯色背板**（40×24 m @6 m），避免庭院杂物影响轮廓判读。
- **D3 尺寸以既有断言为准**：`run_art02_cat.gd`（现 72 条）已锁三角数、材质槽、朝向、贴地、装胶囊、动画绑定；本任务只补"低机位三向轮廓"这一块没有证据的部分。
- **D4 已知美术缺陷照实记录，不冒充达标**：贴图分辨率、橘白交界、四肢僵直、头颈过渡属 ART02 遗留，需新来源或 T046 材质返工，写进证据与挂账。

## 4. 验收

1. 三帧在 1.2 m 距离可辨认出是猫（视觉判读原文入证据），头/耳/躯干/四肢/尾巴可辨、比例无明显畸变。
2. 尺寸契约实测通过：AABB 高 ≤0.48 m、长 ≤0.62 m、`min_y≈0`（贴地）、朝 `-Z`；`run_art02_cat.gd` 全绿。
3. 材质槽 ≤2、三角数在实测预算内（T044：≤40k）、33 骨、Idle/Walk/Run 三段动画在。
4. 取证命令可重跑，`exit=0`，`CAP|t045|done`。

## 5. 失败恢复

- 若判读答不出"是猫"：先查机位（朝向/遮挡/背板是否遮住主体），改机位重拍，不靠改模型"凑"判读。
- 若尺寸断言红：以断言为准，回退最近一次资产/配置改动，不在 T045 改玩法尺寸。
- 若背板出现可见边界被误判为渲染缺陷：把背板放大到铺满视野（本任务实测踩过两次：4×3 m 与 12×8 m 都出现地平线，40×24 m 才稳定）。

## 6. 挂账（不在 T045）

- 美术质量（贴图分辨率/橘白交界/四肢僵直/头颈过渡）→ 需负责人决定换源，或 T046 材质返工。
- 角色接地阴影/接触 AO 的表现 → 表现层任务（ART 系列），T045 只如实记录判读结论。
- 45° 视角尾巴是否被身体遮挡 → 本轮只记录，不做骨骼级验证。
