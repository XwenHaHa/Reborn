## 0. 一句话目标

让猫（`can_pounce = true`）做出受预算约束的地面扑击：沿锁定朝向连续扫掠，**撞障碍即停**，命中有效猎物则**结算一次**捕获并生成一个容量 1、300 s 失效的可食对象；无论成功、失败、被挡都恰好扣 25 体力，恢复 0.6 s。

## 1. 范围

做：扑击动作（身体级）、扫掠与障碍优先、命中判定、捕获结算（幂等）、捕获食物对象、体力代价与恢复、动作互斥、诊断字段、无头测试套件、证据文档。

不做（属其他任务，禁止顺手实现）：猫 NPC 状态机与追击/搜索（T023/T025）、猫 NPC 攻击伤害 35 与 0.45 s 预警（T025）、区域动物数量账本与持久化（P4/P5）、HUD 捕获提示（T022 视需要）、伤害/死亡通道改动。

## 3. 行为决策

**D1 扑击是身体级动作，不是 AI 状态。** `ACT` 由 `AnimalBody` 维护；`action_state()` 优先级：`DEAD` > `POUNCING` > `RECOVERING` > `INTERACTING` > `IDLE`。`DEAD` 以 `captured == true` 或生存状态已死亡判定；**`SurvivalState` 没有 `alive` 字段**，一律用 `SurvivalState.is_dead()`（health ≤ 0），无 `survival` 时视为未死。

**D2 启动门（全部满足才启动，否则 `start_pounce()` 返回 `false` 并写明 `last_pounce_blocked_reason`）。**

| 条件 | 失败原因字符串 |
| --- | --- |
| `species_config.can_pounce` | `"species"` |
| 已 `captured` 或 `DEAD` | `"dead"` |
| `is_on_floor()` | `"airborne"` |
| `action_state() == IDLE`（非扑击/恢复/交互） | `"busy"` |
| 体力 ≥ `pounce_stamina_cost` | `"stamina"` |
| （额外）所在物理帧未结束上一条扑击 | `"busy"` |

启动成功：**立即**扣 `pounce_stamina_cost`（25；用 `survival.spend_stamina(...)` 或文件既有等价扣减接口，需保持 `SurvivalState.stamina` 与既有信号一致）、`pounce_count += 1`、朝向锁定、`_pounce_travel = 0`、`_pounce_elapsed = 0`。

**D3 扫掠位移（不得传送、不得超过预算、障碍优先）。**
- 每物理帧用 `move_and_collide(motion)` 推进，**不使用** `move_and_slide()`；`motion.x/z = locked_dir * (pounce_max_distance / pounce_duration) * delta`，`motion.y` 沿用常规重力增量（扑击不悬空）。
- 累计水平位移超过预算时把当帧水平分量截断，使**总水平位移 ≤ `pounce_max_distance`**；记录 `last_pounce_travel`。
- `move_and_collide()` 每帧只返回**第一个**碰撞 → 天然满足"障碍优先于障碍后的猎物"：更近的墙会先于墙后的猎物响应。
- 碰撞处理：碰撞体属于 `LAYER_WORLD_STATIC`（或不是动物体）→ `last_pounce_blocked_reason = "world"`，结束扑击进入 RECOVERING；碰撞体是动物体但不满足 D4 → `"animal"`，同样结束且**不**结算。
- 无碰撞 → 直到 `_pounce_elapsed ≥ pounce_duration` 结束（`last_pounce_blocked_reason = ""`）。
- 扑击期间水平 `velocity` 由扑击驱动；`move_intent` 被忽略（不叠加玩家输入）。

**D4 有效猎物判定（`is_valid_prey`，纯状态/配置判定，禁止物种名分支）。**
`target is AnimalBody` 且 `target != self` 且 `target.species_id != species_id` 且 `target.captured == false` 且（有 `survival` 时）`survival.is_dead() == false`。

**D5 命中结算只在命中瞬间发生一次，双重幂等。**
命中有效猎物时：`hit_position = 猎物碰撞位置（或本帧碰撞点）`，调 `capture.try_capture(target, hit_position)`；随后 `captures += 1`、结束扑击进入 RECOVERING、**不**产生伤害事件（捕获不走走伤害/死亡通道）。去重由 `WorldDirector.captured_target_ids` + 目标 `captured` 标记共同保证（`mark_captured` 亦幂等：已捕获返回 `false`）。被捕获目标：`captured = true`、`captured_by = 捕食者 source_id`、退出 `animal_bodies` 组（不再作为威胁/猎物）、停止 `_physics_process`、隐藏网格并关闭碰撞（`collision_layer = 0`、`collision_mask = 0`），节点保留在树上（供测试与证据读取），不 `queue_free()`。

**D6 捕获食物对象（"可食对象"≠回满指标）。**
在命中点生成 1 个 `ResourcePoint`（`res://scenes/world/resource_point.tscn`）：`kind = KIND_FOOD`、`food_type = FoodType.MEAT`、`units = 1`、`capacity = 1`、`refill_interval = 0.0`、`next_refill_at = INF`、`infinite = false`、`auto_advance = true`、`expire_at = 命中世界时间 + species_config.capture_food_expire`（300）、`nutrition` 沿用 `ResourcePoint` 既有默认（35.0）、`region_id` 沿用捕食者/关卡默认（`&"Courtyard"`）。生成**不**直接改变捕食者任何状态量：`SurvivalState`（hunger/thirst/stamina 除 D2 的 25 点外）在捕获前后保持，进食须由既有 T017 交互流程消费该对象。

**D7 恢复 0.6 s。** 扑击结束进入 RECOVERING，时长 `species_config.pounce_recovery`，按**世界时间差**计时（`world_time_now()`，无 `WorldDirector` 时用既有 `_fallback_world_time`）。恢复期：不能再次扑击（`"recovering"`）、不能跳跃、不能交互、`move_intent` 不产生水平位移（站位固定）、允许视角。

**D8 互斥。** POUNCING/RECOVERING 期间 `want_jump` 被吞；POUNCING 期间锁定朝向：`apply_look(yaw, pitch)` 忽略 `yaw`（`rotation.y` 不变），`pitch` 仍生效（观察用）；启动扑击时若存在进行中的交互，先 `interaction` 取消（无收益、`cancel_interaction` 语义），并置交互受阻原因 `"pouncing"`。

**D9 时间源。** 位移用物理 `delta`；时长/恢复/食物失效用世界时间；两者不混用累积。

**D10 诊断。** §2.5 / §2.4 的字段必须反映真实状态（扑击中被挡也如实写 `blocked`，不得只在成功时赋值）。

## 4. 验收断言（`tests/run_t021_capture.gd`，目标 ≥ 80 项）

场景统一在测试脚本内自建（**不**依赖 Courtyard 关卡）：`StaticBody3D` 地面 + 可选墙壁 + 猫 `AnimalBody`（`player_controlled=false`、`ai_enabled=false`）+ 鼠 `AnimalBody`（同上），坐标手工给定。

- **A 启动门**：鼠（`can_pounce=false`）`start_pounce()` → false 且 `"species"`；猫空中 → `"airborne"`；体力 10（< 25）→ `"stamina"` 且体力不变、`pounce_count` 不变；`mark_captured` 后 → `"dead"`；交互中 → `"busy"`；合法地面 Idle → true、`pounce_count == 1`、体力 −25（±1e-4）。
- **B 位移预算（无墙）**：空场地扑击全程 → 水平位移 ∈ (1.30, 1.40]、`last_pounce_travel ≤ pounce_max_distance + 1e-4`、`blocked == ""`、期间 `action_state() == POUNCING` 至少出现一次、结束转 RECOVERING。
- **C 障碍优先**：墙在 1.00 m、鼠在 3.00 m 同侧同一射线上 → 扑击结束于墙前（水平位移 ≤ 1.00 + 0.05）、`blocked == "world"`、鼠 `captured == false`、`WorldDirector.capture_count == 0`、体力仍恰好 −25、`pounce_count == 1`。
- **D 命中猎物**：鼠在前方 1.20 m 无墙 → 命中；鼠 `captured == true`、`captured_by == 猫 source_id`、`action_state() == DEAD`、已移出 `animal_bodies` 组、`collision_layer == 0`；世界 `capture_count == 1`、`is_captured(鼠 id) == true`；猫 `captures == 1`、`pounce_count == 1`、体力 −25。
- **E 幂等**：再次 `WorldDirector.report_capture(猫, 鼠, pos)` → `false` 且 `capture_count` 仍 1；再次 `鼠.mark_captured(...)` → `false`；已被捕获的鼠作为扑击目标 → `is_valid_prey == false`、食物不新增（`capture_food_count` 不变）。
- **F 捕获食物**：命中后世界新增**恰好 1** 个 `ResourcePoint`：`kind == food`、`food_type == MEAT`、`capacity == 1`、`units == 1`、`refill_interval == 0`、`infinite == false`、`expire_at == 命中世界时间 + 300`（±0.01）、位置与命中点水平距离 ≤ 0.15；捕获前后猫的 `hunger`/`thirst`/`health` 不变（**不直接回满指标**）；世界时间推进到 `expire_at` 后 `is_expired() == true` 且 `expired` 信号已发；达到 `expire_at` 之前 `is_expired() == false`。
- **G 恢复与互斥**：命中/被挡后 `action_state() == RECOVERING`；恢复期内 `start_pounce()` → false 且 `"recovering"`、`pounce_count` 不变；恢复期 `move_intent = Vector2(1,0)` 连续帧不产生水平位移（≤ 0.02 m）；恢复期 `want_jump` 不产生离地（未 `has_touched_floor` 的 false 转折 / `position.y` 不上升）；POUNCING 期间 `apply_look(0.8, 0.0)` 后 `rotation.y` 不变；世界时间推进 0.6 s 后 `action_state() == IDLE` 且可再次扑击（体力 ≥ 25 时 `start_pounce()` true）。
- **H 失败同价 + 时序**：C（被挡）与 D（命中）两种失败/成功路径都恰好扣 25，且**不退还**；整个扑击期间（B）水平位移严格 ≤ 1.40 m；扑击时长 ∈ [0.20, 0.35] s（世界时间口径）；不出现瞬移：任意相邻物理帧水平位移 ≤ `速度 × delta × 1.5`。

自检要求（与 T020 同规矩）：套件打印 `SUMMARY|checks=<n>|failures=0` 与 `RESULT|PASS`，退出码 0；运行必须核对 checks 条数（`--quit-after` 过小会静默截断）。
