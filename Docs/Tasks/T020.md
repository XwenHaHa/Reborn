## 1. 目标

1. **视觉**：距离 + 视野（`vision_range` 6.5 m / 半角 75°，鼠）+ **遮挡**（`world_static` 挡视线）三者共同判定；
   目标在草丛（`cover_volumes` 的 `visibility_factor=0.4`）里时**发现距离乘该系数**；
   **近距 0.80 m 内按无遮挡检测**（近距豁免，`TechnicalDesign` §0）。
2. **听觉**：行动产生的**噪声事件**（不是每帧）：脚步在给定节奏下产生事件，`Loudness` 按档位（潜伏/行走/奔跑 = 0.2/0.5/1.0），
   可闻距离 = **`hearing_range × loudness`**；墙**不挡**听觉，但听到的**只有声音发生位置**（不获得持续真实位置，§6）。
3. **逃跑**：看见威胁 → 警戒最长 0.3 s（T019 已有）；**目标在 1.80 m 内立即逃**（跳过警戒停留）；
   `FLEE` 选择**可达**躲藏点（`hide_spots` 组，真实关卡里 = 鼠洞）→ 到达后 `HIDDEN`；
   **没有可达鼠洞时先试附近遮挡**（`cover_volumes`）；两者都没有或不达 → **超时回退**回 `EXPLORE`（`flee_timeout`），
   并保留 T019 的「1 s 窗口 / 最多重选 3 次 / `WAIT`」机制 —— **任何路径都不永久阻塞**。
4. **躲藏后外出**：`HIDDEN` 期间停住；**无危险持续 4 s** → 回 `EXPLORE`（危险 = 看见威胁或听到噪声）。
5. **可查看**：`ai_report()` 增加感知字段（`seen` / `heard` / 噪声位置与年龄 / 草丛系数 / 躲藏点 / 逃跑超时计数），
   调试入口 HUD 增加 `sense:` 行，`MOV|` 增加字段。
6. **沿用已有规则**：状态机与失败回退**不重写**（T019 的 `AnimalAI`）；进食仍走 T017；导航仍走 T012 的双图分层；
   **AI 不直接改位移、不直接改生存数值**。

## 4. 决策（D1~D9）

- **D1 感知是组件，挂在身体上**（与 T016 `InteractionDetector`、T019 `AnimalAI` 同一模式）：
  `AnimalBody.perception`；只**观察**并记录知识，**不直接改位移、不改状态机的状态**。
  AI 通过 `alert_for()`（T019 已有注入点）消费它 —— 保持「感知」与「决策」分离，T023 猫 NPC 可直接复用。
- **D2 威胁定义（不写物种名）**：`animal_bodies` 组里**物种 ID 不同**且未死亡的身体 = 潜在威胁。
  同物种不互相警戒；敌我关系的细化（例如猫对鼠的捕食态度）属 T023/T027。
- **D3 视觉判定顺序**：① 距离 ≤ `vision_range × cover_factor(目标位置)`；② 水平角 ≤ `vision_half_angle_deg`（始终检查）；
  ③ `world_static` 射线不被挡。**近距 0.80 m 内跳过 ①的草丛系数与 ③的遮挡**（`Parameters.md` 第 73 行「近距 80 内仍按无遮挡检测」）——
  视野角仍然生效。**草丛系数取目标位置所在所有 `cover_volumes` 的最小值**（重叠取最有利遮挡），不在草里 = 1.0。
- **D4 听觉不看遮挡、不看草丛**（§6：隔着障碍仍能听见，但只得到位置）：可闻距离 = `hearing_range × loudness`；
  事件里带 `source_id`，**自己的噪声不触发自己**（`source_id == body 的 source_id` 直接丢弃）。
- **D5 噪声只是快照**：`receive_noise()` 只记录**位置 + 时间**，不建立对声源的持续跟踪；
  感知**永远不**提供「声源真实位置」，`report()` 里 `last_seen_*` 与 `last_noise_*` 分开暴露——
  这就是「噪声只有发生位置」的可断言形式。
- **D6 脚步节奏**：`footstep_interval_base = 0.5 s`（标准行走一步的时间），其他档位按**速度反比**缩放
  （`interval = base × walk_speed / 当前速度`，钳在 0.1~1.5 s）→ 蹲 0.85 s（鼠）/ 跑 0.18 s（鼠）；
  只在**贴地 + 水平速度 > 0.05 m/s** 时累计；时间用**世界时间差**（暂停不产生脚步）。
  `Parameters.md` 只给了响度、没给节奏 → **0.5 s 是 T020 新增值，待负责人确认**。
- **D7 逃跑目标优先级**（策划第 198 行）：① 最近的**可达** `hide_spots`（真实关卡 = 鼠洞）；② 最近的**可达** `cover_volumes`（草丛遮挡）；
  ③ 都没有/都不可达 → **不设目的地**，由 `flee_timeout`（3.0 s，T020 新增）超时回 `EXPLORE`（`reason = flee_timeout`，计数可查）；
  逃跑途中路径失败仍走 T019 的 1 s / 3 次 / `WAIT`。
- **D8 可达性判据**：`NavigationServer3D.map_get_closest_point()` 到目标的距离 ≤ `reach_tolerance`（0.5 m，T020 新增）
  **且** `map_get_path()` 非空且终点 ≤ `reach_tolerance`。取不到有效导航地图时**不判定为不可达**（交给 T019 的失败回退），
  避免把"地图还没同步"误判成"封路"。
- **D9 立即逃与躲藏语义**：看见威胁且距离 ≤ `immediate_flee_range`（1.80 m，`Parameters.md` 第 71 行）→ **直接 `FLEE`**；
  否则先 `ALERT`（0.3 s），警戒结束时**仍看得见**才 `FLEE`。`HIDDEN` 期间停住并刷新「危险时间」；
  `now − max(最后看见, 最后听见) ≥ hidden_hold_time`（4.0 s，同第 71 行）→ 回 `EXPLORE`。

## 6. 断言（`tests/run_t020_perception.gd`，目标 ≈90 条）

- **A 接口与默认值**：`Perception` 存在且是 `Node`；`can_see_point` / `receive_noise` / `report` 方法齐全；
  `near_detect_range = 0.80`；配置里的响度 0.2/0.5/1.0、`footstep_interval_base = 0.5`；
  AI 的 `hidden_hold_time = 4.0` / `immediate_flee_range = 1.80` / `flee_timeout = 3.0` / `hide_arrive_radius = 0.30` / `reach_tolerance = 0.5`；
  `State.FLEE = 3` / `State.HIDDEN = 4`（契约顺序）。
- **B 视觉**：无遮挡 3.0 m 看见；6.0 m 看见 / 6.9 m 看不见（> 6.5）；
  正前 0°、侧 60° 看见 / 身后 180°、侧后 100° 看不见（半角 75°）；
  中间放 `world_static` 墙 → 看不见，移走墙 → 看见（**遮挡有效**）；
  **近距豁免**：墙 + 0.6 m → 看见（< 0.80），墙 + 1.2 m → 看不见；
  **草丛系数**：目标在 `cover_volumes` 内 3.0 m 看不见（3.0 > 6.5×0.4 = 2.6）、2.0 m 看见、同一 3.0 m 移出草丛看见；
  `cover_factor_at()` 在草丛 = 0.4、在外面 = 1.0。
- **C 听觉**：奔跑响度 1.0 → 9.5 m 可闻 / 10.5 m 不可闻；走路 0.5 → 4.5 m 可闻 / 5.5 m 不可闻；潜伏 0.2 → 1.5 m 可闻 / 2.5 m 不可闻；
  **墙不挡听觉**（墙后 3 m 跑步 → 听见）；**自己的噪声不触发自己**；超距不记；
  `heard_count()` 只随有效噪声增长。
- **D 噪声只有发生位置**（TestCases **A02** 前半）：收到 5 m 外跑步噪声后，把声源**瞬移到 8 m 外且不再发声** →
  `noise_position()` **仍是原位置**、`noise_age()` 随时间增长、`last_seen_position()` 仍为空、`is_threat_visible()` 为假；
  该噪声（外部把噪声转发给 AI，与 `WorldDirector` 总线同一条路径）后，AI 的 `alert_position()` **等于原噪声位置**（不是声源新位置），
  （**没有朝真实位置导航**）。
- **E 脚步事件（非每帧）**：猫身体贴地行走 2.0 s → `footstep_count` 在 3~6 之间（0.5 s 节奏，**不是每帧**，物理帧 ≫ 10×脚步数）；
  档位响度：蹲 0.2 / 走 0.5 / 跑 1.0；`WorldDirector.noise_event_count` 增长，且事件字段 `loudness` 与档位一致；
  暂停或不动时不产生脚步（位置不变 → 计数不变）。
- **F 逃跑与躲藏（可达鼠洞）**：夹具（屏障 + 0.24×0.30 洞 + 鼠层导航 + 洞内 `hide_spots` 标记，NPC 距洞 ≈5 m）：
  威胁出现在 3.0 m（> 1.80）→ 先 `ALERT`（0.3 s 内仍在 alert）→ 自动 `FLEE`（`reason` 可查）→
  **位移 > 3 m**（真的跑，不是瞬移）→ 到达洞（距标记 ≤ `hide_arrive_radius`）→ `HIDDEN`、`move_intent = 0`、`hidden_count = 1`、`hide_target_id` 非空；
  威胁移出视野且不再发声 → **4 s 前仍在 HIDDEN、4 s 后回 `EXPLORE`**（`reason = hidden_done`）。
- **G 无路径超时回退（封路）**：同夹具但**洞被封死**（放一个 world_static 墙盒把洞填住 → 鼠层没有通道）：
  `find_hide_spot()` 返回 null、`hide_candidates_tested ≥ 1`；无 `cover_volumes` → FLEE 不设目的地 →
  **`flee_timeout`（3.0 s）内**回 `EXPLORE`（`reason = flee_timeout`、`flee_timeouts ≥ 1`）；
  NPC 仍在物理世界且**能再次觅食**（不永久阻塞）；**立即逃**：威胁出现在 1.5 m → 直接 `FLEE`（不等警戒 0.3 s）。
- **H 集成**：真实 `l_courtyard.tscn`：`hide_spots` 组里有**且仅有 1 个**鼠洞躲藏点；鼠 NPC 放在 Roots 区 →
  `find_hide_spot()` 取到它、`reachable()` 为真、设目的地后路径点 > 1；**猫层在洞里没有导航面**
  （`map_get_closest_point` 距离 > `reach_tolerance`）；HUD 出现 `sense:` 行、`MOV|` 出现 `heard=`；
  关卡与 `main` 里 0 调试节点；T011/T012 断言不退化。

## 8. 失败回退

- 若运行期 `map_get_path()` 在**同进程烘焙**后不可靠（T012 踩过：运行期换 navmesh 后查询返回 0 点）：
  夹具改为**用已落盘的 `resources/nav/l_courtyard_*.tres`**（真实关卡）而不是运行期烘焙，或把"可达"判据退化为
  `map_get_closest_point()` 单条（并在证据里写明）。**不伪造可达/不可达**。
- 若 `cover_volumes` 的几何判定无法通用（非 Box 形状）：只支持 Box/Sphere 并在 `report()` 里标 `unsupported_shape`，
  不静默当成"没有遮挡"。
- 若 HIDDEN 外出计时与 T019 的警戒回落互相干扰：保留 T019 语义（警戒最长 0.3 s、可重复注入不无限延长），
  T020 只在警戒**结束**时决定去向；断言以"状态与原因"为准。
- 任一失败最多两次有依据的修复，之后按 `AGENTS.md` 记 blocked。
