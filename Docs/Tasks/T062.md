## 2. 决策

- **D1 发布预设排除"作弊入口"**：`preset.0.exclude_filter` 由 `tests/*` 扩为
  `tests/*,scripts/debug/*,scenes/debug/*`。**SelfTest 预设保持不变**（它要跑 `tests/*` 断言，是验证用的另一件事）。
  依据：策划/开发计划要求候选版"移除测试作弊入口"；debug 入口（F1 切猫、F2 切鼠、F3 碰撞线框、F4 导航路径、
  F5 调试 HUD、F6 重开）在正式玩家面前等于作弊面板。
- **D2 审计要**证明**排除了**，不是"配置里写了就算"：`Tools/t043_pck_audit.py` 增加
  `--deny scripts/debug/ --deny scenes/debug/ --deny debug_entry`，**任何命中即退出 1**。
- **D3 "个人配置"用可判定口径**：运行期脚本（`scripts/**`、`autoload/**`）里**不得出现绝对盘符路径**
  （`E:\`、`C:\`、`/home/`），所有运行期路径必须是 `user://` 或 `res://`；由新套件断言。
- **D4 干净测试存档要正面证据**：发行包在**临时 `APPDATA`** 下首启（真实 `user://` 不碰），
  出生前**不得**产生 `savegame_v1.json`；存档只应在触发点（死亡/发现/解锁/休息/退出）出现。
- **D5 输入可用 = 真按键驱动**：沿用 T043 的判据——无存档首启菜单按 **Enter** 进物种选择页、**再 Enter 出生**，
  画面从"深色菜单"变成"有 HUD 的生存帧"（非黑像素比 + vision 判读）。
- **D6 零窗口**：打包与取证全走隐藏桌面（`Tools/CaptureRun.ps1` / `t043_release_capture.ps1`），
  不许任何 Godot 窗口弹到负责人桌面（Handoff 硬约束）。

1. **预设契约**：preset.0 排除 `tests/*` + `scripts/debug/*` + `scenes/debug/*`、控制台包装 0；
   preset.1 保留 `tests/*`（`exclude_filter` 空）、控制台包装 2；两者 `embed_pck=false`、`x86_64`、`script_export_mode=2`。
2. **卫生**：`scripts/**`、`autoload/**` 无绝对盘符路径；`GameSettings.DEFAULT_PATH` 与 `SaveManager` 默认路径均为 `user://`；
   `MainEntry.test_mode` 默认 `false`；`main.tscn` 实例化后树内**没有** `DebugEntry`。
3. **导出成功**：两预设 `EXIT=0`；发行包无 `Reborn.console.exe`。
4. **审计**：发行包 `.pck` **不含** `tests/`、`scripts/debug/`、`scenes/debug/`、`references/`、`Docs/`、`tool_*`、`run_t0*`；
   审计退出码 0。
5. **非编辑器启动**：`Builds/P0-Win64/Reborn.exe` 在隐藏桌面 + 临时 `APPDATA` 下启动，菜单帧非黑；
   Enter×2 出生后存活帧非黑且 HUD 可读。
6. **干净测试存档**：出生前临时 `APPDATA` 下**无** `savegame_v1.json`；全程 `visible_hits=0`、`console_windows=0`。
7. 全量 headless 0 失败、`invalid=0`。

## 5. 失败恢复

- **排除 debug 后工程报错**：`debug_entry.tscn`/`debug_entry.gd` 被排除属预期；若有**运行期**引用（`preload`/`load`）就会在导出时暴露——
  先查引用再决定是"改引用"还是"只排除场景"。**不允许**为了让包导出通过而把 debug 脚本塞回发布包。
- **审计误报**：`.uid`/`.import` 也会出现在列表里；deny 只按前缀匹配，必要时用 `--allow` 收紧，**不许**放宽到"全部放过"。
- **发行包启动失败**：先看 `Art/Probes/.capture_logs/t043_release_*.log`；区分"崩溃"（无窗口/非黑比 0）与"隐藏桌面不可用"。
- **临时 APPDATA 不生效**：`user://` 走 `%APPDATA%\Godot\app_userdata\Reborn`；必须确认子进程继承的是临时目录，
  否则会读写真实存档（**绝对禁止**）。
