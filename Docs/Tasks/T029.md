# T029 调整路线与参数 —— 任务规格

> 计划出处：`轮生_Reborn_开发计划_v1.0.md` 第 156 行「T029 调整路线与参数 | 2～4h | 前置 T028 |
> **针对一个最大体验问题完成调整并复测；更新参数表**」。
> 日期口径：2026-10-26（顺序递增虚构日期）。状态：**awaiting-review**（能力与判据全部通过；**开关默认关**，是否默认开属产品平衡，待负责人 / U01）。
## 0. 一句话目标

修掉 T028 实测暴露的**一个最大体验问题**——**猫 NPC 的追击永远不会成功**（`CatAI` 从不设 `want_sprint`，
全程 `walk_speed 1.8` < 鼠 `sprint 3.0`，实测 `cat_min_to_player 6.76 m` 就放弃），
让"被追"重新有压力；**参数表同步更新**，并用 T028 的同一把尺子复测。

## 1. 为什么是这一个（而不是候选 A）

`Docs/Evidence/T028.md` §6 有两个候选：

| 候选 | 性质 | 选/不选 |
|---|---|---|
| **A** 鼠 `ALERT` 停留 0.3 s + 猫 `sprint 4.5` ⇒ 扑击必中 | **数值偏好**（猎太快、过程太短） | 不选：这是"要不要更难"的取舍，属设计口味，应等真人试玩（U01）再定 |
| **B** 猫 AI 追击**从不 `want_sprint`** | **机制缺失**（`CHASE` 状态存在但数学上追不上） | **选它**：不是口味问题，而是 `CHASE` 目标未达成；且它直接削弱 P3 阶段门"同一地点对两物种的不同用途"——鼠的路线当前是**零风险直线** |

D0：**这条理由必须写进证据**，因为它改变了"被追"的行为强度，属可感知的手感变化。

## 2. 范围

### 做
1. `scripts/ai/cat_ai.gd`：新增两个 `@export`（`chase_sprint_enabled` 默认 `true`、`chase_sprint_min_gap` 默认 `1.2` m）；
   `_step()` 每帧先把 `body.want_sprint` 清成 `false`（避免残留），**只有 `_step_chase()`** 在
   `水平距离 > chase_sprint_min_gap` 时置 `true`。
2. 新断言套件 `tests/run_t029_sprint_chase.gd`：开关时机 + 速度对照 + 体力门控不崩 + 状态门控（非 `CHASE` 一律不冲刺）。
3. **复测**：重跑 `tests/tool_t028_walkthrough.gd`（同一把尺子），给出**改前/改后对照表**。
4. 视觉 `-- t029` 一帧（追击中 + HUD 显示冲刺状态）——判据仍是 `CAP|t029|done` + `save_result=0 (OK)`。
5. 参数表：`Docs/Parameters.md` 新增"猫 AI 追击冲刺（T029 落地口径）"段。

### 不做
- **不改** `AnimalBody` 的冲刺双门控（`sprint_min_stamina` / 体力消耗）——那是 T015 已锁的行为。
- **不改** `MouseAI`、不改鼠的 `ALERT` 停留（候选 A 留给真人试玩后决定）。
- **不改** `sprint_speed` / `walk_speed` 任何数值（速度差是设计，缺的是"用它"）。
- 不引入新状态、不改 `CHASE`/`SEARCH` 的进入与退出条件。

## 3. 决策

| # | 决策 | 理由 |
|---|---|---|
| D1 | 冲刺只在 **`CHASE`** 打开，`APPROACH` 保持走 | 接近阶段要留"潜行/试探"手感；贴脸时冲刺会让位置来回抖（0.65 m 攻击距离内反复进出） |
| D2 | 距离门控 `chase_sprint_min_gap = 1.2 m` | 略大于攻击距离 0.65 + 迟滞 0.05，保证"远追才跑、近身收步" |
| D3 | 每帧 `_step()` 顶部**统一清 `want_sprint`**，不靠各分支各自清 | 状态切换点很多（ALERT/WAIT/ATTACK/SEARCH/EXPLORE），漏一个就会"搜索时冲刺" |
| D4 | 体力门控**不在这里做** | `AnimalBody` 已有双门控（`stamina >= sprint_min_stamina` 才允许冲刺）；AI 只管"想不想" |
| D5 | 参数放 `CatAI` 的 `@export`，不进 `SpeciesConfig` | 这是 AI 行为参数，不是物种能力；与 T023~T025 的既有默认值同层 |

## 4. 判据

### 硬判据（套件）
- **A1** `CHASE` 且水平距离 > 1.2 m → `body.want_sprint == true`。
- **A2** `CHASE` 且水平距离 ≤ 1.2 m → `want_sprint == false`。
- **A3** 非 `CHASE` 状态（`EXPLORE` / `ALERT` / `APPROACH` / `SEARCH` / `ATTACK` / `WAIT`）→ `want_sprint == false`。
- **A4** 开关关掉（`chase_sprint_enabled = false`）→ `CHASE` 里也 `false`。
- **A5** 速度对照：同一段追击里，`CHASE` 的实际水平位移速率 **> walk_speed 1.8** 且 **≤ sprint_speed 4.5**（体力充足时）。
- **A6** 体力耗尽（`stamina < sprint_min_stamina`）→ 位移速率回落到 walk 量级，且**不报错、不崩**（`is_instance_valid` 全真）。

### 复测判据（走查，**记录不硬判**）
- **B1** `tool_t028_walkthrough.gd` 鼠线的 `cat_min_to_player` 应从 6.76 m **明显下降**（猫真的追上来了）；
  `cat_min_to_hole` 应同步下降；`enter_hole_s` 可能变长（被追）。
- **B2** 猫线的 `catch_s` 不应变慢（冲刺也让玩家猫更快）。

### 8.1 与规格的偏离（都已写进证据，这里只列要点）
- **冲刺范围比 D1 大**：从"只在 `CHASE`"扩到"`APPROACH` / `CHASE` / `SEARCH` 赶路"。原因：实测**只给 `CHASE` 加冲刺等于没改**
  （猫几乎从不进 `CHASE`，`cat_min_to_player` 6.76 → 6.75）。
- **门控从 1.2 m 调到 3.0 m**：1.2 m 时刹不住（进 `in_range` 后还滑 0.475 m、洞口挤到 0.276 m），2.0 m 时鼠仍会被打死。
- **`predator_min_distance` 14.0 → 24.0 m**：出生安全距离必须按**最快速度 × 窗口**重算（原值按 walk 算的）。
- **默认关而不是默认开**：打开后鼠必死（3/3），但根因是下面 8.2 ①，属产品平衡 → 交负责人。

### 8.2 复测暴露的两个既有缺陷（都不是本轮引入）
1. **鼠洞不是安全区**：鼠进洞（`hole_gap 0.13~0.26 m`）后，猫在洞外 0.75~0.80 m 处仍在攻击距离（0.65+0.05）内 → 咬死（`hp 100→0`）。
   **关掉冲刺同样复现**。这回答了 T026 的"洞里能否被打中=未测"：能。→ 削弱 P3 的"同一地点对鼠=安全"，需设计决策。
2. **冲刺会把 AI 冲出无护栏平台且掉落后无处理**：T023 的 `split_platform` 夹具实测 `y=-210.54`、`on_floor=false`；
   该段已显式关冲刺（只验证路径失败语义），"掉落后怎么办"交后续任务。

### 8.3 本任务新增的坑（已并入 `Docs/Commands.md` §2.25）
- **`_sprint_gate` 的距离初值不能写 `INF`**：非移动状态会被判成"离目标很远"→ 巡游也冲刺（实测 `B2` 25 帧假阳性）。
- **刹车距离是硬约束**：`sprint_speed²/(2×max_acceleration)` 必须算进"收步门控"，否则贴脸停不住、会挤进洞口。
- **别在 workspace 里用 shell 做文本编辑**：`Get-Content | -replace | Set-Content` 会把整个文件的编码/行尾改掉（228+/297-），
  只能用 Edit/Write；误操作后用 `git checkout -- <file>` 恢复再重做。
