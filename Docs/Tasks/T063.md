# T063 外部试玩与收尾决策

> **状态：blocked（2026-11-11）—— 缺 **3～5 位未参与设计的真人玩家**。**
> 本文件把"能不能验收"提前定义清楚，并把**除真人以外的所有准备**做完；
> 负责人按 §2 的最小请求安排人，就能直接执行 §3 的流程并把结果填进 §5。
> 依赖 T062（候选版已打包并验证）：`Builds/P0-Win64/Reborn.exe`。

## 1. 目标与不做

**目标**（开发计划 :255）：**外部试玩与收尾决策** —— 3～5 位**未参与设计**的玩家，记录问题；
输出**阻断问题、体验问题**和**继续投入的决定**。

真源：策划 v1.1 :171「首次试玩安排可采用约 **10～20 分钟**的观察窗口，不代表固定一世寿命，也不是已验证的平衡结果」；
:358 M5「存档、声音、UI、休息昼夜、打包 → **可完整游玩并正确恢复进度**」。

**不做**：不改玩法/数值/画面；本任务只观察与记录（发现问题后另开任务修）。

## 2. 最小请求（交给负责人）

1. **人**：3～5 位**没看过本项目**的玩家（同事/朋友均可），至少 1 位**不常玩生存游戏**。
2. **环境**：Windows 机器；把 `Builds/P0-Win64/` 整个目录拷过去（`Reborn.exe` + `Reborn.pck` 必须同目录）。
3. **时长**：每人 **10～20 分钟**，**不要提示玩法**（只给 §3.1 的一句话开场）。
4. **回收**：每人试玩后把 `%APPDATA%\Godot\app_userdata\Reborn\` **整目录**拷回，
   或让试玩者把该目录打包发回（只读收集脚本见 §4）。
5. **决策**：试玩结束后由负责人按 §6 选 **继续 / 继续但先修 / 停止**。

## 3. 流程（每位玩家照做）

### 3.1 开场语（照读，不额外解释）

> 「这是个还在做的小游戏，你是猫，要活下来。WASD 走、Shift 冲刺、Ctrl 潜行、E 交互、鼠标左键扑击、Esc 暂停。
> 没有目标提示，你自己找。玩 10～20 分钟就行，死了就接着玩另一只。」

**不给**：哪里有食物、鼠洞能解锁鼠、休息点在哪、HUD 每个条是什么意思。

### 3.2 观察员记录（不打断，只在表里打勾/写字）

| 阶段 | 观察什么 | 记录 |
|---|---|---|
| 0–1 min | 会不会动？有没有卡在出生点？ |  |
| 1–3 min | 有没有找到食物/水？试了几次 `E`？ |  |
| 3–6 min | 有没有遇到鼠 NPC？扑击试了几次？成功/失败？ |  |
| 6–10 min | 有没有发现鼠洞并解锁鼠？有没有用休息点？ |  |
| 10–15 min | 死因是什么？他自己说得清吗（饿/被打/掉下去）？ |  |
| 死亡后 | 结算页看懂了吗？选了哪个物种继续？ |  |
| 收尾 | 想不想再玩一局？（问：现在最想改哪一件事？） |  |

### 3.3 每人的三个必答问题（原话记录）

1. 「你觉得**这一局为什么结束**？」
2. 「**哪一刻最不知道该怎么办**？」
3. 「如果只能改**一件事**，你改什么？」

## 4. 会话回收（只读工具）

试玩结束后在**试玩者机器**上执行（不改任何文件，只读取并打印）：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File Tools\t063_session_collect.ps1 `
    -Tester "P1" -Out "E:\Reborn\Tools\Probes\t063_P1.log"
```

输出 `SESSION|` / `PROBLEM|` 行：存活局数、解锁物种、世界时间、存档 revision、`SCRIPT ERROR` 条数、
隔离文件（`.corrupt-*`）个数、设置项、日志尾部。**任何人拿到报告都能复现"是不是技术问题"**。

## 6. 判定标准（负责人据此做"继续投入"决定）

- **阻断问题**（必须修才能继续）：崩溃/黑屏/无法操作；存档丢失或读档错位；死亡后卡住无法再开局；
  3 人以上"完全不知道要做什么"。
- **体验问题**（记录但不阻断）：找不到食物/水；不知道鼠洞能解锁；HUD 指标含义不明；
  捕猎手感/判定不合直觉；夜间太黑或太亮；声音/字幕不可辨。
- **继续投入的决定**：≥3/3 完成"捕食→死亡→重生"闭环且无阻断 ⇒ **继续**；
  1～2/3 完成 ⇒ **继续但先修**（列出必修项）；
  0/3 且多数卡在同一处 ⇒ **停止并回到那一步重做**。

## 7. 失败恢复

- 试玩者机器缺 VC++/显卡驱动 → 先在同类机器上跑一次 `Reborn.exe` 确认能开（本机已通过，见 T062 证据）。
- 没有人可安排 → T063 保持 **blocked**，不把"自测走查（T028 自测半边）"冒充外部试玩。
- 试玩者不愿拷 `APPDATA` → 至少抄回 §3.3 三问与 §5 表格，技术侧问题用截图代替。
