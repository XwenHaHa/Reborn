## 3. 决策

- **D1 单一时钟接缝**：新增 `scripts/core/game_clock.gd`（`extends RefCounted` + static，**不用 `class_name`**：`--headless --script` 不刷新全局类缓存，消费者一律 `const GameClock := preload(...)`）。生产实现 `now_ms()` 走 `Time.get_ticks_msec()`；测试可 `GameClock.use_fake(n)` / `advance_ms(ms)` / `use_real()`。只接两个真实需要单调计时的消费者：HUD Toast 到期、SaveManager 普通写节流。游戏逻辑不出现 `if 测试` 分支。
- **D2 权威世界时钟优先**：资源恢复、种群恢复、生存消耗只吃 `WorldDirector.world_time`。测试用 `set_world_time(world_time + dt)` 快进，不睡眠；暂停用 `time_advancing=false` 冻结。
- **D3 运动/寻路类按固定物理步数**：位移与状态机断言用"物理帧数 × 1/60"，不真等墙钟。需要世界时间的套件统一用：`GameClock.use_fake()`（让 `_process` 不再叠加真实 delta）+ 保持 `time_advancing=true`（不误判暂停）+ 每物理步 `world_director.set_world_time(w + 1/60)` 注入。此时世界时间与物理帧严格同步，CPU 负载下不会跑飞。
- **D4 批处理守卫**：每套必须 `checks>0`、`failures=0`、格式可解析；`checks=0`、无 `SUMMARY/RESULT`、`RESULT` 格式未知一律 RED，整体非零退出。
- **D5 墙钟守卫（防待机污染）**：每套记录起止墙钟（`WALL|<suite>|start=|end=|wall_ms=|max_silence_s=`）与整轮 `RUN|r|WALL|wall_ms=|sum_ms=|delta_ms=`。任一单套出现 **>30 s 无输出空洞**，或整轮墙钟与累计套件耗时**偏离 >60 s**，该轮判 `INVALID`（疑似系统待机/挂起），**不算通过也不算失败**，退出码 2 要求重跑；日志写 `VERDICT|INVALID|list=...`。阈值可经 `T040_GAP_SEC` / `T040_DRIFT_SEC` 缩小，仅用于验证该守卫本身。理由：18 分钟一轮，中途合盖会污染整轮，靠事后人肉还原不可接受。

**生产代码零测试分支**：`WorldDirector` 的 `_process` 只从 `GameClock.now_ms()` 取 delta（生产=真实墙钟，测试=可替换），没有 `is_fake()` 分支去改游戏逻辑；`time_advancing` 是既有公开语义（暂停门闩），不是测试开关。注入点在测试侧。

## 6. 用例

- **时钟接缝**：假时间下 Toast 到期与节流窗口由 `advance_ms` 精确驱动；恢复真实时间后行为不变。
- **世界快进**：`set_world_time` 推进后资源/区域/生存在一个/数个帧内结算，不依赖墙钟。
- **固定步数**：移动距离/速率按 `frames × 1/60` 计算，CPU 负载下与空载一致。
- **批处理守卫**：空跑（checks=0）、解析失败、未知 RESULT 均 RED 并非零退出。
- **墙钟守卫**：人为制造 >30 s 无输出空洞（可控 sleep 探针）→ 该轮 `INVALID`、退出码 2；整轮墙钟偏离阈值（`T040_DRIFT_SEC` 调小复现）→ 同样 `INVALID`；正常套件不受影响。

## 7. 失败恢复

- 时钟注入导致某套件其它段失稳：只在该测试段 `use_fake()`，结束 `use_real()`，不全局注入。
- 世界快进导致物理穿模：保留物理帧步进，改用固定帧数，不做大跳。
- 守卫误杀历史格式（如 t031 `fails=`）：显式兼容 `checks=...|fails=...` 与 `pass=...|fail=...` 两种已知格式，其余判 RED。
