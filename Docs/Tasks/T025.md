# T025 NPC 攻击与玩家受伤 —— 任务规格

> 计划出处：`轮生_Reborn_开发计划_v1.0.md` 第 152 行「T025 NPC 攻击与玩家受伤 | 4～8h | 前置 T015,T024 |
> **攻击预警、距离/朝向/遮挡检查、恢复间隔；不是无提示碰撞即死**」
> 日期口径：2026-10-22（顺序递增虚构日期）。状态：**done（2026-10-22）** —— 断言 175/175 ×3、包内 174/174、全量回归 23 套 2655 条全绿；两帧截图已产出（视觉判读因 vision 服务 503 **NOT-VERIFIED**）；见 `Docs/Evidence/T025.md`。

## 0. 一句话目标

让猫 NPC 在**攻击距离内、朝向正确、无遮挡**时发起一次**带预警的攻击**：
**预警 0.45 s → 伤害帧 35 → 恢复 1.2 s**，伤害帧用**当前距离 / 朝向 / 遮挡 / 目标存活**复核
（躲开或绕墙就**无伤**），恢复期内**绝不重复伤害**；受伤一律走既有 `survival.apply_damage()` 通道。
**不是无提示碰撞即死**；不改感知、不改导航基类语义、不做扑击（扑击属 T021）。

## 1. 范围

### 做
1. `resources/species/*.tres` + `SpeciesConfig` 新组 **`Attack`**（真源 `Docs/Parameters.md` 第 69 行）：
   `can_attack`、`attack_damage = 35.0`、`attack_telegraph = 0.45`、`attack_recovery = 1.2`、`attack_range = 0.65`，
   外加 1 个**实现默认值** `attack_facing_half_angle_deg = 60.0`（朝向检查；`Parameters` 无对应行）。
   自校验：`can_attack` 为真 → 四个正数都必须 > 0；为假 → `attack_damage` 必须 0。
2. 新组件 `scripts/systems/attack.gd`（`class_name AttackSettlement extends Node3D`，挂在**攻击者**身上）：
   预警计时、伤害帧复核与结算、恢复计时、诊断与信号；**只执行 + 结算**，不改 AI 状态机、不写位移。
3. `scripts/characters/animal_body.gd`：`enum ACT` 加 **`ATTACKING`**（优先级 `DEAD > POUNCING > ATTACKING > RECOVERING > INTERACTING > IDLE`）；
   按 `can_attack` 建 `attack` 组件；`request_attack()` / `is_attacking()`；攻击与恢复期间禁扑击 / 跳跃 / 交互。
4. `scripts/ai/cat_ai.gd`：新增 **`State.ATTACK`**（`TechnicalDesign` §1 早已预留）：
   追到 `attack_range` 后进 `ATTACK` 并请求攻击；命中后进恢复，恢复结束仍在范围内**再打**。
   （**实现修订**：曾加过"猎物已死 → 直接 `EXPLORE(prey_dead)`"的捷径，但它要调 `_prey_alive()` 全图查询 = **上帝视角信息**，
   且会改写 T023/T024 的"失视 → `SEARCH`"语义 → **撤回**；猎物死亡一律走既有时序 `SEARCH` → 超时 → `EXPLORE`。见 `Docs/Evidence/T025.md` §6.3。）
   新开关 **`attack_enabled: bool = true`**（默认开；夹具可关）。
5. 可查看：`ai_report()` 加 `attack_*` 字段；调试入口 HUD `ai:` 加 `attack=`、`MOV|` 加 `atk=`/`atk_hits=`/`atk_miss=`/`atk_state=`。
6. 断言套件 `tests/run_t025_attack.gd`（A～H，目标 ≥ 100 条）。

### 不做（越界即停并解释）
- **鼠的藏身与掩体规则**（`Parameters` 第 73 行草丛、鼠洞进不去）→ **T026**。
- **被攻击后的逃跑反应 / 仇恨与再追击**：属 T026 与 P4 生态（本任务只保证伤害与复核）。
- **体力/资源消耗、动作音效**：第 69/152 行没给攻击的体力成本；`行动声音与 AI 噪声统一` 属 **T055**。

## 3. 数据与接口契约

```gdscript
# SpeciesConfig（新组；真源 Parameters.md 第 69 行 + 1 个实现默认值）
@export_group("Attack")
@export var can_attack: bool = false
@export var attack_damage: float = 0.0          # 35（第 69 行）
@export var attack_telegraph: float = 0.0       # 0.45 s（第 69 行）
@export var attack_recovery: float = 0.0        # 1.2 s（第 69 行）
@export var attack_range: float = 0.0           # 0.65 m（第 69 行 AttackRange 65）
@export var attack_facing_half_angle_deg: float = 0.0   # 60°，**实现默认值**

# AttackSettlement（scripts/systems/attack.gd）
signal attack_started(target_id: String)
signal attack_landed(target_id: String, damage: float, applied: bool)
signal attack_ended(target_id: String, hit: bool)

func setup(p_body: AnimalBody, p_config: SpeciesConfig) -> void
func start_attack() -> bool                          # 门控：species/dead/captured/airborne/busy/target
func is_attacking() -> bool                          # 预警中
func is_in_recovery() -> bool
func state_name() -> String                          # idle / telegraphing / recovering
func telegraph_elapsed(world_time := NAN) -> float
func recovery_elapsed(world_time := NAN) -> float
func target_id() -> String
func last_miss_reason() -> StringName                # ""/out_of_range/occluded/facing/dead/target_lost
func report() -> Dictionary
var attack_count: int                                # 发起次数
var hit_count: int
var miss_count: int
var last_damage: float

# AnimalBody
enum ACT { IDLE, INTERACTING, POUNCING, ATTACKING, RECOVERING, DEAD }
var attack: AttackSettlement = null                  # 仅 can_attack 时建
func request_attack() -> bool
func is_attacking() -> bool
var last_attack_blocked_reason: StringName           # ""/species/dead/captured/airborne/busy/target

# CatAI
@export var attack_enabled: bool = true
@export var attack_retry_interval: float = 0.25      # 实现默认值：在范围内但攻击被拒时的重试间隔
func attack_count() -> int
```

## 4. 状态机与时间线

| 阶段 | 时长 | 允许 | 禁止 |
|---|---|---|---|
| `telegraphing`（预警） | `attack_telegraph` 0.45 s | 停住、朝向锁定（攻击开始时锁定） | 扑击 / 跳跃 / 交互 / 再次攻击 / 位移（AI 不给意图） |
| **伤害帧** | 1 帧 | —— | —— |
| `recovering` | `attack_recovery` 1.2 s | 停住 | 扑击 / 跳跃 / 交互 / 再次攻击 |
| 之后 | —— | 全部（仍看得见且在范围内 → AI 再次进 `ATTACK`） | —— |

伤害帧复核（**四查一结算**，全过才掉血）：
1. **目标个体仍在**（不是"重新找最近的"）；
2. **水平距离 ≤ `attack_range` + 0.05**（迟滞与 `RANGE_HYSTERESIS` 同口径）；
3. **朝向**：与攻击开始时锁定的方向夹角 ≤ `attack_facing_half_angle_deg`；
4. **无遮挡**：`eye → target.eye_position()` 射线打 `world_static` **且不走 `Perception` 的近距豁免**
   （0.65 m < 豁免 0.80 m，用感知的判据会让"绕墙"永远打中 —— 这是本任务刻意与感知分开的一条）；
5. 目标未死亡 / 未 `captured` → `survival.apply_damage(attack_damage, &"attack")`。

未过 → `miss_count += 1` + 写 `last_miss_reason`（`out_of_range` / `facing` / `occluded` / `dead` / `target_lost`），**不掉血**。

## 5. 行为决策

| # | 决策 | 理由 |
| --- | --- | --- |
| D1 | 攻击执行放**身体组件**（`AttackSettlement`），AI 只请求（`request_attack()`） | 与 T021 扑击同结构：AI 不直接改生存数值；也便于无 AI 的纯几何测试 |
| D2 | 预警**不打断**（开始就锁定方向与目标，不等"取消"） | §6 第 231 行"攻击开始即保存方向与目标信息"；命中与否只由**伤害帧复核**决定 |
| D3 | 恢复期**复用** `AnimalBody` 既有的 `_recover_until` / `is_recovering()` 封锁 | 与扑击恢复同一套门，避免两套"忙"判据打架 |
| D4 | 遮挡复核**不**走 `Perception.can_see_point()`，用独立 `world_static` 射线 | 0.65 m 在近距豁免 0.80 m 内，用感知判据会让 A04 的"绕墙"失效 |
| D5 | `attack_enabled` 默认 **true**，但 T024 夹具显式关掉并加 1 条声明断言 | T025 起"到 0.65 m 停住"升级为"停住 + 攻击"，T024 的判据只在**它自己的夹具**里保持原义（见 §8） |
| D6 | 玩家与 NPC **同一条**受伤通道（`survival.apply_damage`） | `Parameters` 第 65/75 行；`died` 只发一次由 T015 保证 |
| D7 | 攻击**不消耗体力** | `Parameters` 第 69 行没给攻击成本；不能凭空加数值（记开放项） |
| D8 | 朝向检查放在**伤害帧**（不在启动时硬拒） | 让"预警期间转身躲开"也能无伤（D2 的一致结果） |
| D9 | 3 个实现默认值（`attack_facing_half_angle_deg` 60°、`attack_retry_interval` 0.25、伤害帧迟滞 0.05 沿用 `RANGE_HYSTERESIS`）放 `@export` | 与 T019/T020/T023/T024 同做法；`Parameters` 无对应行 |
| D10 | 鼠 `can_attack = false` → **不建** `attack` 组件、`request_attack()` 返回 false（`species`） | 与 T021"鼠 `can_pounce=false` 无捕获组件"同口径 |

## 6. 验收断言（`tests/run_t025_attack.gd`，目标 ≥ 100 项）

### A 接口与参数（≥ 12）
- A1 `SpeciesConfig` 有 `Attack` 组 6 个字段；猫 `can_attack=true` 且 35 / 0.45 / 1.2 / 0.65 / 60°；鼠 `can_attack=false` 且 `attack_damage == 0`
- A2 自校验：把猫的关键值改成 0 → `validate_config()` 报错（至少 1 条）；鼠改成 `can_attack=true, damage=0` → 报错
- A3 `AttackSettlement` 类可实例化、`setup()` 后 `state_name() == "idle"`；查询/信号齐备
- A4 `AnimalBody.attack` 只在 `can_attack` 时建；`ACT.ATTACKING` 在枚举里；`action_state_name()` 能到 `"attacking"`
- A5 `CatAI` 有 `attack_enabled` / `attack_retry_interval` / `attack_count()`；`ai_report()` 含 `attack_*`
- A6 **无物种名字面量**（`attack.gd` 源码静态检查；包内标 `STATIC|NOT-APPLICABLE`）

### B 预警与命中（≥ 16）
- B1 目标在 0.65 m 内、正前方、无遮挡 → `request_attack()` 为真、`attack_count == 1`、`state_name() == "telegraphing"`
- B2 **预警期间目标不受伤**：0.44 s 时 health 仍 100（`telegraph_elapsed()` 单调增长）
- B3 预警 **0.45 s（±0.08）** 后伤害帧：health 100 → **65**、`hit_count == 1`、`last_damage == 35`
- B4 恢复 **1.2 s（±0.12）**：期间 `action_state_name() == "attacking"`/`is_recovering()` 为真，到点回 `idle`
- B5 目标 `last_damage_reason == "attack"`（走既有受伤通道）
- B6 攻击期间 `move_intent` 为零、1 s 内位移 ≤ 0.15 m（**预警期间不乱跑**）
- B7 `attack_started` / `attack_landed(target, 35, true)` / `attack_ended(target, true)` 三个信号各 1 次

### C 躲开、绕墙与边界（A04 的另一半，≥ 16）
- C1 预警期间把目标移到 1.5 m（同方向）→ 伤害帧 `miss`、`last_miss_reason == "out_of_range"`、health 仍 100、`miss_count == 1`
- C2 预警期间在两者之间放 0.4 m 厚的 `world_static` 墙 → `occluded`、health 仍 100（**近距豁免不得放行**）
- C3 预警期间目标被打死（`apply_damage(9999)`）→ `dead`、不掉血
- C4 预警期间目标被 `mark_captured()` → `dead`（同一支路：不可行动）且不掉血
- C5 目标**背对**时（猫转身 180° 后目标在身后）→ 伤害帧 `facing`、不掉血
- C6 距离恰好 0.65 m → 命中；0.70 m → `out_of_range`（迟滞 0.05 的边界两侧各测一次）
- C7 目标在**另一层**（`collision_layer` 换走）时不命中（不误伤无关的动物）

### D 恢复间隔与连按（≥ 12）
- D1 命中后 1.2 s 内 `request_attack()` 被拒（`busy`），`attack_count` 不变
- D2 恢复期内目标 health **不再下降**（连续采样 1.0 s 全为 65）
- D3 恢复结束后可再次攻击 → 第二次命中 65 → **30**（`hit_count == 2`）
- D4 同一帧连按 10 次 → `attack_count` 只 +1
- D5 第三次命中 → 30 → 0，`died` 只发**一次**（`is_dead()` 为真）
- D6 死亡后 `request_attack()` 被拒（`dead`）

### E 朝向与几何（≥ 10）
- E1 正前方 0.3 m → 命中；正后方 0.3 m → 开始就被拒或伤害帧 `facing`（判据：**不掉血**）
- E2 侧方 30° 内（60° 半角）→ 命中；侧方 90° → 不掉血
- E3 朝向检查分两条（实测口径）：
  - **E3a 锁定方向**：预警中途**猫自己转身 180°**，但目标仍在**锁定锥**内 → 伤害帧**照样命中**（§6 第 231 行"攻击开始即保存方向"）；
  - **E3b 目标跑出锁定锥**：预警中途把**目标**移到同距离、偏 90°（半角 60° 外）→ 伤害帧 `facing`、**不掉血**。
- E4 竖直差不算距离：目标抬高 0.5 m（水平仍 0.5 m）→ 仍命中（水平距离判据）

### F 玩家受伤通道与不变量（≥ 12）
- F1 受伤走 `survival.apply_damage()`：`last_damage_reason == "attack"`、`changed` 信号至少 1 次
- F2 受伤**中断交互且无收益**（T017 交界）：交互中受击 → `is_interacting()` 为假、资源 units 不变
- F3 世界账本不变（`capture_count` / `capture_food_count` / `captured_target_ids` 均不变）
- F4 掉血不触发捕获：目标 `captured == false`、`captures == 0`
- F5 攻击不消耗攻击者体力（`stamina` 前后差 ≤ 0.5，只受时间衰减影响的部分单列）与 `pounce_count` 不变

### G 鼠不攻击（≥ 6）
- G1 `mouse.tres` 的 `can_attack == false`、`attack_damage == 0`
- G2 鼠身体 `attack == null`；`request_attack()` 为假且 `last_attack_blocked_reason == "species"`
- G3 `MouseAI` 的状态集合里**没有** `attack`（跑一圈鼠 AI，`state_id()` 从不出现 `attack`）

### H 集成与可查看（≥ 10）
- H1 真实关卡 `l_courtyard.tscn` + 猫 NPC（`ai_enabled=true`）：发现 → 接近 → **预警 → 命中**（鼠 health 100 → 65）
- H2 关卡里把鼠移到猫身后 1.5 m 再等 2 s：**不掉血**（不会隔空打）
- H3 HUD `ai:` 含 `attack=`；`MOV|` 含 `atk=` / `atk_hits=` / `atk_miss=` / `atk_state=`
- H4 `l_courtyard.tscn` / `main.tscn` 内无 `/debug/` 脚本节点
- H5 全程无脚本错误（套件汇总 + 退出码；日志报错行由 Evidence 的 `Select-String` 扫描核对）
