# T014：生存状态与统一时间入口

状态：**done（2026-10-15）**。本文件是开工规格 + 完成说明；验收结果与实测数据见 `Docs/Evidence/T014.md`。总计划定义：`轮生_Reborn_开发计划_v1.0.md` §5
「生存状态与统一时间入口 | 4～8h | 前置 T008 | 生命、饥饿、水分、体力；按时间变化，暂停不消耗，高低帧率结果近似一致」。
验收结果见 `Docs/Evidence/T014.md`。

## 1. 目标

1. **生存状态数据**：按 `Docs/TechnicalDesign.md` §3 的契约新增 `SurvivalState`（Resource）：
   `health / hunger / thirst / stamina / last_damage_reason`。
2. **统一时间入口**：所有按时间的生存消耗**只从 `WorldDirector` 的世界时间取差**推进，
   不在各系统里各自累加 delta（`Docs/TechnicalDesign.md` §5）。
3. **帧率无关**：低频结算（每 0.2 s 一次）但**用实际经过时间**，30 / 60 / 144 Hz 结果近似一致。
4. **暂停不消耗**：树暂停（`get_tree().paused`）与显式门闩（`WorldDirector.time_advancing = false`）都不推进世界时间 →
   生存值不变。
5. **生命与体力接口**：生命可受伤害（含致死信号）、体力可被消耗并在 `RegenDelay` 后按速率恢复、且都夹紧在容量内。
   **本任务不接"奔跑/扑击消耗"与"饥渴归零扣血"**（那是 T015），只提供接口与恢复/伤害路径。

范围外（**本任务不做**）：奔跑/跳跃/扑击的体力代价与耗尽降级（T015）、饥渴警告与持续伤害（T015）、
食物/饮水交互与收益（T017）、正式 HUD 与调参页（T018）、休息推进世界时间（T017/T034）。

## 4. 决策

- **D1 时间源唯一**：生存消耗**只**用 `WorldDirector.world_time` 的差（`tick_to(t)`），
  不累加 `_physics_process` 的 delta。依据：一个渲染帧可能跑 0/1/2 次物理帧，
  直接累加 physics delta 会与"世界时间"漂移，也会让"暂停不消耗"依赖两套开关。
- **D2 低频结算但用真实经过时间**：内部 `UPDATE_INTERVAL = 0.2 s`，每当累计到 0.2 s 就用
  **累计到的实际时间**一次性结算（`Docs/TechnicalDesign.md` §5 明文要求）。残留不足 0.2 s 的部分留到下次。
- **D3 数据与逻辑分离**：`SurvivalState`（受契约约束，将来要进存档）只放数据 + 夹紧；
  推进/伤害/恢复逻辑在 `SurvivalController`（`RefCounted`，无 Node 依赖，便于无头断言）。
- **D4 本任务不产生"生存危机伤害"**：饥渴归零扣血、警告阈值（25）属 T015；
  本任务只提供 `apply_damage()` 并保证 `died` 信号只发一次。
- **D5 容量取 `Parameters.md` 既有值**：`初始 Health/Hunger/Thirst/Stamina 100/100/100/100`
  → 字段名 `max_*`，两者都取 100（食物/饮水"成功后全值夹紧"以同值为容量）。
- **D6 休眠帧/极长帧**：单帧世界时间差 >1 s（窗口失焦、断点）也**照实结算**，但要在断言里证明不越界、不跳空。
- **D7 调试可见**：只在调试入口 HUD 加一行（物种/生命/饥饿/水分/体力 + 世界时间），
  正式 HUD 属 T018，**不混入**正式场景（沿用 T013 的分离断言）。

## 5. 接口（实现契约）

```gdscript
class_name SurvivalState extends Resource
var health: float = 100.0
var hunger: float = 100.0
var thirst: float = 100.0
var stamina: float = 100.0
var last_damage_reason: StringName = &""
func clamp_to_max(max_health, max_hunger, max_thirst, max_stamina) -> void
func ratio(value_name: StringName, max_value: float) -> float   # 供 HUD/警告用
func duplicate_state() -> SurvivalState                        # 存档/断言用

class_name SurvivalController extends RefCounted
signal changed(state: SurvivalState)
signal died(reason: StringName)
func _init(config: SpeciesConfig, state: SurvivalState = null) -> void
func tick_to(world_time: float) -> float     # 返回本次推进的**世界时间差**（0 = 时间没走）
func apply_damage(amount: float, reason: StringName) -> void
func spend_stamina(amount: float) -> void    # T015 会用它做奔跑/扑击代价
func is_dead() -> bool
func health_ratio() / hunger_ratio() / thirst_ratio() / stamina_ratio() -> float
func set_state(new_state: SurvivalState) -> void   # 读档
```

`AnimalBody` 增加：`var survival: SurvivalController`、`func survival_snapshot() -> SurvivalState`、
`debug_state()` 里加 `health/hunger/thirst/stamina`（**不改**既有字段语义）。

## 6. 断言（`tests/run_t014_survival.gd`，目标 ≈70 条）

**A 数据类型与契约**：`SurvivalState` 是 `Resource` 子类；五个字段名与契约一致；默认 100/100/100/100；
`clamp_to_max` 把越界值夹回、把负值夹到 0；`last_damage_reason` 默认 `&""`。

**B 世界时间入口**：Autoload `WorldDirector` 存在；`world_time` 随运行前进（`_process`）；
`time_advancing = false` 后 `world_time` 与 `sim_delta` 都不再变；恢复后继续；
`get_tree().paused = true` 后 `world_time` 不动；`reset_for_new_game()` 归零；`get_world_time()` 与字段一致。

**C 按时间消耗**：猫/鼠各自的 `hunger/thirst` 按 `Parameters.md` 速率下降（用真实世界时间跑 N 秒）；
体力**不因时间下降**（本任务没有消耗源），且**恢复**按 `StaminaRegenPerSecond` 进行；
断言两个物种速率**确实不同**（猫 0.08/0.06、鼠 0.10/0.08）。

**D 帧率无关（核心）**：同一段 60 s 世界时间，用 `tick_to()` 分别以 1/30、1/60、1/144 s 步长推进：
- 三者两两差 ≤ `rate × UPDATE_INTERVAL + 1e-6`（≈0.016 / 0.02）；
- 且都落在 `[60 − 0.2, 60] × rate` 区间内（残留 ≤ 一次结算间隔）。

**E 暂停不消耗**：真实循环里先跑 1 s（有消耗）→ 暂停树跑 1 s（**值不变**）→ 恢复再跑 1 s（继续消耗）。

**F 体力**：`spend_stamina` 立即下降并夹紧 ≥0；`RegenDelay` 内**不回复**；之后按速率回复；
容量封顶；`spend_stamina(0)` 不改变任何东西；大量消耗后仍不会变负。

**G 生命**：`apply_damage` 扣血并写 `last_damage_reason`；夹紧 ≥0；`died` 信号**恰好一次**；
死后继续扣血不再发信号；`amount <= 0` 不产生副作用。

**H 极长帧 / 休眠**：单帧世界时间差 5 s → 一次结算也正确（数值符合速率 × 5，且不越界）；
时间**回退**（读档把世界时间调小）不产生负消耗。

**I 集成**：`AnimalBody` 建出 `survival`；在真实物理循环里跑 2 s 后饥饿下降符合速率；
`debug_state()` 暴露四个生存字段；**调试 HUD 出现生存行**；官方场景仍不含调试节点（沿用 T013 判据）。

**J 回归**：T002/T005/T006/T007/T008/T009/T010/T011/T012/T013 ×2 全绿；包内同跑。

## 8. 失败回退

- 若 WorldDirector 在 `--script` 模式下不可用：断言先证明（打印 `get_node_or_null("/root/WorldDirector")`），
  并让 `AnimalBody` 走**本地累计时间**的兜底路径（要在证据里写明"正常运行时走单例、兜底只为无 Autoload 环境"），
  **不允许**把两套时间源混着用。
- 若帧率无关性达不到判据：先查是不是把 physics delta 和世界时间混用（D1），再查结算间隔残留；
  **不许**为了让数值好看把 `UPDATE_INTERVAL` 调到 0（那就变成每帧结算，失去低频意义）。
- 若暂停不消耗失败：先区分"树暂停"与"显式门闩"两条路径各自是否生效（T014 断言里两条都查）。
