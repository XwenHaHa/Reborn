# T010：老鼠移动与通道尺度

状态：**done（2026-10-13）** —— 断言 95/95 ×3、包内 95/95、回归全绿、视觉 4 帧；结果见 `Docs/Evidence/T010.md`。
本文件保留为开工规格（`in-progress` 已于 2026-10-13 关闭）。总计划定义：`轮生_Reborn_开发计划_v1.0.md` §5
「老鼠移动与通道尺度 | 4～8h | 前置 T008 | 短冲刺、窄缝通过、禁止高跳；低顶下不能扩大碰撞体卡入障碍」。
用例归属：`Docs/TestCases.md` **M01 的"鼠半边"（能过内宽 24 / 高 30 cm 通道；无法直接跳上 50 cm 高台）**、
**M02 的鼠部分（低顶下松蹲不扩大碰撞）**，以及 T010 自己的"通道尺度"判据（猫过不去同一个洞）。
验收结果见 `Docs/Evidence/T010.md`。

## 1. 目标

在 **完全复用 T009 那套控制器**（`AnimalBody` + `SpeciesConfig` + `StepClimb`）的前提下，把鼠的差异**全部压进 `mouse.tres`**，
并用物理实测证明"尺度差异真的成立"：

> 1) **短冲刺**：鼠 Walk 1.10 / Sprint 3.00 / Crouch 0.65（`Parameters.md`），加减速走 `max_acceleration = 16`；
> 2) **窄缝通过**：鼠（0.12 × 0.18 m 胶囊）能**站着**穿过内宽 0.24 / 高 0.30 m 的洞；
>    **猫（0.32 × 0.48，蹲下也是 0.32 × 0.30）过不去同一个洞** —— 这是"通道尺度"的硬判据；
> 3) **禁止高跳**：`can_jump = false` / `jump_velocity = 0` → 按跳跃键不起跳；**上不了 50 cm 高台**；
> 4) **低顶下不扩大碰撞**：鼠蹲高 0.12 < 净空 0.15 < 鼠站高 0.18 → 蹲着能过、松蹲**站不起来**、
>    且**不扩大碰撞体**、不卡进障碍；走出去自动站起；
> 5) 全程**不写物种名分支**（差异只在 `.tres`；T008 的静态断言继续守着）。

## 4. 参数与两个新设计常量（**不在 `Parameters.md` 里，属试验世界设计**）

鼠的起测值全部来自 `mouse.tres`（不改）：

| 字段 | 鼠 | 对照（猫） |
|---|---|---|
| `capsule_radius` / `capsule_half_height` | 0.06 / 0.09（站高 0.18） | 0.16 / 0.24（站高 0.48） |
| `crouch_half_height`（蹲高） | 0.06（**0.12**） | 0.15（0.30） |
| `walk / sprint / crouch_speed` | 1.10 / 3.00 / 0.65 | 1.80 / 4.50 / 0.90 |
| `jump_velocity` / `can_jump` | **0.0 / false（禁止高跳）** | 3.20 / true |
| `max_acceleration` / `max_step_height` | 16.0 / 0.03 | 10.0 / 0.12 |
| `camera_offset_z` / `fov` | 0.03 / 90 | 0.10 / 90 |
| `can_use_mouse_tunnel` | **true** | **false** |

**新增试验世界常量（本任务定，写进工具与断言，需负责人确认是否作为关卡设计基线）**：

| 常量 | 取值 | 依据 |
|---|---|---|
| `TUNNEL_OPENING_W` | **0.24 m** | M01 原文"内宽 24 cm" |
| `TUNNEL_OPENING_H` | **0.30 m** | M01 原文"高 30 cm" |
| `MOUSE_LOW_CLEARANCE` | **0.15 m** | 必须夹在鼠蹲高 0.12 与鼠站高 0.18 之间；顺带满足"猫连蹲都进不去"（猫蹲高 0.30 > 0.15） |

由 §4 表可**算出**的硬关系（断言直接算，不硬编码结论）：

- 鼠站立横截面 0.12 × 0.18 ≤ 洞 0.24 × 0.30 ⇒ **能过**（两侧各留 0.06，顶部留 0.12）；
- 鼠蹲姿 0.12 × 0.12 ⇒ 也能过（本任务用**站立**通过，蹲姿只用于自己的低顶区）；
- 猫站立 0.32 × 0.48 ⇒ **过不去**；**猫蹲姿 0.32 × 0.30 也过不去（宽度 0.32 > 0.24 是硬边界）**。

## 6. 实现步骤与断言清单（`tests/run_t010_mouse_movement.gd`）

单位：米；`ASSERT|id|expected|actual|PASS/FAIL`；`SUMMARY|checks=|failures=`；`RESULT|`；退出码 0/1。
试验世界用 T009 的 `l_move_fixtures.tscn`（本任务新增两个区）；鼠/猫都由测试自己实例化，位置由测试显式设定。

1. **配置与几何**（静态 + 从场景读）
   - `mouse.tres` 逐字段（§4 表）与 `validate_config()` 为空；`can_jump=false`、`can_use_mouse_tunnel=true`；
   - 洞的开口 = 0.24 × 0.30（读场景几何，±1e-3）；鼠低顶净空 = 0.15（±1e-3）；
   - **尺度判据**（用两个配置算）：鼠站立/蹲姿能过、猫站立/蹲姿过不去；净空夹在鼠蹲高与鼠站高之间；
   - 鼠的相机偏移是竖直的（`camera_offset_axis == "y"`）且眼点在胶囊内。
2. **平地三档（鼠）**：位移 ∈ [0.95, 1.15] / [2.40, 3.00] / [0.50, 0.75]（理论 1.062 / 2.719 / 0.637）；
   终极速度 ≈ 1.10 / 3.00 / 0.65；加速到 90% 目标 ≤ 0.20 s（`max_acceleration = 16`）；
   松键后速度 → 0、滑行 < 0.10 m（理论 `v²/2a` = 0.038 m）；胶囊底始终贴地。
3. **窄缝通过（M01 鼠半边）**
   - 鼠**站立**从洞一侧走到另一侧：终点越过洞 ≥ 0.30 m、全程 `is_on_floor()`（不是爬上去）、
     身体中心 y 保持在 0.10 + 0.09 ± 0.01（**没有**被抬到洞顶）、与几何体 0 overlap（收缩 1 cm）、
     相机始终在胶囊内且视线不插进几何体；
   - **猫过不去**：同一洞、同一车道，猫走到洞前被挡住（贴住洞面、`z` 不越过洞），
     与几何体 0 overlap（收缩 1 cm），`y` 不变（没爬上去）；
   - 鼠通过时**胶囊没变矮**（站立总高 0.18）→ 证明它不是靠蹲过去，而是尺度允许。
4. **低顶（M02 鼠部分）**：净空 0.15 处
   - 蹲着进入 → 松开蹲 1.0 s → **仍是蹲姿**、胶囊仍 0.12、`headroom_free == false`、
     `stance_blocked_by_headroom == true`、与几何体 0 overlap（**不扩大碰撞、不卡入障碍**）；
   - 走出低顶 → 自动站起：胶囊 0.18、身体 y 回 0.10 + 0.09；
   - 相机在蹲姿下仍在胶囊内、站位不变（相对胶囊顶偏移恒定）。
5. **禁止高跳（M01 鼠半边）**
   - 平地按跳跃 40 帧：`is_on_floor` 始终 true、`velocity.y` 不出现正冲量、y 变化 ≤ 0.01；
   - 助跑直冲 50 cm 高台 2.5 s：仍在地面（y ≈ 0.19）、不进入台子footprint、
     台阶判定原因 `blocked_after_raise`（不是被"蹭上去"）；
   - 对照：同一位置用 `cat.tres` 建身体 → `can_jump() == true`（能力差异只在配置）。
6. **回归**：T002 / T005 / T006 / T007 / T008 / **T009** / 台阶探针全绿；包内同跑 T009/T010。

## 8. 失败回退

- 若鼠过不去洞：**不放宽洞**。先按 T009 的方法逐帧记录（位置/`is_on_floor`/`climb.last_probe`），
  判断是"圆的底蹭到洞下棱"还是"被台阶逻辑误判"；只允许修**判据**（有实测依据）或调**车道对中**，
  并把实测数据写进证据。
- 若猫竟然过去了：说明尺度判据写错（例如高度用错），先查 `capsule_half_height` 与 `CapsuleShape3D.height` 口径。
- 若低顶下松蹲把胶囊撑到 0.18：**不许把断言删掉**，先查 `has_headroom()` 的净空判据
  （T009 的 5 mm 收窄/上移常量是否在 0.15 这种小尺度下失效），修判据 + 记录。
- 任何情况下都不许"为了过测试"改鼠的产品参数（`mouse.tres`）；要改先记 Decisions 并交负责人。
