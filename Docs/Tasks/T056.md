# T056 环境声音与关键字幕

## 1. 目标与不做

**目标**（开发计划 :248）：**环境声音**（溪流等基础环境音）+ **关键字幕**；字幕**不显示不可感知敌人的真实位置**。

开工前状态：T055 刚建立音频设施（`AudioDirector` + 4 个行动音），但**没有环境音**，也**没有任何字幕**。
本任务要解决的是两件容易做歪的事：
1. 环境音不是"事件音"，它是**空间性持续声场**（离水近才响）——不能塞进事件播放池；
2. 字幕最容易泄露信息：很多实现直接把敌人坐标格式化进文本，或对**没被感知到**的敌人也报字。

**不做**：
- 不下载第三方环境音（许可与授权）——溪流/风由脚本合成。
- 不改听觉判据（`hearing_range × loudness`）与 AI 行为。
- 不做字幕样式/字号/多语言（HUD 视觉细节属 ART09 契约，本轮复用既有 toast 通道）。
- 不做环境音随昼夜/天气变化（T057 之后再说）。

## 2. 决策

- **D1 环境音单独一层 `AmbienceDirector`**：溪流是 3D 循环（每个 `water_bodies` 水体一条，`unit_size 6` / `max_distance 30`），风是非定位底噪（`-20 dB`）。与事件音（`AudioDirector`）分开，避免两类声音互抢播放器。
- **D2 循环点靠构造解决，不靠"循环时补一刀"**：合成时用整数频率的周期性起伏 + 首尾交叉淡化，导出后运行时再设 `LOOP_FORWARD` + `loop_end = 帧数`（导入器默认 `LOOP_DISABLED`，不设就会"播完就停"）。
- **D3 字幕只由 `Perception.noise_heard` 产生**：该信号在 `Perception.receive_noise()` 里已经做过距离/响度/自身过滤 —— **听不到就根本不会触发**，不是靠"生成时记得判断"。
- **D4 文本只有方位词，永不带数值**：8 个 45° 方位桶（前方/右前/右侧/…），相对**玩家朝向**计算；同一方位不同坐标 → 文本完全相同（可判定：文本不携带位置）。
- **D5 HUD 复用既有 toast 通道**：不新增控件、不动 HUD 布局，避免破坏 ART09 的 HUD 契约断言。

## 4. 验收

1. 溪流/风两条流存在、`LOOP_FORWARD`、长度 ≥ 2 s。
2. 关卡里每个水体各一条 3D 循环，位置与水体一致（≤ 0.5 m）、`unit_size 6`、`max_distance 30`、全部在播；风底噪在播。
3. **可感知**噪声（1.4 m、loudness 0.5，猫听觉 12×0.5=6 m）→ 出 1 条字幕，含方位词。
4. **不可感知**噪声（50 m）→ 字幕数 **+0**。
5. 文本：无数字、无坐标、同方位不同位置文本完全相同、不含真实坐标串。
6. 环境字幕（`「溪水声」`）无数字；`enabled=false` 后不再产生字幕。
7. 全量 headless 0 失败、0 INVALID、`visible_hits=0`。

## 5. 失败恢复

- **`Identifier not found: SubtitleDirector`**：在 `--script` 运行方式下**直接写 autoload 单例名**会在编译期失败（实测让 3 套红）。一律用 `get_node_or_null("/root/XxxDirector")` + `has_method()` 调用。
- **循环"播一下就停"**：查 `AudioStreamWAV.loop_mode`，导入默认是 `LOOP_DISABLED`；运行时必须设 `LOOP_FORWARD` 且 `loop_end` = 帧数。
- **字幕对没听到的敌人也出现**：不要自己再判一次距离，直接订阅 `Perception.noise_heard`；若发现重复，是订阅了 `WorldDirector.noise_emitted`（那是全局总线，不分受体）。
- **文本里带数字**：方位桶是唯一来源，不要在拼接时附距离/坐标。

## 6. 挂账（不在 T056）

- **听觉主观判读未做**：循环接缝、溪流/风的音色是否可接受，只验证了"在播 + 循环模式正确"，没有听过（headless 无输出）→ 与 T055 一并列为 awaiting-review 待试听。
- 环境音未做距离/朝向的**主观**定位验证（只验证了 3D 播放器参数与位置）。
- 字幕未做视觉排版（复用 toast 位置，正式字幕条属 UI 美术）。
- 环境音未随昼夜/天气变化（T057）；字幕音量/开关项属 T059。
