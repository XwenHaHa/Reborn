# T049 猫奔跑、攻击提示动画

## 1. 目标与不做

**目标**（开发计划 :217）：给猫补齐**攻击提示动作**，且**动画时间必须和攻击事件吻合**；同时确认「猫奔跑」在引擎里真的生效。

验收词拆开就是：
1. 资产里有 `AttackCue` 片段，长度 = `attack_telegraph`（0.45 s），**只播一次**（`LOOP_NONE`）；
2. `AttackSettlement.start_attack()` 进入 `telegraphing` 的那一帧起，视觉就切到 `AttackCue`，提示期时长 ≈ 0.45 s；
3. 恢复期结束后回到 `Idle`/`Walk`，不卡在攻击姿态；提示期不产生位移（不抢走移动控制）；
4. 冲刺时切到 `Run` 且速率按速度归一。

**不做**：
- 不改 `Idle/Walk/Run` 三段（T048 已锁，本轮回归保护）。
- 不动肩/髋折痕的骨架与权重（T047 awaiting-review，仍需负责人选方案）。
- 不碰攻击数值（`attack_telegraph` / `attack_recovery` / 伤害）——时间对齐是"动画服从配置"，不是反过来。

## 2. 决策

- **D1 提示长度取配置值而不是"看起来合适"**：`AttackCue` 长度直接对齐 `SpeciesConfig.attack_telegraph = 0.45 s`，由测试断言 `|clip.length - telegraph| ≤ 0.02`。改配置就必须重做片段，不许两边各说各话。
- **D2 一次性片段**：`LOOP_NONE`，播完停在末帧（恢复期保持出爪姿态），由 `AnimalBody` 在 `ACT.ATTACKING` 期间优先播它。
- **D3 缺片段必须优雅退化**：`has_animation("AttackCue")` 先判断，鼠（无此段）及其他物种行为不变。`get_animation()` 未命中会打 ERROR，所以一律先 `has_animation()`。
- **D4 竖直压低不超过 2 cm**：根骨位移会带着整只猫一起下沉，压低过多会让脚陷进地面（实测 4.5 cm 时脚底 `min_z = -0.017`）。
- **D5 姿态幅度以"一眼可读"为判据，不靠推测**：第一版 spine/neck 6~10°、腿 14~22°，帧判读结论是"几乎看不出在发力，更像站立"→ 放大到 ~1.8 倍并加**单侧前爪抬起**。但前腿伸展 38° 会把肩根折痕（T047 已知缺陷）放大到明显可见，收到 26° 后判读为"能看出出爪，无穿模无撕裂"。

## 4. 验收

1. `A1～A4`：片段存在、长度 0.450 s、`LOOP_NONE`、轨数 ≥ 12。
2. `B0～B6`：攻击结算可用、进入 `telegraphing`、同一帧切到 `AttackCue`、片段在推进、提示时长 0.450 s（±0.05）、提示期位移 ≤ 0.05 m。
3. `C1～C2`：恢复期后回 `Idle`/`Walk`，`is_attacking() == false`。
4. `D1～D4`：冲刺到 4.500 m/s、播 `Run`、`speed_scale` 等于 `speed/sprint_speed` 的归一值、松手回 `Idle`。
5. `run_art02_cat` 75/75（4 段动画、循环口径不变）。
6. 全量 headless 套件 0 失败、0 INVALID、`visible_hits=0`。
7. 视觉：蓄势峰值帧能读出"压低 + 抬爪"，末帧能读出"前探出爪"，且无穿模/撕裂。

## 5. 失败恢复

- **提示卡住不结束**：先查假时钟下世界时间是否逐帧注入（`WorldDirector.set_world_time(+1/60)`），`AttackSettlement.step()` 依赖世界时间；不注入会永远停在 `telegraphing`。
- **`Animation not found` ERROR**：有人对没有该片段的物种调了 `get_animation()`/`play()`；加 `has_animation()` 门，不要靠 try。
- **姿态幅度调大后出现穿模**：先降前腿伸展角，再考虑抬爪单侧化；不要靠加权重补丁（T047 已证明权重平滑无效）。
- **根骨"压低"看不出效果**：查骨架对象缩放（本资产 0.0366，骨骼空间比世界大 27 倍），必须用 `静置矩阵逆 @ (世界位移 / 对象缩放)`。
- **判读与数值冲突**：以"两者都过"为准，冲突记 `awaiting-review` 并给出选项。

## 6. 挂账（不在 T049）

- 肩根折痕/体积收缩（T047）仍在，出爪帧能在肩部看到；未随本任务修。
- 攻击命中的**受击反馈**（鼠的受伤/死亡动作）不属本任务。
- 包内复验（T043 打包链未重跑）。
- `AttackCue` 与 `attack_recovery`（1.2 s）之间的姿态保持是否需要额外"收爪"片段，留待试玩判断。
