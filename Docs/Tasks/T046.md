# T046 猫 UV、材质和拓扑检查

## 1. 目标与不做

**目标**（开发计划 :214）：给出猫资产（正式视觉 `sm_cat_004.glb`）的**拓扑 / UV / 材质**客观检查结论 —— 非流形、翻面、严重拉伸、材质复杂度、贴图规格；有缺陷就定位到部位并给出最小修复方案。

**不做**：
- 不改网格、不重展开 UV、不重烘焙贴图（本轮只**检查 + 定位**；返工需负责人拍板是否动第三方贴图映射）。
- 不做骨骼权重（T047）与动画（T048/T049）。
- 不因为"能跑"就判合格（`approved` 只能负责人置位）。

## 2. 决策

- **D1 只看导出物**：以 `Art/Exports/Cat/SM_Cat_004.glb` 为准（与 `Game/Reborn/assets/characters/cat/sm_cat_004.glb` 逐字节相同，sha256 `b4843d37…`），因为它就是进包的东西。
- **D2 拓扑分 `raw` / `welded` 两组**：glTF 导入会在 UV/法线接缝拆点（ART03 踩过），`raw` 的非流形数会虚高；判据只看 `1e-5` 焊点后的 `welded`，并把"真非流形"定义为 `非流形 − 边界`。
- **D3 UV 拉伸用逐三角各向异性**：`ratio = max(s1,s2)/min(s1,s2)`（`s = UV 边长 / 三维边长`），≈1 为保形；报中位数/p95/最大值与 >2×、>4× 面数，并按**主导骨骼**分组定位到身体部位。
- **D4 材质判据**：槽数 ≤2、贴图 ≤2048²、无粒子/毛发修改器（T044 预算里材质槽 ≤2 也是硬项）。

## 3. 产物

- `Tools/Blender/t046_cat_check.py`（新，可重跑）
- `Docs/Evidence/T046.md`（原始输出 + 结论 + 最小修复方案）

## 4. 验收

1. 脚本可重跑：`blender --background --factory-startup --python Tools/Blender/t046_cat_check.py -- <glb>`，输出 `T046|done`、`exit=0`。
2. 非流形（排除边界）、退化面、孤立点、翻面四项各有明确数值与结论。
3. UV 拉伸给出分布与**部位定位**，不是"感觉有点糊"。
4. 材质槽数/贴图尺寸/毛发几何三项有明确数值。
5. 若有缺陷：给出最小修复方案与工作量判断，并说明是否需要负责人授权（是否动第三方贴图映射）。

## 5. 失败恢复

- 导入后报错/找不到网格：确认 Blender 版本（3.3.1）与 glTF 导入器可用；FBX 源有 3 个网格时取面数最大的那个。
- 指标口径被质疑：`raw` 与 `welded` 都打印，差异归因于接缝拆点（可用 `remove_doubles` 前后对比复核）。
- 判定与视觉判读冲突：以**视觉判读 + 指标**两者都通过才判过，冲突时记 `awaiting-review` 交负责人。

## 6. 挂账（不在 T046）

- 头部 UV 返工（重展开 + 从旧贴图烘焙）或换源 —— 需负责人决定。
- 接地接触阴影弱（T045 记录）→ 表现层任务。
- 骨骼权重质量（T047）。
